How do baseline, backfill, and unchanged monitors work?

initialRunMode default is baseline_only: store a snapshot with no dataset rows and no PPE. emit_backfill emits the first observed hiring rows under limit and maxChargeUsd. emitUnchanged default is false: later runs emit only newly observed hiring rows. Keep monitorKey stable for the same watch. delivery always writes the dataset first; webhook POSTs after dataset output succeeds. dryRun true returns sample rows and skips dataset writes and webhook.
