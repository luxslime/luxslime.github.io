What is Google Maps Reviews Scraper Apify?

Google Maps Reviews Scraper Apify is the taroyamada Store actor google-maps-review-intelligence. It fetches initial HTML from public place URLs and extracts structured place and review signals. This English landing is https://apify.momiji-space.com/google-maps-reviews-scraper/.

Is this a Google Maps reviews scraper on Apify?

Yes, for public place HTML. Pass Maps place URLs, goo.gl/maps share links, maps.app.goo.gl links, or /maps/place/ URLs in placeUrls. Do not expect a complete Places API dump: snippets are whatever is embedded in the public HTML.

  "placeUrls": [
    "https://www.google.com/maps/place/Tokyo+Station/"

  "reviewLimit": 200,
  "delivery": "dataset",
  "dryRun": false

Which live input fields does Google Maps Review Scraper accept?

placeUrls is required. Optional published fields are reviewLimit (default 200), delivery (dataset or webhook), webhookUrl, and dryRun. additionalProperties is false.

Does Google Maps Reviews Scraper Apify return every review on a place?

No guarantee. The live schema says full review extraction requires the Places API; this Actor returns whatever review snippets are embedded in the public HTML.

What place fields can a run include?

The published README summary lists name, address, coordinates, category, phone, website, aggregate rating and review counts, public review snippets, and provenance/warning indicators. Extraction uses Open Graph meta tags, JSON-LD LocalBusiness, embedded script data, URL components, and inline text patterns. That list is not a live coverage guarantee for every URL.

How do dataset, webhook, and dryRun work?

delivery defaults to dataset. Set delivery to webhook and provide webhookUrl to POST results. dryRun true runs extraction without saving to the dataset or webhook.

Does Google Maps Reviews Scraper Apify accept a Google login or Places API key?

No. The published input schema is placeUrls, reviewLimit, delivery, webhookUrl, and dryRun. This independent Actor is not affiliated with or endorsed by Google. Do not use the output to target individual reviewers.
