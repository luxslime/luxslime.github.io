How is Site QA Contact Page Audit different from Contact Page Audit & Business Channel Extractor and CSV Local Business List Scoring Report?

Site QA Contact Page Audit (taroyamada/site-qa-contact-page-audit-scraper): Audit public site contact pages for QA completeness without collecting personal outreach data. Not a contact-detail harvester for emails and phones (use Contact Page Audit & Business Channel Extractor). Not CSV scoring of a local-business list. Not a broken-link crawler. You supply the URLs. Contact Page Audit & Business Channel Extractor is for Channel/contact fields on known pages (input urls; Public contact pages; Channel rows). Not a contact-page QA completeness report pack. CSV Local Business List Scoring Report is for Score a CSV you already hold (input csvUrl / csvData; User-supplied CSV; Scoring report). Not a live contact-page HTML audit. Broken Link Checker is for Crawl start URLs for 404s (input start URLs; Linked HTTP statuses; Broken-link rows). Not contact-page completeness QA.

What input is required?

Live required fields: urls. Published exampleRunInput is shown below.

Field Type Default Notes
urls any[] ["https://example.com/contact?siteQaCanary=contact-v2"] Public page URLs. Public URLs that you are allowed to audit. Required.
maxPages integer 10 Max pages. Maximum number of input pages to check. minimum=1 maximum=100
maxLinksPerPage integer 25 Max links per page. Maximum links to check per page for URL health workflows. minimum=1 maximum=250
emitPageRows boolean false Emit raw page rows. Emit optional raw page snapshot rows in addition to value-event issue/report rows.
generateReport boolean true Generate report row. Generate a site-level report row.
emitExport boolean false Generate export row. Generate an export row for handoff workflows.
emitUnchanged boolean false Emit unchanged rows. When false, repeated unchanged runs emit zero rows and zero charges.
dryRun boolean false Dry run. Emit local sample rows without charging.
