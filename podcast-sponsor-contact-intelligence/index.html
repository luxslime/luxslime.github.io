Podcast sponsors

Public podcast sponsor evidence from RSS, show pages, and iTunes search

Podcast Sponsor Evidence Scraper scans public RSS feeds, show pages, and optional Apple iTunes Search terms for source-linked sponsor evidence. The Store tagline is: public podcast sponsor evidence; try emitResearchExport=false (skip the $7 export); paste 1 RSS URL and Start. It is not the cheaper report scraper sibling — compare Podcast Sponsor Evidence Report Scraper — and it is not Apple Podcasts catalog metadata (Apple Podcasts Scraper).

Try Input: 1 RSS URL, maxEpisodesPerFeed 1, emitResearchExport false. Live Store card: from $15.00 / 1,000 podcast enriched shows ($0.015 per show) + $0.25 per sponsor evidence row + $7 per research export. No Actor Start.

How is Podcast Sponsor Evidence Scraper different from Podcast Sponsor Evidence Report Scraper and Apple Podcasts Scraper?

Podcast Sponsor Evidence Scraper (taroyamada/podcast-sponsor-contact-intelligence) reads public RSS, show pages, and optional iTunes Search terms. Live PPE is podcast-enriched-show $0.015 (primary), podcast-sponsor-evidence $0.25, and podcast-research-export $7 (skip with emitResearchExport=false). Podcast Sponsor Evidence Report Scraper is a sibling Actor with a different live card (do not copy those prices here). Apple Podcasts Scraper is catalog/episode/chart metadata, not sponsor evidence. RSS & Atom Feed Extractor is generic feed XML. Use this Actor for source-linked sponsor evidence. Use Apple Podcasts Scraper for iTunes catalog. Use RSS & Atom Feed Extractor for feed items only.

What input is required?

The live schema required array is empty. Live fields are rssFeedUrls (default one NPR feed URL), showUrls (default empty), searchTerms (default one business-podcast term), maxEpisodesPerFeed (default 3, min 1, max 50), emitResearchExport (default false), emitUnchanged (default false), and dryRun (default false).

How do dataset, webhook, and dry-run delivery work?

This schema does not expose a delivery enum. Dataset output is the billable surface when rows are written. dryRun true samples rows locally with no live calls or billing. emitUnchanged false suppresses previously seen evidence so unchanged runs can write zero rows and zero events.

Limits to keep in mind

  • No required fields; first paid path still needs a public RSS URL and dryRun false.
  • Skip emitResearchExport on the first paid run ($7).
  • Not an outreach list, not purchased emails, and not a claim of advertiser intent.
  • Unchanged evidence is suppressed when emitUnchanged is false.
  • Respect RSS/show publisher terms and Apple Search API terms.
