How is Medicare Coverage Change Impact Report different from CMS Provider Ownership & Quality Change Report and HHS Healthcare Data Breach Change Scraper?

Medicare Coverage Change Impact Report (taroyamada/medicare-coverage-change-impact-report): Track public CMS national coverage reports and NCD/NCA records, then receive source-linked change alerts, descriptive impact reports, and JSON exports. Not CMS nursing-home ownership/quality snapshots. Not an HHS breach list. Not a general Federal Register digest. You supply coverage watches. CMS Provider Ownership & Quality Change Report is for Nursing-home ownership/quality (input watches; CMS facility snapshots; Ownership/quality alerts). Not NCD/NCA coverage records. HHS Healthcare Data Breach Change Scraper is for HHS breach submissions (input terms; HHS breach portal; Breach-change rows). Not Medicare coverage NCDs. Regulatory Alerts Scraper is for Regulatory alert pages (input urls / terms; Public regulatory pages; Alert rows). Not CMS NCD/NCA coverage.

What input is required?

Live required fields: watches. Published exampleRunInput is shown below.

Field Type Default Notes
watches any[] [] National coverage watches. Bounded saved searches across public national CMS coverage sources. No local coverage article or LCD endpoints are included. Required.
monitorKey string "medicare-national-coverage-watch" Monitor key. Stable isolated state namespace for a recurring public CMS coverage watch.
initialRunMode string enum "baseline_only" Initial run mode. baseline_only stores the first observation with zero rows; emit_backfill emits current matches for an explicit first report. enum: baseline_only, emit_backfill
generateReport boolean true Generate coverage impact report. Generate one descriptive report when new or changed public coverage observations are emitted.
emitRawRows boolean false Emit coverage rows. Emit optional low-priced normalized public coverage rows for each new or changed observation.
emitExport boolean false Generate coverage export. Generate a compact JSON export when new or changed observations are emitted.
emitUnchanged boolean false Emit unchanged observations. Accepted for compatibility, but unchanged observations always remain zero rows and zero charge.
maxRecordsPerWatch integer 100 Maximum records per watch. Maximum public records retained per watch/source after filtering. minimum=1 maximum=500
maxChargeUsd number 25 Maximum charge USD. Fail closed before pushing any row if planned PPE charges exceed this cap. minimum=0.005 maximum=250
dryRun boolean false Dry run. Return representative rows for all four configured event types without calling CMS, saving state, or charging PPE events.
