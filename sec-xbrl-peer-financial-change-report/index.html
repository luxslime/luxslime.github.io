How is SEC XBRL Peer Financial Change Report different from SEC EDGAR Scraper and SEC 13F Institutional Holdings Change Report?

SEC XBRL Peer Financial Change Report (taroyamada/sec-xbrl-peer-financial-change-report): Compare selected public-company XBRL facts across a bounded ticker or CIK watchlist. Receive source-linked metric change alerts, descriptive reports, and optional exports. Not a general EDGAR filing monitor. Not 13F holdings. Not FDIC bank call reports. Live schema requires watchlists and userAgent. SEC EDGAR Scraper is for 8-K and S-1 filing alerts (input tickers / CIKs; EDGAR; Filing rows). Not XBRL company facts. SEC 13F Institutional Holdings Change Report is for 13F holdings tables (input watchlists + userAgent; EDGAR 13F; Holdings-change alerts). Not us-gaap XBRL tags. FDIC & NCUA Peer Financial Trend Report is for Bank/CU call-report peers (input watches; FDIC / NCUA; Peer trend report). Not SEC XBRL.

userAgent string "taroyamada-sec-xbrl-peer-financial-change-report/1.0 ops@example.com" SEC User-Agent. Required descriptive value, for example your-company-xbrl-watch/1.0 ops@yourcompany.com. Replace the example contact with your own application contact before production use. Required.
initialRunMode string enum "baseline_only" Initial run mode. baseline_only stores the first observations with zero rows; emit_backfill emits current observations as a first paid report. enum: baseline_only, emit_backfill
generateReport boolean true Generate peer variance report. Emit one report-first descriptive peer variance row when selected observations change.
emitRawRows boolean false Emit raw fact rows. Optional low-priced compact XBRL fact rows for changed observations.
emitExport boolean false Generate evidence export. Emit a compact JSON export of current observations and selected changes.
emitUnchanged boolean false Emit unchanged observations. Accepted for compatibility, but unchanged observations remain free and emit zero rows and zero charges.
maxRequests integer 40 Maximum SEC requests. Hard request bound including ticker index, companyfacts, and frames calls. minimum=1 maximum=200
requestIntervalMs integer 1100 Request interval milliseconds. Minimum delay between official SEC requests. Keep a conservative interval and respect current SEC guidance. minimum=100 maximum=5000
maxChargeUsd number 25 Maximum charge USD. Fail closed before delivery if planned PPE charges exceed this cap. minimum=0.005 maximum=250
dryRun boolean false Dry run. Return deterministic representative rows for all event types without SEC requests, state writes, or charges.
