How is BIS Export Control List Change Report different from HTS Tariff & Trade Scraper and Sanctions Change Tracker?

BIS Export Control List Change Report (taroyamada/bis-export-control-list-change-report): Monitor official BIS Entity List, Denied Persons List, and Unverified List downloads for source-linked descriptive matches and list changes. Not HTS tariff rates. Not OFAC SDN. Not UN Comtrade flows. You supply name/country watchlists against BIS public list files. HTS Tariff & Trade Scraper is for HTS tariff changes (input codes; Public HTS; Tariff-change rows). Not BIS Entity/DPL lists. Sanctions Change Tracker is for OFAC list additions/removals (input names; OFAC public lists; Sanctions-change rows). Not BIS Entity/DPL/UVL. UN Comtrade Trade Flow Change Report is for UN Comtrade preview queries (input watches; UN Comtrade; Trade-flow change rows). Not BIS restricted-party lists.

What input is required?

Live required fields: watchlists. Published exampleRunInput is shown below.

Field Type Default Notes
watchlists any[] [] BIS watchlists. Each watch is a descriptive filter. Leave names and countries empty to observe all records in the selected list types. Required.
monitorKey string "bis-export-control-watch" Monitor key. Stable isolated state namespace for this recurring watch.
initialRunMode string enum "baseline_only" Initial run mode. baseline_only stores the first observation with zero rows. emit_backfill delivers current matching records. enum: baseline_only, emit_backfill
generateReport boolean true Generate delta report. Generate one source-linked aggregate report when selected list changes exist.
emitRawRows boolean false Emit normalized list rows. Add one low-priced descriptive row for each selected list delta.
emitExport boolean false Generate change export. Generate one compact JSON export for the selected deltas.
emitUnchanged boolean false Emit unchanged records. Accepted for compatibility. Unchanged runs always remain zero rows and zero charge.
maxRowsPerList integer 10000 Maximum rows per list. Fail closed instead of silently truncating an official source download. minimum=2 maximum=50000
maxChargeUsd number 50 Maximum charge USD. Fail closed before the first push when the planned PPE charge exceeds this cap. minimum=0.008 maximum=500
dryRun boolean false Dry run. Return deterministic representative rows without requesting BIS, saving state, or charging events.
