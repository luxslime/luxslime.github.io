How is DailyMed Label Change Watch Report different from FDA Warning Letters Scraper and FDA Orange Book Patent & Exclusivity Change Report?

DailyMed Label Change Watch Report (taroyamada/dailymed-label-change-watch-report): Monitor official DailyMed SPL metadata and version history for selected drugs, labelers, NDCs, applications, or Set IDs. Receive source-linked label-change alerts, impact reports, and optional exports. Not FDA warning letters. Not Orange Book patents. Not FDA shortage records. You supply DailyMed watches. FDA Warning Letters Scraper is for FDA warning-letter pages (input search terms; FDA warning letters; Letter rows). Not DailyMed SPL versions. FDA Orange Book Patent & Exclusivity Change Report is for Orange Book patents/exclusivity (input watches; FDA Orange Book; Patent/exclusivity alerts). Not DailyMed labels. FDA Drug Shortage Supply Change Report is for FDA shortage records (input watches; FDA shortages; Shortage-change alerts). Not DailyMed label versions.

What input is required?

Live required fields: watches. Published exampleRunInput is shown below.

Field Type Default Notes
watches any[] [] DailyMed watches. Bounded recurring watches. Use a stable id and at least one filter per watch. Required.
monitorKey string "dailymed-label-watch" Monitor key. Stable isolated state namespace for a recurring DailyMed portfolio.
initialRunMode string enum "baseline_only" Initial run mode. baseline_only stores the first observation with zero rows; emit_backfill emits current matches for an explicit first report. enum: baseline_only, emit_backfill
nameType string enum "both" Drug name type. How DailyMed interprets drugNames. enum: both, generic, brand
includeHistory boolean true Fetch version history. Fetch bounded DailyMed /history metadata for source-linked version evidence. Full label content is never fetched.
generateReport boolean true Generate impact report. Generate one report-first aggregate when new or changed observations are emitted.
emitRawRows boolean false Emit metadata rows. Emit the low-priced compact metadata row for each new or changed record.
emitExport boolean false Generate export. Generate a compact JSON export of metadata/version evidence without full labels.
emitUnchanged boolean false Emit unchanged observations. Accepted for compatibility, but unchanged observations remain zero rows and zero charge.
maxRecordsPerWatch integer 25 Maximum labels per watch. Maximum DailyMed list records retained per bounded query. DailyMed pagesize maximum is 100. minimum=1 maximum=100
maxHistoryEntries integer 10 Maximum history entries. Maximum version-history entries retained per label. minimum=1 maximum=100
maxChargeUsd number 25 Maximum charge USD. Fail closed before delivery if planned PPE charges exceed this cap. minimum=0.005 maximum=250
dryRun boolean false Dry run. Return representative rows for every configured event without DailyMed requests, state save, or PPE charges.
