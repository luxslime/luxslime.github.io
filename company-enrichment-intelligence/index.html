What input is required?

The live schema required array is empty. Live fields are domains (default empty array; prefill stripe.com, notion.so; www and duplicates removed), auditLevel (basic, security_audit, or techstack_report; default techstack_report), proxy (default useApifyProxy false), and dryRun (default true). Live schema does not document which auditLevel value maps to company-basic versus company-full. README maps company-basic to DNS/TLS/RDAP/firmographics/site and company-full to a full report including tech stack and schema.org. Store company-full text says verified public business contact signals (wording differs from README). Prefer live Store event titles; treat auditLevel basic as the cheapest domain event path.
