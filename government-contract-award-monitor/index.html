lookbackDays integer 14 Award lookback window (days). Fetch award notices published within this many days. Keep it short (7–30) for recurring runs to stay fast; widen it for initial discovery.
maxAwardsPerFeed integer 50 Max awards per feed. Upper bound on awards fetched per feed per run. Increase for discovery runs; keep lower for recurring digest runs.

delivery string dataset Delivery mode. dataset stores results in the Apify dataset. webhook posts the digest JSON to webhookUrl.

datasetMode string new_only Dataset output mode. all emits every feed digest row. action_needed emits only feeds that have new awards or watch-term hits. new_only emits only feeds with awards not seen in the previous run.
snapshotKey string contract-award-monitor-state Snapshot key for recurring state. Stable key used to persist seen award IDs across recurring runs so new_only and action_needed modes stay comparable. Use the same key across scheduled runs.
samApiKey string empty SAM.gov API key (required for sam_awards feeds). SAM.gov API key from Account Details on sam.gov. Required for sam_awards source feeds. If missing, sam_awards feeds are skipped with a warning.
samApiUrl string https://api.sam.gov/opportunities/v2/search SAM.gov opportunities API URL. SAM.gov opportunities search endpoint used for award-type records.
tedApiUrl string https://api.ted.europa.eu/v3/notices/search TED API URL (ted_awards feeds). TED notices search endpoint. No API key required.
usaSpendingApiUrl string https://api.usaspending.gov/api/v2/search/spending_by_award/ USASpending.gov API URL (usaspending feeds). USASpending.gov awards search endpoint. No API key required.
requestTimeoutSeconds integer 30 HTTP request timeout (seconds). Timeout for each API request.
notifyOnNoNew boolean false Emit digest even when no new awards found. When true, every feed always produces a digest row even if no new awards were found. When false, feeds with no new awards are omitted from the output.
emitRawRows boolean false Include raw award rows. When enabled, new source-linked award rows are delivered at $0.004 each.
generateReport boolean true Generate supplier-share report. Generate one buyer-facing supplier-share report when new award evidence is found.
emitExport boolean false Generate award export. Generate a consolidated export when new award evidence is found.
maxChargeUsd number 10 Maximum event charge per run. Fail before delivery when the estimated PPE event charge exceeds this amount. Set 0 for no cap.
dryRun boolean false Dry run (skip snapshot writes and webhook delivery). Validate and fetch without persisting state or posting webhooks. Safe for testing input shapes.
nowIso string empty Override current time (ISO string, for testing). Set to a fixed ISO timestamp to make runs deterministic against fixture data.

How do dataset, webhook, and dry-run delivery work?

delivery defaults to dataset on the live schema. Dataset output is the billable surface when rows are written. webhookUrl is used when delivery is webhook (and typically not during dryRun). dryRun true validates or samples without the usual dataset/webhook side effects described on the Store schema. datasetMode can limit emits to changes_only versus all. Unchanged runs that write zero default-dataset rows typically charge $0.00 on current PPE.
