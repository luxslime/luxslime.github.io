What input is required?

The live schema has no required array. Live fields are urls (default https://example.com/), sitemapUrl (default empty), maxPages (default 5, min 1, max 50), strategy (mobile, desktop, both; default mobile), runMode (audit or monitor; default audit), monitorKey, initialRunMode (baseline_only or emit_backfill; default baseline_only), scoreDropThreshold (default 5, min 1, max 50), generateReport (default true), generateExport (default false), emitUnchanged (default false), authorizedUseConfirmed (default false; required for live runs), maxChargeUsd (default 0, min 0, max 1000), timeoutMs (default 90000, min 30000, max 180000), and dryRun (default true).
