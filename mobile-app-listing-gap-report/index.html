How is App Store & Google Play Listing Gap Report different from Chrome Web Store Extension Intelligence and Website Content Extractor?

App Store & Google Play Listing Gap Report (taroyamada/mobile-app-listing-gap-report): This Actor scores public App Store and Google Play listing metadata for one target app against competitor listings and returns a capped, source-linked improvement report. Seed keywords are checked only as presence in listing text — it does not scrape rankings, autocomplete, or search volume. Not an ASO rank tracker, keyword-volume tool, review scraper, or paid-acquisition optimizer. Watch-tier listing_change_watch_summary is proof-gated and not selectable at public launch. Chrome Web Store Extension Intelligence is for Chrome Web Store listing/search metadata (input extensionUrls / searchTerms; chromewebstore.google.com HTML; extension metadata rows). Not App Store or Play listing gap reports. Website Content Extractor is for Docs/pricing/help pages to markdown (input urls; page HTML body; markdown/text). Not store-listing ASO scoring.

What input is required?

Live required fields: targetApp. exampleRunInput sets dryRun true and reportTier entry with maxChargeUsd 9. Schema default dryRun is false. Watch templates are not public. Keep maxChargeUsd aligned with the selected tier.

Field Type Default Notes
targetApp string required https://apps.apple.com/us/app/duolingo-language-lessons/id570060128 Target app URL, App Store ID, or package. App Store URL/numeric ID or Google Play URL/package for the app you want to improve.
competitorApps array see schema prefill Competitor app URLs, IDs, or packages. Add 3-10 competitor App Store or Google Play listings for a paid competitor gap report.
country string us Country/storefront. Two-letter country/storefront code. Used for public metadata requests only.
language string en Language. Language code for Google Play listing pages.
seedKeywords array ["language learning", "spanish", "vocabulary"] Seed keywords. Optional buyer-provided terms. The actor checks listing metadata coverage only; it does not scrape rankings, autocomplete, or search volume.
reportTier string entry Report tier. Choose entry or premium. Watch templates are proof-gated and not selectable during public launch.
maxChargeUsd number 9 Max charge USD. Safety cap for this run. This cap always wins before charging any report group.
demoMode boolean false Demo mode. Return a no-charge preview and sample nextRunInput.
dryRun boolean false Dry run. Set true to return a no-charge previewReport with nextRunInput and estimated cost.
maxReports integer 1 Advanced max reports. Advanced. Maximum report groups to charge; maxChargeUsd is still checked first.
sourceDatasetId string Advanced source dataset ID. Advanced only. Optional prepared input dataset. Not needed for the first run.
webhookUrl string Advanced webhook URL. Advanced. Optional URL to receive results outside Apify.

How do dataset, webhook, and dry-run delivery work?

webhookUrl is used when delivery is webhook (and typically not during dryRun). dryRun true validates or samples without the usual dataset/webhook side effects described on the Store schema.

What does a result contain?

No fenced output JSON. README field list: status, chargedEvent, chargedUsd, reason, listingScore, metadataCoverageScore, keywordCoverage, competitorGaps, actionList, rewriteSuggestions, sourceUrls, confidence, errors, recoveryHint. Treat README samples as illustrations, not a live coverage guarantee. There is no published output JSON schema on the Store page.
