What a G2 reviews scraper row contains

The published README field list is source, sourceUrl, status, productName, vendorName, categoryName, overallRating, totalReviewCount, ratingBreakdown, and nested reviews[] (title, rating, date, author, body, pros, cons, verified), plus fetchError and warnings when a page is thin, blocked, or structurally changed. status is ok, partial, blocked, or error. Export is CSV/JSON from the default dataset. No API key.

Choose among the three public-review sources on the Review Intelligence pack hub. Shopify merchant listings belong on Shopify App Store Review Scraper. Apple/iTunes podcast reviews belong on Apple Podcasts Reviews Scraper or the Apple Podcasts reviews scraper use case.

Tiny first-paid input

The smallest useful G2 reviews scraper check is one public G2 URL, a modest reviewLimit, delivery dataset, and dryRun false. reviewPageUrls is required. Mix a Capterra URL only after this one-URL schema check. Omit unpublished README aliases such as products, source, slug, maxReviewsPerProduct, and emitDeltas.

{
  "reviewPageUrls": [
    "https://www.g2.com/products/notion/reviews"
  ],
  "reviewLimit": 25,
  "delivery": "dataset",
  "dryRun": false
}

Can a G2 reviews scraper also pull Capterra reviews in the same run?

Yes, after a small-sample schema check. The Actor accepts both G2 (g2.com/products/{slug}/reviews) and Capterra (capterra.com/p/{id}/{slug}/reviews/) URLs in reviewPageUrls. It auto-detects source and routes each URL to the matching parser. Start with 1–5 URLs and a modest reviewLimit (25–50). Mix G2 and Capterra in one run only after you validate the schema on a small sample.

What does this G2 reviews scraper return besides a star rating?

Each product row can include source, product metadata, overall rating, rating distribution, and nested review rows with headline, body, pros, cons, and verified. Reviews are extracted from server-rendered HTML. Pages that render reviews only via client-side JavaScript may return partial results. Blocked requests are reported honestly. This independent Actor is not affiliated with or endorsed by G2 or Capterra. Do not use the output to target individual reviewers.

What is a first G2 reviews scraper input that stays on the live schema?
