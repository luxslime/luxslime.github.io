Localized Google News headlines by language and country

Use this page when the job is regional Google News RSS, not a global dump and not a publisher feed you already have. Google News Scraper is the existing Store Actor. It is not a new Actor, not a paid news API, and not an HTML cleaner. Set language and country on the same queries run.

Live Store price: $0.003 per successfully parsed public RSS article row ($3.00 / 1,000 Google News RSS articles). There is no Actor start event on the current Store pricing tab. Platform usage is listed as Included.

What localization changes

language defaults to en (schema examples: en, ja, de). country defaults to US (schema examples: US, JP, GB). Together they tune Google News RSS for a region. Output fields stay title, link, source, pubDate, pubDateISO, description, and query. The published README positions this for global topic monitoring. It does not translate bodies and it does not score sentiment.

For company or brand queries without a regional change, see Google News brand monitoring. For known-publisher XML you already have, see newsroom RSS monitoring.

Tiny first-paid input

Keep the first run small. The live field for per-query volume is maxItems, not maxItemsPerQuery. The published README localized JP illustration uses language ja, country JP, and query 人工知能. The English GB example below uses live schema names only.

{
  "queries": ["artificial intelligence"],
  "language": "en",
  "country": "GB",
  "maxItems": 10,
  "deduplicate": true,
  "delivery": "dataset",
  "dryRun": false
}

Start with Quickstart (company news) on the Store, then change language and country. Confirm the dataset shows real article URLs for that region, then send news, blog, and press links to Article Content Extractor.

How do language and country localize Google News RSS results?

The live schema defaults language to en and country to US. Schema descriptions give examples en, ja, de for language and US, JP, GB for country. Together they tune Google News RSS for a region. RSS & Atom Feed Extractor has no language or country fields because it reads feed URLs you already have.

What live input localizes a first paid Google News run?

Required field is queries (maximum 50). Set language and country to the region you want. maxItems is 1–100 per query (default 25). deduplicate defaults to true. Live PPE is $0.003 per successfully parsed public RSS article row. Do not send unpublished aliases such as maxItemsPerQuery. See Google News Scraper pricing.

Does localization return translated article bodies?

No. Localization tunes which Google News RSS results you get. Each row is still headline, article URL, publisher, timestamps, snippet, and originating query. There is no published full-article text field and no translation step. Send article URLs to Article Content Extractor afterward. For RAG ingestion of those bodies, see article extractor for news and blog RAG.
