What a newsroom feed row contains

The published README field list is source, title, link, pubDate, pubDateISO, description, content (encoded content when available), categories, and matchedKeywords on filtered rows. That table is the published field inventory, not a coverage guarantee for every feed. Keyword filtering is OR-based: any matched keyword keeps the item. There is no exclude list in the live schema. deduplicate defaults to true and removes duplicate links across feeds.

The published README use cases include PR and comms newsroom tracking, competitor blog and product-update monitoring, filtered story queues for content ops, and a fresh URL stream for AI / RAG teams before deeper extraction. Discover URLs here, then send news, blog, and press links to Article Content Extractor. For RAG ingestion of those bodies, see article extractor for news and blog RAG.

Tiny first-paid input

The published Store Quickstart is two publisher feeds. Live required field is feedUrls (maximum 50). Schema prefill is https://blog.google/rss/ and https://openai.com/news/rss.xml. Optional keywords attach matchedKeywords. Leave delivery as dataset and dryRun false for a paid dataset write. Do not send README aliases such as feeds, onlyNewSinceLastRun, or snapshotKey.

{
  "feedUrls": [
    "https://blog.google/rss/",
    "https://openai.com/news/rss.xml"
  ],
  "keywords": ["AI", "agents"],
  "maxItemsPerFeed": 10,
  "deduplicate": true,
  "delivery": "dataset",
  "dryRun": false
}

Start with a small set of high-trust feeds. Store templates named in the README are Quickstart (2 publisher feeds), Multi-Source Monitoring for several feeds with keyword filters, and RSS → Article Cleanup when the next step is article extraction.

Can RSS & Atom Feed Extractor monitor publisher and company newsroom feeds?

Yes, when you already have those publishers' public RSS or Atom URLs. Required input is feedUrls (maximum 50). The Actor parses feed XML and returns item titles, links, publication timestamps, summaries, encoded content when available, categories or tags, and matchedKeywords when an include-list is set. It does not crawl website HTML, query Google News, or extract full article bodies from those links.

What is the cheapest first paid input for newsroom RSS monitoring?

The published Store Quickstart is two publisher feeds. Live schema names are feedUrls (required), optional keywords, maxItemsPerFeed (default 25), deduplicate (default true), delivery dataset, and dryRun false. Live PPE is $0.001 per successfully parsed public feed item. There is no Actor start event on the current Store pricing tab. See RSS & Atom Feed Extractor pricing.

Does newsroom RSS monitoring return cleaned article bodies?

No. This Actor is a feed discovery layer. Encoded content in a feed row, when present, is still feed XML content. Send news, blog, and press links to Article Content Extractor. Send docs, product, or policy links to Website Content Extractor. Use Google News Scraper when you do not have feed URLs yet.
