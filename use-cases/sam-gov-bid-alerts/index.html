SAM.gov and TED bid-alert queue

Use this page when the job is a source-linked public-sector bid queue. TED, SAM.gov & Grants Bid Alerts Scraper is the existing Store Actor for that queue. It is not a new Actor, not a scrape of SAM.gov or TED HTML UIs, and not Google News RSS. Start TED-only with no external key, then add us once a SAM.gov API key is available.

Live Store price: $8.00 / 1,000 procurement opportunity or alert rows ($0.008 per delivered row). No live start charge.

What the bid-alert queue returns

A normal run returns four published surfaces: meta.executiveSummary (queue size, top buyers, review urgency, source mix, and overallStatus stable, watch, or action_needed), notices[] (normalized rows with source, noticeId, title, buyer, deadlineAt, estimatedValue, signalTags, lanePriority, and recommendedAction), alerts[] (deadline, status, closing-soon, award-watch, or rebid when enabled), and warnings[] / errors[] when a source is missing, throttled, or degraded. A partial source response is never presented as complete coverage.

Official schema-default endpoints are TED https://api.ted.europa.eu/v3/notices/search, SAM.gov https://api.sam.gov/opportunities/v2/search, and Grants.gov / Simpler.Grants.gov https://api.simpler.grants.gov/v1/opportunities/search. For Google News headlines, use Google News Scraper. For citation watch, use PubMed Literature Watch.

Tiny first-paid input

The published Store Quickstart is TED-only and needs no external key. Leave generateReport and emitExport off. Set dryRun false so a delivered row can bill.

{
  "jurisdictions": "eu",
  "keywords": "cloud,cybersecurity,IT services",
  "cpvCodes": "72000000,72220000",
  "daysAhead": 21,
  "maxItemsPerSource": 40,
  "minValue": 100000,
  "delivery": "dataset",
  "dryRun": false
}

If one opportunity row is delivered, live PPE is $0.008. There is no live start charge. An empty result emits zero rows and zero charges. If all 40 fetched items are delivered, 40 × $0.008 = $0.32 at the same published rate. For a smaller first paid cap, see cheapest first paid run for a SAM.gov scraper or grants scraper.

Add jurisdictions us and samApiKey when the TED queue is useful. If us is present without a SAM.gov key, the Actor warns and skips that source instead of failing the whole run. Grants.gov is additive. Do not send unpublished aliases such as sources, query, or maxResults.

Can this Actor queue SAM.gov and TED bid alerts?

Yes, as a bounded procurement queue. It searches official notice APIs — TED by default, SAM.gov when a samApiKey is present, and Grants.gov as an additive lane — and returns a summary-first queue. It is not a scrape of SAM.gov or TED HTML UIs, not Google News RSS, and not PubMed. Start TED-only, then add us once a SAM.gov API key is available.

Why not use Google News or PubMed for procurement watch?

Google News Scraper returns headlines and article URLs from queries; it does not read TED, SAM.gov, or Grants.gov notice APIs. PubMed Literature Watch queries NCBI E-utilities for citation metadata; it is not a bid queue. For public-sector tenders and opportunities, use this procurement Actor.

What is the TED-only first paid bid-alert input?

The published Store Quickstart is TED-only: jurisdictions eu, starter keywords and CPV codes, daysAhead 21, maxItemsPerSource 40, minValue 100000, and delivery dataset. Leave generateReport and emitExport off. Live PPE is $0.008 per delivered opportunity or alert row. There is no live start charge.
