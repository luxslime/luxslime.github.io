What each review row contains

Raw rows have rowType podcast_review. Published fields include podcastId, country, page, reviewerName, rating, title, content, version, voteCount, updated, reviewId, sourceUrl (the official iTunes Customer Reviews RSS URL), and fetchedAt. Export is CSV/JSON. No login, cookie, API key, or CAPTCHA bypass.

Get collection IDs first with Apple Podcasts Scraper search or a watchlist refresh, or from an Apple Podcasts URL. Rank context belongs on the Apple Podcasts chart scraper use case. The three public-review sources sit on the Review Intelligence pack hub.

Tiny first-paid input

The smallest useful reviews check is one podcastIds item, one country, maxPagesPerPair 1, generateReport false, delivery dataset, and dryRun false. podcastIds is required. Leave mode on snapshot until you have a stable monitorKey.

{
  "podcastIds": ["1535809341"],
  "countries": ["us"],
  "maxPagesPerPair": 1,
  "generateReport": false,
  "delivery": "dataset",
  "dryRun": false
}

Can I scrape Apple Podcasts reviews without a collection ID?

No. Required input is podcastIds (numeric iTunes collection ID strings). The schema sets additionalProperties to false, so unpublished showUrls, searchTerm, lookupIds, and episode-feed fields are not accepted. At most 25 unique IDs, 10 unique ISO-3166-1 alpha-2 country codes, and 10 review pages per show/country pair (50 reviews each; iTunes cap). Over-limit input fails instead of being silently truncated.

What is the difference between review rows and a podcast review report?

Default delivery is raw podcast_review rows. Set generateReport true for exactly one podcast_review_report: per-show/country counts, average, five-point distribution, latest date, and up to ten 1–2★ samples with source URLs. Set mode to monitor with a stable monitorKey to emit only new or changed reviews after a baseline_only first run. Leave emitUnchanged false so an unchanged poll stays zero rows.

Does this Apple Podcasts reviews scraper also scrape G2 or Shopify reviews?

No. This Actor reads Apple/iTunes Customer Reviews RSS JSON only. G2 and Capterra pages belong on G2 & Capterra Review Scraper or the G2 reviews scraper use case. Shopify App Store listings belong on Shopify App Store Review Scraper. Review text is public source material for reputation and market research. Do not use the output to target individual reviewers. The Actor does not infer private reviewer identity. It is not affiliated with or endorsed by Apple.
