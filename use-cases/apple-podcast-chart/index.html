Apple Podcasts chart scraper for country rank and movement

Use this page when the job is scraping public Apple Podcasts / iTunes Top Podcasts charts. Apple Podcasts Chart Scraper is the existing Store Actor for that source. It is not a new Actor, not keyword search, and not a reviews tool. Pass ISO country codes; optional genreId narrows to a category chart.

What chart rows and movement reports contain

Raw rows have rowType chart_rank. Published fields include country, rank, showId, showName, artistName, sourceUrl, and fetchedAt, plus aliases name, artist, and collectionId. A movement report has rowType podcast_chart_movement_report: monitorKey, changedCount, newCount, droppedCount, and changes[] with changeType, ranks, rankDelta, and sourceUrl. Export is CSV/JSON. Max 20 countries per run; chart depth capped at 200.

If you will store each snapshot and join on collectionId yourself, use Track Apple Podcasts charts over time with Apple Podcasts Scraper chartRequests. For public ratings on IDs you already have, use the Apple Podcasts reviews scraper use case.

Tiny first-paid input

The smallest useful chart snapshot is one storefront, a modest limit, delivery dataset, and dryRun false. Leave generateMovementReport off until you have a stable monitorKey. Default country is us.

{
  "countries": ["us"],
  "limit": 25,
  "delivery": "dataset",
  "dryRun": false
}

Raise limit or add countries only after the first snapshot is useful. For current pay-per-event rates, see the Store pricing card. Endpoint notes for the sibling snapshot Actor are on How to get Apple Podcasts chart metadata from Apple/iTunes endpoints.

Does this Apple Podcasts chart scraper compute rank movement?

Yes, when you set a stable monitorKey and generateMovementReport true. A baseline_only first run stores state with zero rows. Later polls emit at most one movement report when ranks are new, changed, or dropped. Unchanged polls emit zero rows when emitRawRows is false. A failed storefront is not treated as a mass drop. Rank movement is descriptive evidence, not a forecast, audience estimate, or advertising guarantee.

When should I use Apple Podcasts Scraper instead of this chart scraper?

Use Apple Podcasts Scraper for keyword search, collection-ID watchlists, recent episodes, and chartRequests snapshots that you join yourself — including episode charts with feedType podcast-episodes. This Chart Scraper has no searchTerm, lookupIds, or feedType field. Use Shortlist podcasts for outreach when the job starts from a topic search.

Does Apple Podcasts chart rank equal downloads or listener count?

No. Chart rows are public catalog metadata. Download counts and listener numbers are not in the published output. The Actor reads public Apple Podcasts / iTunes chart JSON. No proxy, Apple ID, or private dashboard is required. It is not affiliated with or endorsed by Apple.
