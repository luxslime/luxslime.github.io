How is Public Vendor Registry Intelligence different from TED, SAM.gov & Grants Bid Alerts and Government Contract Award Change Report?

Public Vendor Registry Intelligence (taroyamada/public-vendor-registry-intelligence): This Actor extracts procurement-ready B2B fields from public vendor registry, supplier portal, and supplier registration pages using direct-source URLs only. No search-engine discovery. Not SAM.gov opportunity search. Not authenticated supplier portals. Direct-source URLs only. TED, SAM.gov & Grants Bid Alerts is for Open opportunities / tenders (input keywords / jurisdictions; SAM/TED/Grants notices; Opportunity rows). Not vendor-pursuit profiles, Form D notices, or post-award spend reports. Government Contract Award Change Report is for Post-award spend/award changes (input feeds; TED / USASpending awards; Award change rows). Not open bid queues. Trade Show Exhibitor Intelligence is for Booth fields from supplied URLs (input exhibitor URLs; User-supplied show pages; Exhibitor rows). Not ATS job boards.

What input is required?

Live required fields: none listed (see live fields). Published exampleRunInput is shown below.

Field Type Default Notes
urls string[] empty Vendor Registry URLs. Public vendor registration, supplier portal, procurement, bid/vendor registry, or supplier onboarding URLs to fetch directly. No search engine discovery is used. maxItems=100
domains string[] empty Procurement Domains. Optional bare domains from public agencies, enterprises, or buyer lists. Domains are normalized to https://domain/ and inspected for same-domain vendor registration links only. maxItems=100
buyerType string empty Buyer Type Hint. Optional buyer context used only for local classification hints. Examples: government, healthcare, university, enterprise, utility, construction.
region string empty Region Hint. Optional region, state, country, or sourcing market to match against page text.
maxLinkedPages integer 2 Max Linked Registration Pages. When a supplied page links to same-domain vendor registration, supplier portal, procurement, or bid pages, fetch up to this many extra direct-source pages as evidence. minimum=0 maximum=5
maxResults integer 25 Max Registry Profiles. Maximum normalized direct sources to process and emit. minimum=1 maximum=100
dryRun boolean false Dry Run. Validate input and write local output without sending dataset rows or charging custom PPE events.
