How is Azure Retail Price Cost Impact Report different from AWS Cloud Pricing Cost Impact Report and Multi-Cloud Pricing Cost Impact Report?

Azure Retail Price Cost Impact Report (taroyamada/azure-retail-price-cost-impact-report): Read official Azure Retail Prices data and emit stable price changes and cost-impact report rows for the scopes you configure. Not AWS offer files (use AWS Cloud Pricing Cost Impact Report). Not a multi-cloud scenario compare. No Azure subscription key is the Store contract unless the live schema adds one — this Actor is the public Retail Prices feed. AWS Cloud Pricing Cost Impact Report is for AWS public offer files (input scopes; AWS price list; SKU change / cost-impact rows). Not Azure Retail Prices. Multi-Cloud Pricing Cost Impact Report is for Normalized AWS vs Azure scenarios (input scenarios; AWS + Azure public prices; Cross-cloud comparison report). Not an Azure-only SKU watch. SaaS Pricing Tracker is for Competitor SaaS page changes (input urls; Public HTML; Page-change rows). Not Azure list prices.

What input is required?

Live required fields: scopes. Published exampleRunInput is shown below.

Field Type Default Notes
scopes any[] [] Azure price scopes. A bounded selection. Include serviceName, armRegionName, and at least one exact SKU, meter, product, or ID selector. Required.
monitorKey string "azure-retail-price-watch" Monitor key. Stable state namespace for a recurring watch.
initialRunMode string enum "baseline_only" Initial run mode. Store a free baseline or explicitly emit current matched prices and a report. enum: baseline_only, emit_current
generateReport boolean true Generate cost impact report. Generate an aggregate monthly cost-impact report when current or changed meters are emitted.
emitRawRows boolean false Emit raw price rows. Emit normalized public Azure meter rows in addition to value-event outputs.
emitExport boolean false Generate price export. Generate a compact JSON-ready export when current or changed meters are emitted.
emitUnchanged boolean false Emit unchanged rows. Accepted for compatibility; unchanged runs remain zero rows and zero charge for billing safety.
maxPagesPerScope integer 2 Maximum API pages per scope. Bound the number of official API pages fetched for each scope. minimum=1 maximum=5
maxItemsPerScope integer 20 Maximum matching meters per scope. Bound the number of exact matched price meters retained for each scope. minimum=1 maximum=100
maxChargeUsd number 25 Maximum charge USD. Fail closed before delivery if configured PPE charges exceed this cap. minimum=0.006 maximum=250
dryRun boolean false Dry run. Return representative rows without Azure requests, state writes, or PPE charges.
