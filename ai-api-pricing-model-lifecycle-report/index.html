How is AI API Pricing & Model Lifecycle Report different from SaaS Pricing Competitor Monitor and B2B Pricing Scraper?

AI API Pricing & Model Lifecycle Report (taroyamada/ai-api-pricing-model-lifecycle-report): Compare and watch official public pricing, model, deprecation, and release-note pages for OpenAI, Anthropic, and Gemini without API keys or model calls. Not a SaaS marketing-page price scrape (use SaaS Pricing Competitor Monitor). Not AWS/Azure cloud SKU prices. It does not accept API keys or send prompts. SaaS Pricing Competitor Monitor is for Competitor marketing price pages (input urls; Public pricing HTML; Price-change rows). Not official AI API model-card prices. B2B Pricing Scraper is for B2B public price pages (input urls; Public HTML; Price rows). Not OpenAI/Anthropic/Gemini model lifecycle. AWS Cloud Pricing Cost Impact Report is for AWS public offer files (input scopes; AWS price list; SKU change / cost-impact rows). Not LLM API token prices.

What input is required?

Live required fields: none (see live fields). Published exampleRunInput is shown below.

Field Type Default Notes
providers string[] ["openai", "anthropic", "gemini"] Providers. v1 provider adapters. Only OpenAI, Anthropic, and Gemini are supported.
models string[] [] Models. Optional exact model IDs, provider:model selectors, or glob selectors. Empty means all models found in the selected providers.
filters object {} Model filters. Optional status, modality, and context-window filters.
usageProfiles any[] [{"name": "standard-month", "inputUnits": 1000000, "outputUnits": 250000, "cacheUnits": 0}] Monthly usage profiles. Monthly input, output, and cache token units used for source-linked cost comparisons. Values are token counts, not API calls.
mode string enum "compare" Mode. Compare current official prices or watch for source-backed changes. enum: compare, watch
initialRunMode string enum "baseline_only" Initial run mode. baseline_only stores a complete source baseline with zero rows; emit_current emits current rows/reports on an empty baseline. enum: baseline_only, emit_current
generateReport boolean true Generate comparison report. Emit an aggregate cost-comparison report when eligible current or changed source data exists.
emitUnchanged boolean false Emit unchanged. When false, identical watch snapshots emit zero rows and zero charges.
emitRawRows boolean false Emit raw model rows. Emit one normalized ai_model_price_row per eligible model and an ai_pricing_export handoff row.
maxChargeUsd number 0 Maximum charge USD. Optional all-or-nothing PPE budget. Zero means no actor-side budget cap. minimum=0 maximum=100000
dryRun boolean false Dry run. Emit local fixture-derived sample rows without live fetches, model calls, or PPE charges.
snapshotKey string empty State namespace. Optional stable state namespace for separate watch baselines.
