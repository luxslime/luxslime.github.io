How is UN Comtrade Trade Flow Change Report different from HTS Tariff & Trade Scraper and BIS Export Control List Change Report?

UN Comtrade Trade Flow Change Report (taroyamada/un-comtrade-trade-flow-change-report): Monitor bounded official UN Comtrade preview queries for new, changed, or removed trade-flow records and generate source-linked trend reports and optional exports. Not HTS tariff-rate changes (use HTS Tariff & Trade Scraper). Not BIS restricted-party lists. Not OFAC sanctions additions. You supply reporter/partner/HS watches. HTS Tariff & Trade Scraper is for HTS tariff changes (input codes; Public HTS; Tariff-change rows). Not UN Comtrade flow tables. BIS Export Control List Change Report is for BIS Entity/DPL/UVL lists (input watchlists; BIS public lists; List-change alerts). Not Comtrade trade flows. Sanctions Change Tracker is for OFAC list additions/removals (input names; OFAC public lists; Sanctions-change rows). Not UN Comtrade flows.

What input is required?

Live required fields: watches. Published exampleRunInput is shown below.

Field Type Default Notes
watches any[] [] Trade-flow watches. Each watch creates at most one official preview API request. Duplicate query dimensions are fetched once and matched to all watch IDs. Required.
monitorKey string "un-comtrade-trade-flow-watch" Monitor key. Stable isolated state namespace for this recurring watch portfolio.
initialRunMode string enum "baseline_only" Initial run mode. baseline_only stores the first bounded snapshot with zero rows. emit_backfill emits the current changes for an explicit paid run. enum: baseline_only, emit_backfill
generateReport boolean true Generate trend report. Emit one report-first aggregate row when changes are observed.
emitRawRows boolean false Emit trade-flow rows. Emit one low-priced normalized row per changed current record. Report and alerts remain the primary output.
emitExport boolean false Generate export. Emit a compact source-linked JSON export when changes are observed.
emitUnchanged boolean false Emit unchanged records. Accepted for compatibility only. Unchanged runs always emit zero rows and zero charges.
maxChargeUsd number 35 Maximum charge USD. The complete planned PPE charge is estimated before the first dataset push. The run fails closed if this cap would be exceeded. minimum=0.006 maximum=500
requestTimeoutSeconds integer 30 Request timeout seconds. Timeout for each official preview request. minimum=5 maximum=120
maxRetries integer 3 Maximum retries. Bounded retries for 429 and transient 5xx responses only. minimum=0 maximum=4
dryRun boolean false Dry run. Return deterministic representative report, alert, row, and export records without API calls, state writes, or charges.
