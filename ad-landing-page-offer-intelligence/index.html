How is Ad Landing Page Offer Intelligence different from Website Content Extractor and Article Content Extractor?

Ad Landing Page Offer Intelligence (taroyamada/ad-landing-page-offer-intelligence): This Actor analyzes user-provided landing pages and pasted ad copy for offer, CTA, proof, pricing, and CRO gaps without scraping ad libraries. Not an ads-library crawler (use Ads Library Competitive Intelligence on URLs you supply). Not a website-to-markdown dump. Not authenticated ad-manager access. Website Content Extractor is for One-shot page-to-markdown (input urls; Page HTML; Markdown/text). Not recurring pricing/legal diffs or RAG audits. Article Content Extractor is for News/blog HTML cleanup (input urls; Article HTML; Headline/byline/body). Not landing-page CRO reports. B2B Pricing Scraper is for Public subscription-tier changes (input competitors[]; Public pricing HTML; Pricing change rows). Not Shopify catalog maps or ads-library pages.

What input is required?

Live required fields: none listed (see live fields). Published exampleRunInput is shown below.

Field Type Default Notes
landingPageUrls any[] empty Landing page URLs. Public landing page URLs to inspect. Only http/https HTML pages are accepted; localhost, private/link-local/metadata/reserved IPs, unsafe redirects, non-HTML responses, and oversized responses are blocked with no charge. Ad library URLs are blocked with no charge.
adCopy string empty Ad copy. Optional pasted ad copy. The actor does not scrape ad libraries.
reportTier string enum entry Report tier. Choose entry or premium. Watch/audit templates are proof-gated and not selectable during public launch; maxChargeUsd is only a safety cap. enum: entry, premium
maxChargeUsd number 3 Max charge USD. Safety cap for this run. This cap always wins before charging any report group. minimum=0 maximum=100
demoMode boolean false Demo mode. Run a sample with no external fetch and no charge.
dryRun boolean false Dry run. Set true to return a no-charge previewReport with nextRunInput and estimated cost.
maxReports integer 1 Advanced max reports. Advanced. Maximum report groups to charge; maxChargeUsd is still checked first. minimum=1 maximum=25
maxPagesPerReport integer 5 Maximum pages in one comparison report. For the premium tier, compare between 2 and 10 public landing pages in one CRO gap report pack. minimum=2 maximum=10
includeCtaAudit boolean true Include CTA and form-friction audit. Include source-linked CTA labels, competing CTA counts, form counts, and form-field evidence.
includeOfferMatrix boolean true Include cross-page offer matrix. Include the page-by-page offer, proof, pricing, CTA-friction, and ad-message-match matrix in premium output.
sourceDatasetId string empty Advanced source dataset ID. Advanced only. Optional Apify dataset ID for prepared input rows. Not needed for the first run.
webhookUrl string empty Advanced webhook URL. Advanced. Optional URL to receive results outside Apify.
