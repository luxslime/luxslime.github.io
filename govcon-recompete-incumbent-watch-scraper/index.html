How is GovCon Recompete & Spend Shift Watch different from TED, SAM.gov & Grants Bid Alerts and Government Contract Award Change Report?

GovCon Recompete & Spend Shift Watch (taroyamada/govcon-recompete-incumbent-watch-scraper): This Actor watches official public federal award data for recompete windows, agency spend shifts, and vendor concentration reports. Not an open-opportunity bid desk (use TED, SAM.gov & Grants Bid Alerts). Not Grants.gov-only notices. Informational only. Not a bid/no-bid decision. TED, SAM.gov & Grants Bid Alerts is for Open opportunities / tenders (input keywords / jurisdictions; SAM/TED/Grants notices; Opportunity rows). Not vendor-pursuit profiles, Form D notices, or post-award spend reports. Government Contract Award Change Report is for Post-award spend/award changes (input feeds; TED / USASpending awards; Award change rows). Not open bid queues. Grants.gov Scraper is for Grants.gov-only funding notices (input feeds / watch terms; Grants.gov; Funding digest rows). Not a multi-source TED/SAM desk.

maxSpendingRows integer 100 Max spending rows per period. Bound the number of official USAspending award rows fetched for each period. minimum=1 maximum=100
emitSpendExport boolean false Generate spend export event. Generate one source-linked spend export row per changed spend snapshot.
fixturePath string empty Fixture path. Optional local fixture path for private canary/testing runs.
emitUnchanged boolean false Emit unchanged rows. When false, unchanged searches emit no dataset rows and no charges.
dryRun boolean false Dry run. When true, emit sample rows without live calls or billing.
initialRunMode string enum emit_backfill Initial run mode. Deployment canary control used by automation; emit_backfill allows first-run proof rows, baseline_only is used for no-change proof. enum: emit_backfill, baseline_only
snapshotKey string empty Snapshot key. Optional state namespace for canary and recurring no-change proof runs.
