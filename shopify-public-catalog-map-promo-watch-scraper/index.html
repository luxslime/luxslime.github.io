How is Shopify Public Catalog Map & Promo Watch different from Shopify Store Scraper and Shopify App Store Review Scraper?

Shopify Public Catalog Map & Promo Watch (taroyamada/shopify-public-catalog-map-promo-watch-scraper): This Actor unofficially maps user-supplied public Shopify storefront catalogs and detects source-linked promo, collection, and catalog map changes. Not Shopify App Store reviews. Not Shopify Admin/API. Not a store-discovery search engine. Confirm authorizedUseConfirmed. Public storefront JSON/HTML only. Shopify Store Scraper is for Public storefront JSON metadata (input storeUrls; Shopify JSON endpoints; Store intelligence rows). Not catalog-map / promo watch events. Shopify App Store Review Scraper is for apps.shopify.com reviews (input app URLs; apps.shopify.com; App review rows). Not merchant storefront catalogs. B2B Pricing Scraper is for Public subscription-tier changes (input competitors[]; Public pricing HTML; Pricing change rows). Not Shopify catalog maps or ads-library pages.

What input is required?

Live required fields: none listed (see live fields). Published exampleRunInput is shown below.

Field Type Default Notes
storeDomains string[] ["example.myshopify.com"] Store domains. User-supplied public Shopify storefront domains.
collectionHandles string[] empty Collection handles. Optional public collection handles to include.
promoKeywords string[] ["sale", "discount", "clearance", "bundle", "limited time"] Promo keywords. Terms used to flag public sale and promo text.
maxProductsPerStore integer 100 Max products per store. Maximum public products to load from each storefront. minimum=1 maximum=1000
emitBaselineSummary boolean true Emit baseline summary. Emit a baseline summary row on the first run for a new snapshot namespace.
emitProductRows boolean false Emit product map rows. Emit optional public product map item rows. Off by default; signal rows carry the business value.
generateReport boolean true Generate promo report. Generate a report row when report-worthy rows are emitted.
authorizedUseConfirmed boolean false Authorized use confirmed. Required for non-dry runs. Confirms each storefront is owned by you or authorized by the merchant.
emitUnchanged boolean false Emit unchanged rows. When false, unchanged stores emit no dataset rows and no charges.
dryRun boolean true Dry run. When true, emit sample rows without live calls or billing.
initialRunMode string enum emit_backfill Initial run mode. Deployment canary control used by automation; emit_backfill allows first-run proof rows, baseline_only is used for no-change proof. enum: emit_backfill, baseline_only
snapshotKey string empty Snapshot key. Optional state namespace for canary and recurring no-change proof runs.
