How is ATS Hiring Signal Scraper different from Career Site Scraper and Trade Show Exhibitor Intelligence?

ATS Hiring Signal Scraper (taroyamada/ats-hiring-signal-intelligence): This Actor monitors Greenhouse, Lever, and Ashby public job boards for new roles, departments, regions, remote hiring, matched keywords, and hiring-signal rows. Invalid or no-public-board sources can emit no-charge diagnostics. Not a career-site HTML crawl of arbitrary /jobs pages (use Career Site Scraper). Not a resume parser or applicant PII collector. Public boards only. Not a hiring recommendation. Career Site Scraper is for Public /jobs HTML signals (input careerUrls; Public career pages; Hiring-signal rows). Not Greenhouse/Lever/Ashby board APIs. Trade Show Exhibitor Intelligence is for Booth fields from supplied URLs (input exhibitor URLs; User-supplied show pages; Exhibitor rows). Not ATS job boards. Google Maps Lead Enrichment is for Enrich existing leads (input business inputs; Enrichment APIs; Lead rows). Does not scrape Maps or ATS boards.

What input is required?

Live required fields: none listed (see live fields). Published exampleRunInput is shown below.

Field Type Default Notes
companies any[] [{"ats": "greenhouse", "slug": "airbnb", "companyName": "Airbnb"}] Companies. Public ATS boards to monitor. Each item needs ats=greenhouse, lever, or ashby plus slug and optional companyName.
keywords any[] empty Keywords. Role, department, technology, or market terms used to flag relevant hiring signals.
regions any[] empty Regions. Location terms used to keep jobs from matching offices, countries, cities, or remote regions you care about.
remoteOnly boolean false Remote only. When enabled, only jobs that look remote-friendly are returned.
sinceDays integer 14 New Role Window. Treat jobs posted within this many days as fresh deltas for watch-mode scoring. minimum=1 maximum=365
watchMode boolean true Watch Mode. When enabled, emit company-level summary rows in addition to matching job rows.
maxJobs integer 250 Max Jobs. Maximum number of job rows to emit across all companies in this run. minimum=1 maximum=2000
dryRun boolean false Dry Run. Validate inputs and emit no-charge preview rows without applying paid PPE events.

Published Store example run input (omitted fields take schema defaults):

{
  "companies": [

      "slug": "airbnb",

    }

  "maxJobs": 3,
