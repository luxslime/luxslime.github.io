Show CLP hazard display data on product pages and keep audit-ready records.

CLPLens Hazard Display helps merchants record hazard display data, sync app-owned product metafields, and show clear product-page hazard information. Hazard profiles you record can include CLP pictograms and statements. The app includes profile editing, gap review, CSV import and export, storefront preview, and audit records. It does not classify products, determine legal status, or provide legal advice.

  • Create product hazard profiles with GHS pictograms and statements
  • Sync app-owned metafields for theme block storefront display
  • Review missing hazard fields before publishing product pages

Quoted from apps.shopify.com/clp-hazard-info-display.

CLP pictograms

Create a per-product hazard profile and toggle GHS pictograms (for example GHS02 and GHS07). The same pictograms render in the theme block on the product page.

CLP labelling statements

Select H/EUH codes; official statement text is inserted from the catalog. Profiles can also carry the signal word and supplemental label text you record.

Theme-block display

Sync app-owned product metafields, then add the CLP Hazard Info app block on the product template. The listing does not say the app rewrites theme Liquid beyond that sync.

Gap review and audit records

Review missing hazard fields before publishing product pages. CSV import and export and audit records sit in the same tool list. Those are merchant-held records, not a filing with a chemicals agency.

Install from the live listing

  1. Open the published listing: apps.shopify.com/clp-hazard-info-display.
  2. Install CLPLens: CLP Hazard Display from that page — do not look for a second, similarly named app.
  3. Create a product hazard profile with GHS pictograms and statements, then sync app-owned metafields for theme-block storefront display.
  4. In the theme editor, add the CLP Hazard Info app block to the product template. Review missing hazard fields before you publish.
