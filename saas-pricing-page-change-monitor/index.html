How is SaaS Pricing Competitor Monitor different from SaaS Pricing Tracker and B2B Pricing Scraper?

SaaS Pricing Competitor Monitor (taroyamada/saas-pricing-page-change-monitor): This Actor is a SaaS pricing competitor monitor: track plan and price page changes from competitor URLs you paste. Not the SHA256 legal-page watcher (Website Terms & Policy Scraper). Not B2B public-catalog pricing (use B2B Pricing Scraper). Not authenticated billing portals. SaaS Pricing Tracker is for Public SaaS page change rows (input targets; Public pricing/terms HTML; SaaS change rows). Not premium SHA256 legal diffs or battlecards. B2B Pricing Scraper is for Public subscription-tier changes (input competitors[]; Public pricing HTML; Pricing change rows). Not Shopify catalog maps or ads-library pages. Docs & Changelog Drift Scraper is for API docs/changelog drift (input doc URLs; Public docs HTML; Drift rows). Not legal-page SHA256 diffs.

What input is required?

Live required fields: none listed (see live fields). Published exampleRunInput is shown below.

Field Type Default Notes
pricingPageUrls any[] empty Pricing page URLs. Public pricing page URLs to inspect. Login, checkout, customer portal, or paywalled URLs are blocked with no charge.
competitors any[] empty Competitors. Optional competitor labels/domains.
watchMode boolean false Watch mode. Treat this run as a public pricing change-monitoring report.
previousSnapshotText string empty Previous snapshot text. Optional previous pricing text for change detection.
reportTier string enum entry Report tier. Choose entry or premium. Watch/audit templates are proof-gated and not selectable during public launch; maxChargeUsd is only a safety cap. enum: entry, premium
maxChargeUsd number 3 Max charge USD. Safety cap for this run. This cap always wins before charging any report group. minimum=0 maximum=100
demoMode boolean false Demo mode. Run a sample with no external fetch and no charge.
dryRun boolean false Dry run. Set true to return a no-charge previewReport with nextRunInput and estimated cost.
maxReports integer 1 Advanced max reports. Advanced. Maximum report groups to charge; maxChargeUsd is still checked first. minimum=1 maximum=25
sourceDatasetId string empty Advanced source dataset ID. Advanced only. Optional Apify dataset ID for prepared input rows. Not needed for the first run.
webhookUrl string empty Advanced webhook URL. Advanced. Optional URL to receive results outside Apify.
