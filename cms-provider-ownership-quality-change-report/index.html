How is CMS Provider Ownership & Quality Change Report different from Medicare Coverage Change Impact Report and HHS Healthcare Data Breach Change Scraper?

CMS Provider Ownership & Quality Change Report (taroyamada/cms-provider-ownership-quality-change-report): Monitor public CMS nursing-home facility snapshots for ownership and quality/rating changes, then receive source-linked alerts, portfolio reports, and optional exports. Not Medicare NCD/NCA coverage. Not HHS breach submissions. Not NIH RePORTER awards. You supply state/facility watches. Medicare Coverage Change Impact Report is for CMS NCD/NCA coverage (input watches; CMS coverage records; Coverage-change alerts). Not nursing-home ownership/quality. HHS Healthcare Data Breach Change Scraper is for HHS breach submissions (input terms; HHS breach portal; Breach-change rows). Not CMS facility ratings. NIH RePORTER Funding Landscape Report is for NIH award landscape (input org / terms; NIH RePORTER; Award report). Not CMS provider quality.

What input is required?

Live required fields: watches. Published exampleRunInput is shown below.

Field Type Default Notes
watches any[] [] Provider portfolio watches. Bounded recurring watches over the official CMS Provider Information and Ownership datasets. Required.
monitorKey string "cms-provider-ownership-quality-watch" Monitor key. Stable isolated state namespace for a recurring portfolio watch.
initialRunMode string enum "baseline_only" Initial run mode. baseline_only stores the first snapshot for free; emit_backfill emits current matches for an explicit first report. enum: baseline_only, emit_backfill
includeOwnership boolean true Include ownership signals. Include aggregate ownership type/role/percentage/date signals without owner names or personal fields.
includeQuality boolean true Include quality and rating fields. Include public CMS rating and facility quality fields in the normalized record.
generateReport boolean true Generate portfolio report. Generate one descriptive ownership and quality report when a new or changed facility snapshot is found.
emitRawRows boolean false Emit optional provider rows. Emit low-priced normalized facility rows in addition to the change alert.
emitExport boolean false Generate JSON export. Generate a compact source-linked export for downstream research workflows.
emitUnchanged boolean false Emit unchanged snapshots. Accepted for compatibility, but unchanged snapshots always remain zero rows and zero charge.
maxRecordsPerWatch integer 100 Maximum facilities per watch. Maximum matching provider facilities retained per watch. minimum=1 maximum=500
maxOwnershipRowsPerWatch integer 1500 Maximum ownership rows. Maximum ownership records requested per bounded facility chunk. minimum=1 maximum=1500
maxChargeUsd number 25 Maximum charge USD. Fail closed before delivery if planned PPE charges exceed this cap. minimum=0.005 maximum=250
dryRun boolean false Dry run. Return representative rows for all configured event types without CMS requests, state writes, or charges.
