How is NHTSA Recall Scraper different from Product Safety Recall Scraper and FDA Warning Letters Scraper?

NHTSA Recall Scraper (taroyamada/nhtsa-vehicle-recall-digest): This Actor watches official NHTSA recall and complaint records for vehicle feeds you supply (make/model, optional year) and emits source-linked digest rows. It is vehicle safety data, not CPSC consumer-product recalls. Not legal or safety advice. Not CPSC/FDA product recalls. Not a VIN decoder or crash-reconstruction tool. Product Safety Recall Scraper is for FDA/CPSC product recalls (input feeds / recallClasses; FDA + CPSC public recalls; product-recall rows). Not NHTSA vehicle complaints. FDA Warning Letters Scraper is for FDA warning-letter digests (input feeds / watchTerms; FDA public warning-letter feeds; warning-letter digest rows). Not ClinicalTrials.gov or HHS OCR. HTS Tariff & Trade Scraper is for HTS/USTR changes (input HTS watches; USITC/USTR public data; tariff digest rows). Not OFAC SDN list diffs.

What input is required?

Live required fields: none listed (see live fields). Published exampleRunInput is shown below. Monitor official NHTSA recall and complaint endpoints for watched vehicle, VIN, and manufacturer feeds

Field Type Default Notes
feeds object[] empty Feeds to monitor. One digest row per watched vehicle, VIN, or manufacturer feed. Each item supports id, name, type, make, model, modelYear, modelYears, models, vin, recallLookbackDays, complaintLookbackDays, maxRecalls, maxComplaints, maxModels, complaintAlertThreshold.
recallLookbackDays integer 30 Recall lookback days. Default recall lookback window used when a feed-specific override is not set. min=1 max=3650
complaintLookbackDays integer 90 Complaint lookback days. Default complaint lookback window used when a feed-specific override is not set. min=1 max=3650
maxRecallsPerVehicle integer 50 Max recalls per vehicle. Default cap on recall evidence rows per feed. min=1 max=500
maxComplaintsPerVehicle integer 100 Max complaints per vehicle. Default cap on complaint evidence rows per feed. min=1 max=500
maxDiscoveredModelsPerFeed integer 12 Max discovered models per feed. Default cap on manufacturer model expansion before complaints and recalls are fetched. min=1 max=100
maxEvidenceItems integer 10 Max evidence items per section. Upper bound on recall or complaint items retained in each digest section. min=1 max=50
complaintAlertThreshold integer 3 Complaint alert threshold. Complaint-count threshold that escalates a digest to action_needed. min=1 max=50
delivery string enum dataset Delivery mode. dataset writes digest rows to the Apify dataset. webhook POSTs the digest payload to webhookUrl. enum: dataset, webhook
webhookUrl string empty Webhook URL. POST target used when delivery=webhook.
datasetMode string enum all Dataset mode. Choose whether delivery includes all digests, only action-needed digests, or only feeds with new evidence. enum: all, action_needed, new_only
snapshotKey string nhtsa-vehicle-recall-digest-state Snapshot key. Stable key used to persist seen recalls and complaints across recurring runs.
notifyOnNoNew boolean true Notify when nothing is new. When false, stable feeds are omitted from delivery outputs unless they errored.
requestTimeoutSeconds integer 30 Request timeout seconds. Timeout for each NHTSA API request. min=5 max=120
batchDelayMs integer 600 Delay between feeds (ms). Milliseconds to wait between feed fetches. min=0 max=10000
dryRun boolean false Dry run. Skip snapshot writes and webhook delivery while still producing local output.
nowIso string empty Override current time. ISO timestamp used for deterministic tests and reproducible proofs.

How do dataset, webhook, and dry-run delivery work?

delivery defaults to dataset on the live schema. Dataset output is the billable surface when rows are written. webhookUrl is used when delivery is webhook (and typically not during dryRun). dryRun true validates or samples without the usual dataset/webhook side effects described on the Store schema. datasetMode can limit emits to changes_only / changed_only / action_needed versus all. Unchanged runs that write zero default-dataset rows typically charge $0.00 on current PPE.
