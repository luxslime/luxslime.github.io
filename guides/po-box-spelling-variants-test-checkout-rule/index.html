PO box rule test list

PO box spellings and look-alike street names: test your Shopify billing rule before you publish

Direct answer. A PO box rule fails in two ways: it misses a spelling such as Post Office Box or a bare “Box 12”, or it stops a real street such as Boxwood Road. Write a short list of both kinds, run each address through the AddressFence simulator before you publish, and use one-click rollback if a published rule stops a real customer.

AddressFence: PO Box Billing (Shopify App Store) adds billing-address rules to Shopify checkout, including a PO box block and a required street number, and lets you test any address in the simulator before publishing. This page is a test list, not a description of every pattern the app recognises: the simulator result is what counts.

Install AddressFence: PO Box Billing

Why test spellings and look-alikes

Customers write a PO box many ways, and real streets can share the same letters. Shopify’s built-in, no-code checkout settings cover the shipping address only, so the billing line is where your own rule has to hold up. See why built-in rules do not reach billing.

Run it

  1. Write the expected result for each line before you test.
  2. Run every line through the simulator for a billing address and mark any mismatch.
  3. Adjust the rule, test again, and only then publish.
  4. After publishing, place one test order for a blocked and an allowed address.
  5. If a rule stops a real customer, roll it back with one click, fix it, and re-test.

Keep it short

Ten to twenty lines catch most surprises. Keep the list in your store notes and re-run it after any rule change.
