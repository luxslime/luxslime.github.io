PO rule live preview

Preview any PO rule against a sample number before you publish - do not learn the regex on a live company cart

B2B PO Guard - Require PO (Shopify App Store) validates purchase-order numbers by format, prefix, regex, length, and uniqueness, and previews any PO rule live against a sample number before you publish. D2C and no-company checkouts stay untouched. Checkout enforcement runs on Plus B2B; PO rules work on every plan. This page is not legal advice.

Build the rule, preview a sample, then publish

Format, prefix, regex, length, and uniqueness are easy to get wrong on the first try. Run the live preview against a sample number that should pass and one that should fail before the rule goes live. That preview job is separate from the require-PO how-to and from D2C no-op testing after publish.

Install B2B PO Guard -> preview rule -> publish

Sequence

  1. Set the PO validation rule (format, prefix, regex, length, uniqueness as needed).
  2. Preview the rule live against sample numbers before you publish.
  3. Publish, then confirm company checkout enforcement.
  4. Confirm a D2C cart remains untouched.
