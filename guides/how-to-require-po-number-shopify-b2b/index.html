How to require a PO number on Shopify B2B checkout

Direct answer. You do not need to write a Shopify Function or Cart and Checkout Validation Function to require a purchase-order number on B2B checkout. Install B2B PO Guard – Require PO (App Store: b2b-terms-guard), create one live PO rule that rejects blank or malformed PO numbers in the in-app live preview, then publish. D2C and no-company checkouts stay untouched.

Why merchants ask this

Wholesale buyers often finish checkout without a PO, then finance chases a number that never existed. Search demand for “require PO number Shopify B2B” and “Shopify B2B purchase order required” stays high because native Net Terms alone do not validate the PO field. This page is the merchant how-to for requiring that number — not the format-regex sibling and not deposit routing.

Steps — require a PO number with B2B PO Guard

  1. Install B2B PO Guard from the Shopify App Store (handle: b2b-terms-guard).
  2. Open the PO rules screen and create a rule that requires a non-empty PO number on B2B company checkout.
  3. Use live preview with a sample number you expect from buyers (and with a blank sample) before you publish.
  4. Publish the one live rule on the free plan. Confirm a B2B company checkout asks for the PO and a D2C cart still completes without it.
