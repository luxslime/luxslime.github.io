SDS link vs hazard display

An SDS download link is not CLP hazard display — show pictograms and statements on the product page

CLPLens: CLP Hazard Display (Shopify App Store) records CLP hazard display data, syncs app-owned product metafields, and shows storefront hazard information with audit records. Create product hazard profiles with GHS pictograms and statements, sync metafields for theme-block storefront display, and review missing hazard fields before publishing product pages. This page is not legal advice.

A PDF link is a different surface than on-page hazard elements

Many product pages link to a Safety Data Sheet. Distance-sales hazard communication is a different job: the shopper needs pictograms and statements on the offer, not only a file they may never open. Put a structured hazard profile on the product page via metafield sync to a theme block, and review missing fields before you publish.

How to replace “SDS only” with on-page hazard display

  1. Create a product hazard profile with GHS pictograms and statements.
  2. Sync app-owned metafields to a theme block on the product page.
  3. Review missing hazard fields before you publish the page.
  4. Keep audit records of the hazard display data you publish.
