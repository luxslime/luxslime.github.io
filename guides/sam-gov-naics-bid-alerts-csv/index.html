Can I get SAM.gov NAICS bid alerts as CSV without writing the API client?

Yes. The US lane calls the official SAM.gov opportunities search API (api.sam.gov/opportunities/v2/search). You pass naicsCodes (comma-separated; live default 541512,541519), jurisdictions us, and a SAM.gov API key from Account Details. After Start, export the default dataset as CSV. You do not build or host that HTTP client yourself.

Do I need a SAM.gov API key for NAICS alerts?

Yes. samApiKey is required for the US lane. If us is present without a key, the run warns and skips SAM.gov instead of failing the whole job, which can emit zero rows and zero charges. The key comes from SAM.gov Account Details. This page is not a Grants.gov-only or TED-only first run.

Which NAICS codes does the first run use?

Live schema default for naicsCodes is 541512,541519 (optional SAM.gov NAICS filters). Replace those codes with the codes you actually bid. keywords still go to SAM.gov titles. minValue defaults to 100000 and can empty a first queue — lower it or widen NAICS before raising maxItemsPerSource.

What does a first NAICS CSV run cost?

Live pay-per-event is $0.008 per delivered procurement opportunity or alert row ($8.00 / 1,000). There is no live start charge. One US source × maxItemsPerSource 1 ≈ $0.008 if one row delivers. An empty queue emits zero rows and zero charges. Leave generateReport and emitExport false ($5 report / $7 export).

Does this scrape the SAM.gov website?

No. It searches the official opportunities API. It is not a scrape of SAM.gov HTML, not a custom REST client you maintain, and not Google News RSS. NAICS filters apply to the US federal opportunity lane only. TED CPV filters are a different field (cpvCodes).

Are empty NAICS queues billed?

No. An empty result emits zero rows and zero charges. A missing SAM.gov key skips the US lane with a warning. Keep maxItemsPerSource at 1 until a source-linked row looks useful, then raise the cap.

Does this CSV include TED CPV tenders?

Not on this page’s US-only first input (jurisdictions us). CPV codes filter TED. Combined TED + SAM deadlines in one queue belong on the TED and SAM bid-desk guide. Grants.gov is an additive lane (jurisdictions grants), not a NAICS filter.
