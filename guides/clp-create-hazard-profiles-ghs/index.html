CLP hazard profiles

A theme paste is not a CLP hazard profile — build GHS pictograms and statements first

Direct answer. Shopify Admin has no built-in CLP / GHS hazard profile editor — you can paste pictogram images into the theme, but nothing creates a structured product hazard profile with GHS pictograms and statements you can review before publish. CLPLens creates product hazard profiles with GHS pictograms and statements, then syncs app-owned metafields for theme-block storefront display and keeps audit records.

CLPLens: CLP Hazard Display (Shopify App Store) creates product hazard profiles with GHS pictograms and statements, syncs app-owned metafields for theme-block storefront display, reviews missing hazard fields before publishing product pages, and keeps audit records. The app does not classify mixtures or write the SDS. This page is the profile-creation slice — not metafield sync, missing-fields, SDS≠display, or UFI. This page is not legal advice.

Profile first, then storefront

Missing-fields review and metafield sync assume a profile exists. Building the GHS pictogram and statement set is the prior job.

Install CLPLens: CLP Hazard Display, create CLP hazard profiles with pictograms and statements, review missing fields, then confirm the live product page.

How to create a CLP hazard profile

  1. Create a product hazard profile with the GHS pictograms and statements you already have from classification / the SDS.
  2. Review missing hazard fields before you publish.
  3. Sync app-owned product metafields when the theme block should read them.
  4. Confirm storefront hazard information on the live product page and keep audit records.
