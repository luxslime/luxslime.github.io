Shopify collaborator vs staff

A collaborator account is a Partner login, not a staff account

Direct answer. A collaborator account is a Shopify Partner login you allow into the store: they request access with a request code you share, you approve what they can do, and access expires if they have not logged in within 90 days. A staff account is a store user you add in Shopify admin and assign a role; Help Center documents Actions > Suspend and Actions > Remove for those users. Collaborators don’t count towards your store’s user limit. Collaborator access is ended with the remove steps on the collaborator article. Read Collaborator accounts and Managing users. This page does not name subscriptions.

Staff Access Audit Guard (Shopify App Store · Write a review) reviews installed-app access and granted scopes, staff access records, and ownership evidence, without reading customer or order bodies. It does not create staff users, approve collaborator requests, rotate the request code, or remove anyone. This page is the account-type difference — not the request-code steps and not a permissions score.

Checklist: which account you are looking at

  • Partner, freelancer, or agency asking to work on the store: collaborator request, not a staff invite. The code gate is Shopify collaborator request code.
  • Employee who should have a role you assign: a user you add under Settings > Users. Roles are on Managing users.
  • Confirm the request code is the current 4-digit code under Settings > Users > Security before a Partner submits a request.
  • If a collaborator has not logged in for 90 days, Help Center says access expires. That clock is 90-day collaborator expiry, not staff Suspend.
  • Ending access: staff Suspend or Remove is documented on Managing users from your Shopify admin. Collaborator removal is documented on the collaborator article. Do not assume one menu item works for both.

Who the account is for

Collaborator accounts says collaborators are Shopify Partners you have allowed to access your store or organization. They sign in from their Dev Dashboard or the Shopify mobile app. Managing users says you add staff members by creating user accounts and assigning roles with the permissions they need. The same overview says you can also add collaborator accounts for Partners and use permissions to control which sections they can access. A Partner who needs something a collaborator account cannot do may ask for a staff account instead; Shopify’s Working on client stores describes that as the exception, and it says using a merchant’s password is prohibited.

Request code, permissions, and the 90-day limit

The collaborator article says you must give the Partner a request code, and the Partner must enter that code when they submit a request. Only Partners you share the code with can request access. The code is a 4-digit code in Settings > Users > Security. Generating a new code stops older codes from working. The request-code path is Shopify collaborator request code.

Roles managed by Shopify says the Collaborator access role is assigned inside a Partner organization, and that you control what a collaborator can do on your store through collaborator account permissions. Staff permissions are the roles you assign on the user. Those are different permission records. A reading list for staff roles is Staff permissions audit checklist.

The collaborator article says that if a collaborator has not logged into the store within 90 days, access automatically expires. You can reinstate it from the user account with Actions and Reactivate user. Help Center does not describe that 90-day expiry as the way a staff account ends.

Removal is a different control

For users you manage as staff, Managing users from your Shopify admin documents Actions > Suspend (the user cannot log in, and you can Reactivate later) and Actions > Remove (permanent). For a collaborator, the collaborator article documents a permanent remove that you cannot undo; the person must send a new collaborator request if they need access again. Their name can still appear on timelines such as the store activity log. Help Center does not tell you to Suspend a collaborator the way you Suspend a staff user. The error merchants see when they try is walked on Cannot suspend a Shopify collaborator.

Collaborators don’t count toward the store’s user limit. How many staff users a store can add is a subscription question. This page does not name plans. Read Managing users for the limit that applies to your store.

What this page is not

  • Not a security attestation, and not a statement that either account type is safe by itself.
  • Not the request-code walkthrough. That URL is Shopify collaborator request code.
  • Not the 90-day Reactivate steps. That URL is Shopify collaborator access expired after 90 days.
  • Not a subscription comparison. User limits that depend on the store are left to the Help Center page.
