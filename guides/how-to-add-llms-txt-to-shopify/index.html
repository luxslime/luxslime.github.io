How to add llms.txt to Shopify

Add llms.txt on Shopify by confirming the managed URL, then a theme template if you need different text

Direct answer. Merchants can expose an llms.txt file, and related agent files, for AI crawlers. On Shopify Online Store, shopify.dev says /llms.txt is an alternate URL for /agents.md and that Shopify manages it by mirroring /agents.md unless you add a theme template. The 28 May 2026 changelog says stores already include those paths and that you add templates/llms.txt.liquid only when that URL should differ. A catalog-readiness app can review whether the file and product data are present; it is not a second way to publish the theme file. Confirm the live shopify.dev pages. This is not a claim that every sales channel serves the same URL, and it is not a ranking promise.

Agentic Catalog by momiji (Shopify App Store) checks llms.txt and robots.txt rules for GPTBot, ClaudeBot and PerplexityBot, audits Product JSON-LD and Open Graph completeness on live product pages, and reviews policy, shipping, tax, domain and product data in one readiness score. It does not edit theme templates and it does not publish llms.txt for you. This page is how the URL gets onto the store — not the agents.md.liquid lookup walkthrough.

Free check first: Product JSON-LD field checker runs in your browser and sends nothing. Paste product JSON-LD and see which merchant-listing fields are present or missing.

Checklist: expose llms.txt without inventing a host

  • Open https://your-store-domain/llms.txt and see whether Shopify is already serving the managed file. shopify.dev says that is the default.
  • If the managed text is enough, do not add a template. shopify.dev says the llms.txt.liquid template is not included in themes by default for that reason.
  • If /llms.txt must say something different from /agents.md, add templates/llms.txt.liquid under Online Store > Themes > Edit code. The template steps and lookup order are on Customize Shopify agents.md and llms.txt.
  • If you want one custom file for /agents.md, /llms.txt, and /llms-full.txt together, shopify.dev says to edit agents.md.liquid instead of a separate llms file.
  • Use an app to review catalog readiness signals (the file, crawler rules, product JSON-LD). Do not treat that review as the theme template.

What shopify.dev says the store already serves

The changelog dated 28 May 2026 says a store includes a default agents.md at /agents.md, and that /llms.txt and /llms-full.txt point at that content by default. The llms.txt.liquid doc says /llms.txt is an agent-discovery file and an alternate URL for the canonical /agents.md. For most stores, that managed file is the file. This page does not describe an app proxy, a redirect, or a file upload in Content as the documented path. If a Help Center page later describes a different admin control, that page controls.

Theme template, when the default is not the text you want

shopify.dev says you add a Liquid template under the theme’s templates directory. llms.txt.liquid controls /llms.txt only. agents.md.liquid is the fallback for the llms URLs when a dedicated template is absent. The lookup order, the agents object, and what not to hardcode are on Customize Shopify agents.md and llms.txt. This page does not repeat that template reference.

Product JSON-LD on the product page is a different file from llms.txt. Which fields to check is Shopify Product JSON-LD.

An app can review readiness signals

A second path is an app that publishes catalog readiness signals: whether llms.txt is present, how robots.txt treats AI crawlers, and whether live product pages have Product JSON-LD and Open Graph. Agentic Catalog by momiji is that review. It does not replace llms.txt.liquid and it does not claim a crawler will read the file. If shopify.dev is the source for how the URL is served, the app is the source for a recurring check of the signals around it.

What this page is not

  • Not a ranking, inclusion, or AI-shopping promise.
  • Not the theme-template reference. That URL is Customize Shopify agents.md and llms.txt.
  • Not a claim that Shopify Help Center names a single “add llms.txt” button. The sources above are shopify.dev. If Help Center disagrees, follow Help Center.
  • Not product JSON-LD. That URL is Shopify Product JSON-LD.
