How to use SaaS Pricing Competitor Monitor in Make

SaaS Pricing Competitor Monitor (taroyamada/saas-change-monitor-actor) runs inside Make through Apify’s official module. Connect with OAuth or an API token, add Run an Actor (short proof) or trigger Watch Actor Runs (scheduled Console runs), then Get Dataset Items and map status, changed, and changeSummary into Sheets or Slack. Store listing: $1.00 / 1,000 saas change rows. No API key or login is required on the watched public pages.

What this scenario does

Make starts or watches a pricing/terms/features page monitor, then exports change rows (initial, changed, or unchanged) with hashes and added/removed line counts. It is public-web only. It does not log into vendor portals.

Connect Apify to Make

Steps match Apify’s Make integration doc read on 2026-10-30.

  1. In a Make scenario, search for Apify and add a module.
  2. Open Connection. Prefer OAuth, or paste an Apify API token from Console Settings → API & Integrations.
  3. Save the connection.

Synchronous path (first baseline)

  1. Add Run an Actor. Select taroyamada/saas-change-monitor-actor.
  2. Set Run synchronously to Yes only when the run fits Make’s plan timeout; otherwise use Watch Actor Runs.
  3. Override input with one public pricing target and datasetMode all so the first baseline row is delivered.
  4. Add Get Dataset Items. Map Dataset ID from the Run module.
  5. Map name, status, changed, and preview into Google Sheets or Slack.

Suggested Input override (Store example shape):

{
  "targets": [
    {
      "id": "notion-pricing",
      "name": "Notion Pricing",
      "kind": "price",
      "url": "https://www.notion.so/pricing",
      "includePatterns": ["price", "free", "business", "enterprise"],
      "excludePatterns": ["cookie", "login"]
    }
  ],
  "requestTimeoutSeconds": 30,
  "maxChars": 25000,
  "delivery": "dataset",
  "datasetMode": "all",
  "notifyOnNoChange": false,
  "snapshotKey": "saas-change-make-first-run",
  "dryRun": false
}

Asynchronous path (scheduled watches)

  1. Schedule the Actor in Apify Console (daily/weekly) with datasetMode changes_only after the baseline exists.
  2. In Make, add trigger Watch Actor Runs for this Actor (Succeeded).
  3. Add Get Dataset Items using the trigger’s default dataset ID.
  4. Optional: filter items where changed is true before Slack notify.

Webhook delivery is also on the listing (delivery webhook + webhookUrl). Prefer dataset + Watch Actor Runs for Make until the payload shape is approved.

Not this path

  • Not authenticated vendor portals or PDF-only contract hosts.
  • Do not invent unpublished target fields beyond the Store schema (id, name, kind, url, patterns, maxChars).
  • Not Website Content Extractor (one-shot page markdown) — this Actor compares snapshots over time.
  • Never edit the Actor on Apify from this guide; read-only Store usage only.
