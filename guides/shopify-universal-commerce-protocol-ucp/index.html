Shopify Universal Commerce Protocol

UCP is the open standard ucp.dev describes. Shopify’s agents docs say its MCP tools implement it

Direct answer. ucp.dev titles the Universal Commerce Protocol “The common language for platforms, agents, and businesses” and says UCP provides building blocks for agentic commerce across industries, from discovery to checkout and beyond, so the ecosystem can operate through one standard, without custom builds. The same site says UCP is an open standard for AI agents, apps, businesses, and payment providers, and that its capabilities include Catalog Search and Lookup, Cart Building, Identity Linking, Checkout, and Order Management. shopify.dev/docs/agents is headed “Build commerce agents with UCP” and says Shopify’s MCP tools implement UCP at every step of the buyer journey: negotiate and authenticate, discover products, carts and checkout, and monitor orders. This page does not claim a rank, a sale, or inclusion in any agent.

  • Read ucp.dev for what the protocol says it is. Do not add a rank or a sales result the site does not state.
  • Read shopify.dev/docs/agents for how Shopify says its MCP tools implement UCP. That page is written for people building agents.
  • Merchant controls for sharing products with AI channels are Shopify agentic storefronts.

  • A readiness scan of the catalog you already publish is Agentic catalog readiness. It is not a UCP specification.

What ucp.dev says

The home page heading is “Universal Commerce Protocol.” The subheading is “The common language for platforms, agents, and businesses.” The description under that heading says: “UCP provides building blocks for agentic commerce across industries—from discovery to checkout and beyond—allowing the ecosystem to operate through one standard, without custom builds.”

Further down, the site says: “UCP is designed to facilitate the entire commerce lifecycle, from discovery and search to final sale and post-purchase support. The protocol supports a range of core capabilities, including: Catalog Search and Lookup, Cart Building, Identity Linking, Checkout, and Order Management.” The get-started section says: “UCP is an open standard designed to let AI agents, apps, businesses, and payment providers interact seamlessly without needing custom, one-off integrations for every connection.”

What shopify.dev/docs/agents says

The page heading is “Build commerce agents with UCP.” The introduction says: “Build unified agentic experiences that securely act on behalf of buyers with the Universal Commerce Protocol (UCP) and Shopify’s UCP-compliant MCP servers.”

Under “Understand how Shopify does UCP,” the page says: “Shopify’s MCP tools implement UCP at every step of the buyer journey.” It then lists: “Negotiate and authenticate: Identify your agent and get the right access tier.” “Discover products: Search across hundreds of millions of Shopify listings.” “Carts and checkout: Build carts, convert them to checkouts, and hand off to the merchant for payment.” “Monitor orders: Receive order webhooks and fetch fresh order state on demand.” Those sentences describe the agent workflow on that docs page. They are not a statement that a given store will be found, ranked, or sold.
