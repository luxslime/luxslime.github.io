How to use Apple Podcasts Chart Tracker with Python

Direct answer. To scrape Apple Podcasts top charts with Python, install apify-client, call Actor taroyamada/apple-podcast-chart-tracker with a storefront country list (start with ["us"] and a small limit), then iterate the run dataset for rank, show title, artist/network, show id, and source URL. No Apple API key or login is required; leave movement reports off until a one-country snapshot succeeds.

What this script does

Python fetches public Apple Podcasts / iTunes Top Podcasts chart JSON for storefront countries you list, then prints rank rows. Leave movement reports off until a snapshot succeeds. It is not Apple Podcasts Scraper search and not the reviews monitor.

Install and authenticate

  1. pip install apify-client
  2. Export APIFY_TOKEN from Console Settings → API & Integrations. Do not commit the token.

Minimal first-run script

import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])

run_input = {
    "countries": ["us"],
    "limit": 1,
    "generateMovementReport": False,
    "delivery": "dataset",
    "dryRun": False,
    "maxChargeUsd": 0.05,
}

run = client.actor("taroyamada/apple-podcast-chart-tracker").call(run_input=run_input)
print(f"dataset: https://console.apify.com/storage/datasets/{run['defaultDatasetId']}")

for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

After the snapshot works

Raise limit (max 200) or add more countries (max 20) only after one row is useful. Movement reports: set a stable monitorKey and generateMovementReport true — the listing charges $2.5 per delivered movement report. Keep maxChargeUsd low until you intend that charge.
