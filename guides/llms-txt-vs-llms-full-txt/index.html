llms.txt vs llms-full.txt

llms.txt is the proposal. llms-full.txt is not in it. Shopify serves both as copies of /agents.md until you split them

Direct answer. llmstxt.org publishes a proposal, “The /llms.txt file, v2” (published September 3, 2024; modified August 10, 2026), for a Markdown file named llms.txt. The live page does not mention llms-full.txt. Outside that proposal, llms-full.txt is a common file name for a single file that holds the full content. On Shopify, the 28 May 2026 changelog says the store includes a default agents.md at /agents.md, and that /llms.txt and /llms-full.txt also point to this content by default. The llms.txt.liquid and llms-full.txt.liquid docs say each URL mirrors /agents.md until a dedicated template makes that URL diverge. This page does not claim that any AI system reads or ranks these files.

Checklist before you treat the two URLs as different files

  • Read the live llmstxt.org format. The page checked for this guide does not define llms-full.txt.
  • Read the 28 May 2026 changelog and the three template pages linked below. They are the Shopify statements this page uses.
  • Open /agents.md, /llms.txt, and /llms-full.txt on the store. Until a template splits them, Shopify says they point at the same content.
  • The template lookup order is on customize agents.md and llms.txt. This page does not repeat that table.
  • A robots.txt rule is a different file. That page is Shopify robots.txt and AI crawlers.

What llmstxt.org says the file contains

The proposal says it is a Markdown file named llms.txt, at /llms.txt or at a subpath. A file following the spec contains, in order: an optional byte-order mark; an H1 with the name of the project or site, which is the only required section; a blockquote with a short summary of the project, containing key information necessary for understanding the rest of the file; zero or more markdown sections of any type except headings, with more detailed information; and zero or more markdown sections delimited by H2 headers, containing “file lists” of URLs where further detail is available. Each file-list item is a markdown hyperlink [name](url), then optionally a colon and notes. The page says the “Optional” section is used, by convention, for secondary information. The proposal describes the file as information to help agents use a website. That is the proposal’s statement. It is not a claim that a named AI system reads or ranks a store’s file.

What Shopify says the two URLs serve

The changelog dated May 28, 2026 says: “Your store includes a default agents.md file accessible at /agents.md. The paths /llms.txt and /llms-full.txt also point to this content by default.” It says you add a template under Online Store, Themes, Edit code to serve different content per path: templates/agents.md.liquid controls /agents.md and is the default for the other two paths; templates/llms.txt.liquid controls /llms.txt only; templates/llms-full.txt.liquid controls /llms-full.txt only. If no template is present for a given path, it falls back to the agents.md template, then to the Shopify-generated default.

The llms.txt.liquid page says /llms.txt is an agent-discovery file and an alternate URL for /agents.md, which is the canonical agent-discovery document, and that by default Shopify manages /llms.txt by mirroring the content of /agents.md. It says to add llms.txt.liquid only when /llms.txt needs to diverge from /agents.md. A dedicated template takes precedence for /llms.txt only, while /agents.md and /llms-full.txt are unaffected. The llms-full.txt.liquid page says the same mirroring for /llms-full.txt, and that a dedicated llms-full.txt.liquid takes precedence for that URL only, while /agents.md and /llms.txt are unaffected. The agents.md.liquid page says agents.md is the canonical agent-discovery document, and that the two llms URLs are alternate URLs that mirror /agents.md by default.

llms.txt, agents.md, and robots.txt

  • llms.txt is the proposal’s curated Markdown file. On Shopify it is an alternate URL for /agents.md until you add llms.txt.liquid. See how to add llms.txt.
  • agents.md is Shopify’s canonical agent-discovery document. Customizing it is the template guide.
  • robots.txt is the access file for automated crawlers. It is not an llms.txt. See Shopify robots.txt and AI crawlers.

Agentic storefronts, which Shopify Help describes as a sales channel, are a separate control. Catalog readiness checks are crawler rules and product JSON-LD.
