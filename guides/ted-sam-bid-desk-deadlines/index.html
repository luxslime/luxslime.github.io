Can TED and SAM deadlines sit in one CSV queue?

Yes. jurisdictions is a comma-separated source list: eu for TED, us for SAM.gov, grants for Grants.gov. A combined desk uses eu,us plus a SAM.gov API key. Each notice row carries deadlineAt. daysAhead keeps notices closing inside that window (live default 7). Recurring alerts include deadline_changed, status_changed, and closing_soon. Export the default dataset as CSV.

Do I need API keys for both TED and SAM?

TED-only (jurisdictions eu) needs no external key. The US lane needs samApiKey from SAM.gov Account Details. If us is present without a key, the run warns and skips SAM.gov instead of failing the whole queue — TED rows can still deliver. grantsApiKey is optional for Grants.gov.

How do CPV filters differ from NAICS filters?

cpvCodes (live default 72000000,72220000) are optional TED CPV filters. naicsCodes (live default 541512,541519) are optional SAM.gov NAICS filters. keywords go to TED titles, SAM.gov titles, and Grants.gov queries. watchTerms highlight buyers or incumbents in summaries without changing upstream queries. NAICS-only CSV: SAM.gov NAICS bid alerts.

What deadline fields are in the CSV?

Notice rows include source, noticeId, title, buyer, deadlineAt, estimatedValue, signalTags, lanePriority, and recommendedAction. meta.executiveSummary reports queue size, top buyers, and overallStatus (stable, watch, or action_needed). Starter samples still return alerts: [] on a first queue; recurring runs add deadline and closing-soon events.

What does a first combined queue cost?

Live PPE is $0.008 per delivered procurement opportunity or alert row ($8.00 / 1,000). No live start charge. First proof: TED-only, maxItemsPerSource 1 ≈ $0.008 if one row delivers. Empty queues are $0. A later eu,us run still bills per delivered row. The published Store Quickstart is TED-only with maxItemsPerSource 40 (40 × $0.008 = $0.32 if all 40 deliver).

Should I turn on the $5 report on the first desk run?

No. Leave generateReport and emitExport false. Live value events are procurement summary report $5 and opportunity export $7. The cheapest desk proof is raw opportunity rows only. Raise maxItemsPerSource after the first CSV looks like a bid desk.

Is this a scrape of TED or SAM.gov HTML?

No. Schema-default endpoints are TED api.ted.europa.eu/v3/notices/search and SAM.gov api.sam.gov/opportunities/v2/search. It is not Google News RSS, not PubMed, and not page-HTML cleanup. A partial source response is never presented as complete coverage.
