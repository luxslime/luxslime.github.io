Street number at checkout

Require a street number at Shopify checkout after the Address Blocker sunset

Native address format validation cannot require a street number.

Additional address fields only appear in listed countries, and merchants cannot change which fields appear or whether they are required.

AddressFence adds a checkout-validation rule that rejects a shipping street line with no house number.

What happened to “Require street number”?

On 17 June 2026, Shopify made address format validation available to all merchants at Settings → Checkout → Checkout rules → Address format validation. The Checkout Blocks Address Blocker is deprecated and sunsets on 31 August 2026. Compatible settings migrate automatically.

Shopify Help lists “Require street number” among the Address Blocker rules that did not move: “Requiring a street number isn't supported in address format validation. You can require additional address fields in your checkout settings instead.” The same page states: “At this time, only shipping addresses are validated. Billing address fields aren't supported and can't be targeted by rules.”

Do additional address fields replace it?

Address collection preferences can replace the single Address field with Street name and Building number, plus a Neighborhood field. Those extra fields are country-specific. Merchants cannot change which fields appear or whether they are required.

They are required for Brazil, Kuwait, Panama, Peru, and the Philippines. An early-access list still shows them for Belgium, Chile, Colombia, Costa Rica, Germany, Indonesia, Israel, Mexico, Netherlands, Saudi Arabia, Spain, Taiwan, Turkey, the United Arab Emirates, and Vietnam. They are unavailable with certain accelerated checkouts (PayPal is the documented example), when address labels were renamed, or when apps read or edit address data (Checkout Blocks excepted).

Add the street-number rule back with AddressFence

  1. Install AddressFence from the App Store.
  2. Turn on the street-number rule.
  3. In the simulator, test a street line without a number (must error) and one with a number (must pass).
  4. Publish the rule to checkout validation.
  5. Use one-click rollback if the live function is wrong.

The rule checks the shipping address: “Require a street/house number on the shipping address.” This page does not claim billing coverage for street number.

Which rules are on which plan is listed on the AddressFence App Store page.

Post-sunset checklist

  1. Open Checkout rules and confirm the migrated rules exist.
  2. Test a PO Box on shipping.
  3. Test a street line with no number.
  4. If you also need billing PO Box blocking, see PO box blocker for the billing address.
