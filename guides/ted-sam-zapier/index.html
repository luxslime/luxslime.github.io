How to use TED + SAM bid alerts in Zapier

SAM.gov Scraper / TED+SAM bid alerts (taroyamada/procurement-intel-actor) connects to Zapier through Apify's official Zapier app. Use trigger Finished Actor run (or Finished task run), then search Fetch dataset items, and map notice rows into Slack, Gmail, or Google Sheets. Listing: about $0.008 for one TED opportunity with report/export off; from $8.00 / 1,000 rows. No live Actor Start charge.

What this Zap does

Zapier reacts when a Console, schedule, or Zap Run Actor run of this procurement Actor finishes, then pulls notice rows from the default dataset. The Actor searches official TED, SAM.gov, and Grants.gov / Simpler.Grants.gov notice APIs. It is not Google News discovery and not an article extractor.

Connect Apify with Zapier

Steps below match Apify's Zapier integration doc read on 2026-10-30.

  1. In Zapier, create a Zap. Choose Apify as the trigger or as an action.
  2. Click Select next to Connect to Apify (or pick an existing connection).
  3. Choose the Apify account, review shared scopes, click Allow Access.
  4. Use Test Trigger so Zapier can prefill data from existing Actor runs. If you have no runs yet, start one in Apify Console, then retest.

Alert path: Finished Actor run → Slack or Sheets

  1. Trigger: Apify Finished Actor run. Select taroyamada/procurement-intel-actor (or Finished task run if you saved a task).
  2. Add search step Apify Fetch dataset items. Point it at the finished run's default dataset (from the trigger payload).
  3. Add Slack, Gmail, or Google Sheets. Map title, source, deadline, and deep link fields from each dataset item.
  4. Publish the Zap. Schedule or start the Actor in Apify Console (or from another Zap) so the Finished trigger fires.

Optional: start a TED-only proof from Zapier

  1. Action: Apify Run Actor. Select the same Actor.
  2. Fill Actor input. You may run synchronously or asynchronously. Synchronous runs have a hard 30 second timeout in Zapier; if the Actor needs longer, run async and rely on Finished Actor run + Fetch dataset items.
  3. Test the step, then publish.

Suggested first input (TED-only, one row, report/export off):

{
  "jurisdictions": "eu",
  "keywords": "cybersecurity",
  "daysAhead": 7,
  "maxItemsPerSource": 1,
  "generateReport": false,
  "emitExport": false,
  "delivery": "dataset",
  "dryRun": false
}

Add Grants.gov, then the US / SAM.gov lane with a SAM.gov key, only after one TED row is useful. Without a SAM.gov key, the Actor warns and skips the US source instead of failing the whole run.

Not this path

  • Not Google News queries or article URL extraction.
  • Not a full federal API client you host yourself — this is the Store Actor wired through Zapier's Apify app.
  • Do not invent unpublished input aliases; use the Store Input schema.
