Export Apple Podcasts search results to CSV (no API key)

Export Apple Podcasts search results to CSV without an Apple developer API key. Open Input (Try for free), keep Store live defaults, Start, then open the default Dataset and choose Download CSV. Search uses the public iTunes Search API.

What you get in that first run is a small catalog sample — show name, publisher, country, Apple collection ID, and the Apple Podcasts page URL — not chart ranks, not review text, and not audio files. What the CSV contains

Each search row is a public catalog hit (rowType sample: podcast_search_result), not a chart position and not a review. After Start succeeds, open the default Dataset and choose Download CSV (JSON is in the same view). Leave delivery on dataset for this path.

Column Meaning on search rows
collectionId Apple Podcasts collection ID (use later for reviews / charts siblings)
showName Show title from the public catalog
publisher Publisher / artist string when present
country Storefront country used for the search (prefill us)
sourceUrl Public Apple Podcasts page URL
fetchedAt Fetch timestamp for the row
rank Null on search rows (ranks belong on Chart Scraper)

Is the default Apple Podcasts search limit 3 or 50?

The live default and Store prefill for limit is 3, not 50. Empty or omitted limit falls back to 3. The allowed range is 1–200. Keep the first CSV export at 3, then raise limit after those rows are useful.

Do I need an Apple API key to export Apple Podcasts search results to CSV?

No. Keyword search uses the public iTunes Search API. You do not need an Apple developer key, Apple ID, proxy, or private podcast dashboard. The Actor is not affiliated with or endorsed by Apple.

Do I need an Apify account to run this export?

Yes. The run happens on Apify. Open the Actor Input, sign in or create an Apify account, then Start. After the run finishes, export the default dataset as CSV from the dataset view.

How do I download the CSV after Start?

Leave delivery on dataset. When the run succeeds, open the default Dataset and choose Download CSV (JSON is also available in the same view). Do not switch to webhook until you have reviewed the CSV columns. See webhooks only after the file looks right.

What does a first search-to-CSV run cost?

Live pay-per-event prices are Actor Start $0.005 and result $0.0025 per default-dataset item ($2.50 per 1,000 results). Search + limit 3 ≈ $0.0125 if the run writes 3 rows and charges one Start event. Actual row count can be fewer than limit.

Does this CSV include chart ranks or review text?

No. Search rows have rank null and do not include review text. This page is keyword search to CSV. Chart ranks belong on Apple Podcasts Chart Scraper. Public ratings belong on Apple Podcasts Reviews Scraper after you already have collection IDs.

What columns are in the search CSV?

Search results are source-linked dataset items. Sample rowType is podcast_search_result. Documented fields include collectionId, showName, publisher, country, sourceUrl, and fetchedAt. rank is null on search rows.
