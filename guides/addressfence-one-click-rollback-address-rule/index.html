Address rule rollback

Publish an address rule only when you can roll it back in one click

AddressFence: PO Box Billing (Shopify App Store) is a Shopify checkout-validation app for billing-address rules and street-number checks — built-in checkout rules cannot target billing at all. Test any address in the simulator before publishing, with one-click rollback. This page is the rollback job after a rule is live — not the simulator-before-publish sibling and not the billing PO-box rule itself. This page is not legal advice.

Rollback is how you recover from a published rule that blocks good orders

A billing PO-box or street-number rule that ships too wide can stop real checkouts. One-click rollback returns the storefront to the previous published state without a theme redeploy. Pair it with the simulator so you publish only after a sample address passes or fails as you expect.

Install AddressFence

How to use one-click rollback

  1. Publish a billing or street-number rule only after the simulator shows the outcomes you want.
  2. Watch live checkouts for unexpected blocks.
  3. Use one-click rollback to restore the prior published rule set immediately.
  4. Fix the rule offline, re-test in the simulator, then publish again.
