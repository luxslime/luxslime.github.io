How to import CLP hazard profiles by CSV on Shopify

Direct answer. Shopify Admin has no built-in CLP hazard-profile CSV. To import or export hazard profiles in bulk, install CLPLens: CLP Hazard Display (App Store: clp-hazard-info-display). The listing includes import and export of hazard profiles by CSV for bulk edits and audits; CSV audit exports are on the $79/mo plan (Beyond Growth). Profiles hold GHS pictograms, a signal word, and official H, EUH and P statement texts. The app records the label data you enter; it does not classify products or provide legal advice. Free is 5 products with preview-only profiles; Starter $19/mo adds metafield theme sync; $39/mo adds the gap review queue.

Why merchants ask this

Candle and cleaner catalogs often share the same pictograms and H/P codes across dozens of SKUs. Pasting each profile by hand is slow. Search interest in “CLP Shopify CSV”, “GHS pictogram product page”, and “hazard profile import” maps to this bulk job. This how-to is the CSV path — not theme-block sync and not the missing-fields gap queue.

Steps — import or export CLP profiles by CSV

  1. Install CLPLens from the Shopify App Store (handle: clp-hazard-info-display).
  2. Create at least one hazard profile in the app (pictograms, signal word, H/EUH/P codes) so you know the CSV shape, or start from an export of existing profiles on the plan that includes CSV.
  3. On the $79/mo plan, use CSV import for bulk edits and CSV export for audits. Fix any rejected rows and re-import.
  4. After import, sync metafields on Starter+ and place the theme block on product pages. Run the gap review queue on the $39/mo plan before go-live.
