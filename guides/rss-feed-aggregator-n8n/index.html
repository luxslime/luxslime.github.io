How to use RSS Feed Aggregator in n8n

Direct answer. To aggregate public RSS/Atom feed items in n8n, run Apify Actor taroyamada/rss-feed-aggregator with the community node @apify/n8n-nodes-apify (Run an Actor or Run an Actor and get dataset), then map title, link, and date into Sheets, Slack, or the next step. No API key or login is required on the feeds.

Open RSS Feed Aggregator Input on Apify Store

Last updated: 2026-10-30 (Asia/Tokyo). Integration steps verified on Apify docs and the Actor Store listing the same day.

What this workflow does

n8n pulls items from public RSS/Atom feeds you list, optionally filters by keywords, deduplicates across feeds, then passes rows downstream. It is a URL-discovery layer — not Article Content Extractor and not Website Content Extractor.

Install the Apify node in n8n

Self-hosted

  1. Open n8n → Settings → Community Nodes → Install.
  2. Enter @apify/n8n-nodes-apify, accept community-node risk, Install.

n8n Cloud

  1. Open the Canvas nodes panel → search Apify → Install node.

Authenticate

  1. Create Credential → Apify API.
  2. Paste your token from Apify Console Settings → API & Integrations.

Build the feed workflow

  1. Add Apify → Run an Actor (or Run an Actor and get dataset).
  2. Select taroyamada/rss-feed-aggregator.
  3. Set Custom input to the JSON below.
  4. If you used plain Run an Actor, add Get Dataset Items with Dataset ID = previous defaultDatasetId.
  5. Optional next step: pass link into Article Content Extractor for full body Markdown.
{
  "feedUrls": ["https://hnrss.org/frontpage"],
  "maxItemsPerFeed": 5,
  "deduplicate": true,
  "timeoutMs": 15000,
  "delivery": "dataset",
  "dryRun": false
}

Not this path

  • Not Google News query discovery — use a news Actor if you need query search.
  • Do not invent unpublished aliases such as startUrls instead of feedUrls.
  • Never edit the Actor on Apify from this guide; read-only Store usage only.
