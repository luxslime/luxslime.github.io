Article extractor first paid run

Cheapest first paid run for an article extractor

This page is the smallest useful paid run for the Article Extractor actor on Apify: one public news, blog, newsroom, or press URL, then the documented pay-per-event (PPE) add. It is not a full product FAQ. For field lists and routing, use the Article Content Extractor landing.

Live Store listing: Article Content Extractor & Reader Scraper (taroyamada/article-content-extractor). This site’s landing name is Article Content Extractor. Open the Actor: https://apify.com/taroyamada/article-content-extractor.

Documented first-paid PPE if one Actor Start event and one useful article row charge: $0.00005 + $0.008 = $0.00805. Leave the $2.50 audit report and $5.00 batch export off.

Smallest useful input JSON

The published Store Quickstart low-cost extractor input is one urls item, includeImages false, delivery dataset, and dryRun false. urls is required (maximum 300). outputFormat defaults to markdown. generateReport and emitExport default to false — omit them.

{
  "urls": [
    "https://example.com/news/example"
  ],
  "includeImages": false,
  "delivery": "dataset",
  "dryRun": false
}

Replace the placeholder URL with a public HTTP(S) article-shaped page you own or are authorized to fetch. Schema prefill on the Store is three blog.google article URLs; one URL is enough for a first paid proof. Do not send Website fields such as includeMetadata or maxChargeUsd, Google News queries, or RSS feedUrls.

What is the cheapest first paid article extractor input?

The published Store Quickstart low-cost extractor input is one urls item, includeImages false, delivery dataset, and dryRun false. urls is required. Leave generateReport and emitExport at their defaults (false). That is a paid run only when dryRun is false and a useful article row is written.

What does that first paid article extractor run cost on documented PPE?

Live events already quoted on this site’s Article Content Extractor pages: Actor Start (apify-actor-start) $0.00005, one event per GB with a minimum of one event; useful article row (apify-default-dataset-item) $0.008 for one successfully extracted or partially extracted public article row. If the run charges the minimum one Actor Start event and writes one useful row, those two events add to $0.00805. Failed or no-content rows stay out of the default dataset. Platform usage is included.

Why leave generateReport and emitExport off on the first paid run?

Those are this Actor’s published value events, not the cheapest source row. generateReport true emits one article-content-audit-report when at least one article is usable ($2.50). emitExport true emits one article-batch-export when at least one article is usable ($5.00). The live Store card is from $2,500.00 / 1,000 article content audit reports because the primary event is that $2.50 report. The cheapest first paid run keeps both flags false.

Does a dryRun count as a first paid article extractor run?

No. dryRun validates input and writes only local output — no dataset writes, webhooks, or payable rows. A first paid run needs dryRun false so a useful article row can be billed at $0.008.

How to run it

  1. Open Article Content Extractor & Reader Scraper on the Apify Store.
  2. Paste the Quickstart JSON above. Swap in one public article URL you are authorized to fetch.
  3. Keep includeImages false, delivery dataset, and dryRun false. Do not set generateReport or emitExport.
  4. Start the run. Confirm the default dataset has one article row before raising URL count or turning on value events.
