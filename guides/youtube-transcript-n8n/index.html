How to use YouTube Transcript Scraper in n8n

YouTube Transcript Scraper (taroyamada/youtube-transcript-bulk-api) runs inside n8n through Apify’s official community node @apify/n8n-nodes-apify. Install the node, authenticate with an Apify API token, choose Run an Actor (or Run an Actor and get dataset), then map fullText / segments into Sheets, Slack, or a vector store. Listing price: about $0.00255 for one video URL (Start $0.00005 + Result $0.0025); from $2.50 / 1,000 results.

What this workflow does

n8n triggers a bulk caption extract on public YouTube URLs you already have, then passes dataset rows to the next node. The Actor is HTTP-first: public caption tracks only, no browser login, no video/audio download. It is not Website Content Extractor and not a channel-analytics Actor.

Install the Apify node in n8n

Steps below match Apify’s n8n integration doc read on 2026-10-30.

Self-hosted

  1. Open your n8n instance.
  2. Go to Settings → Community Nodes → Install.
  3. Enter @apify/n8n-nodes-apify (latest), accept community-node risk, Install.

n8n Cloud

  1. Open the Canvas nodes panel.
  2. Search for Apify in the community registry.
  3. Click Install node. Instance owners must keep verified community nodes visible in Cloud Admin.

Authenticate

  1. In n8n, Create Credential → search Apify API.
  2. Paste your Apify API token from Apify Console (Settings → API & Integrations).
  3. Save. On n8n Cloud only, Apify OAuth2 API is also available.

Build the caption workflow

  1. Create a workflow. Add node → search Apify.
  2. Pick Run an Actor (or Run an Actor and get dataset if you want items in one step).
  3. Select Actor taroyamada/youtube-transcript-bulk-api.
  4. Set Custom input to the JSON below (or leave empty to use the Actor’s saved default run config).
  5. If you used plain Run an Actor, add Get Dataset Items and set Dataset ID to the previous node’s defaultDatasetId.
  6. Optional: use trigger On new Apify Event with Event Type Succeeded when a Console or schedule run finishes.
  7. Map fullText or formattedTranscript into Google Sheets, Notion, Slack, or your embed pipeline.

Suggested first Custom input (listing prefill watch URL):

{
  "videoUrls": [
    "https://www.youtube.com/watch?v=dQw4w9WgXcQ"
  ],
  "language": "en",
  "includeAutoGenerated": true,
  "outputFormat": "json",
  "delivery": "dataset",
  "dryRun": false
}

Age-restricted, private, deleted, or captionless videos return error rows instead of failing the whole run. Raise maxVideos or add playlists only after one row is useful.

Not this path

  • Not a video/audio downloader — captions only.
  • Not Website Content Extractor (page HTML) or Article Content Extractor (news/blog body).
  • Do not invent unpublished input aliases such as startUrls or captionsOnly.
