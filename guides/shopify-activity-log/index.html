Shopify activity log

Shopify has more than one activity surface, and the store activity log is view-only

Direct answer. Shopify has more than one “activity” surface. Activity logs in the Shopify admin opens: “Activity logs help you track changes and monitor user activity in your Shopify admin. The store activity log includes recent actions taken by store owners and users, whereas page activity displays when multiple users are viewing or editing the same page simultaneously.” The user management activity log records user and role changes. Login history is reviewed on each user. Each order, draft order, customer, and inventory transfer has a Timeline. Quotes below are from those Help pages, checked 12 October 2026.

Staff Access Audit Guard (Shopify App Store): “Review installed app access, granted scopes, staff access records, and ownership evidence without reading customer or order data.” It does not replace Shopify’s activity logs.

Free check first: App scope access reader runs in your browser and sends nothing.

Checklist before you treat one log as the whole record

  • Open the store activity log for recent admin actions by a person, app, or channel. It is view-only.
  • Open the user management activity log for user and role changes. It is a different page.
  • Review login history on the user. The steps live on Shopify staff login history.
  • For one order, draft order, customer, or inventory transfer, use that record’s Timeline.

Store activity log

Shopify Help: “The store activity log displays the date and time of recent actions that are taken by the store owner or a user in your Shopify admin. Each event includes the name of the person, app, or channel that took the action.”

The same section’s examples, as written:

  • Deleting a product.
  • Changing a store setting.
  • Granting store access to an app.

Considerations on that page:

  • “The store activity log is view-only. You can’t expand or click the individual events that are listed.”
  • “The information can’t be exported from the store activity log.”
  • “A maximum of 250 results can be displayed on the store activity log page. The list of actions goes back only as far as the maximum number of results.”
  • “You can’t use the store activity log to display Shopify admin actions that go back over a set number of days.” The page does not state that number of days.

Where to open it, and who can

Shopify Help: “To access the store activity log, users need to have the Home and Store settings > Manage settings store permissions.”

  1. From your Shopify admin, go to Settings > General.
  2. In the Resources section, click Store activity log.

Export and retention, in the FAQ’s words

The FAQ answer to “Can I export or download my activity log?” begins: “No, the store activity log can’t be exported or downloaded.”

The FAQ answer to “How long are activity log entries retained?” says: “The store activity log displays a maximum of 250 results. The time period this covers depends on how active your store is. Stores with frequent changes will have a shorter historical view than stores with less activity.”

This page does not add a retention period in days, an export format, or a certification. Those are not stated on the Help page quoted above.

The other surfaces

The user-activity page’s note: “This page covers the user management activity log which tracks user and role changes. For the store activity log which tracks general admin actions such as product changes and settings updates, refer to Activity logs in the Shopify admin.”

That page also says: “The user management activity log records events related to user activity. For example, when a user or user role is created, edited or deleted.” Open it from Settings > Users > Security, then View in the User management activity log section.

Login history is on the same user-activity page, and it is not the store activity log. The steps, as written: “From your Shopify admin, go to Settings > Users.” “Click the user that you want to review the login history of.” “Under Roles, click the button > View store.” “In the Recent access to store section, review the five most recent login sessions and the following information about each session:” date, IP address, ISP (internet service provider), the staff member’s location at login, and browser and operating system. The longer walk-through is Shopify staff login history.

A tip on the activity-logs page: “Each individual order, draft order, customer, and inventory transfer has their own dedicated activity log, known as a Timeline, which can be used to track the detailed history and communicate internally among users.”

Page activity is the other half of the opening sentence. Shopify Help says you can use it in Product details, Marketing, Customer details, Collection details, and Discount details, and that “This feature works only in a web browser, not in the Shopify mobile app.” The same considerations say “Page activity isn’t available in Canada” and “You can view up to 250 users on a page at one time.” That 250 is a user count on a page, not the store activity log’s result cap.

What this page is not

  • Not a retention period in days. The Help page says “a set number of days” and does not state the number.
  • Not an export, a download, or a feed into another system. The store activity log page says the information can’t be exported.
  • Not a claim that Staff Access Audit Guard reads these logs. The listing sentence does not say that.
