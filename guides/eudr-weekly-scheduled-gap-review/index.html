EUDR weekly gap review

A DDS lot registry is not a weekly gap review — missing supplier, country, or DDS fields still slip

Direct answer. Shopify Admin has no weekly scheduled review that flags missing EUDR supplier, country, or DDS reference fields on product-linked lots — you can open each product by hand, but nothing schedules that gap pass. EUDR Records Manager runs a weekly scheduled gap review that flags missing supplier, country, or DDS fields.

EUDR Records Manager (Shopify App Store) keeps a supplier and commodity-lot registry with DDS reference numbers per product, runs a weekly scheduled gap review that flags missing supplier, country, or DDS fields, and keeps a full audit trail of supplier, lot, document, and export changes. This page is the weekly gap-review slice — not the DDS lot-registry overview or the 2026/2027 scope page. This page is not legal advice.

Registry vs weekly gap pass

Recording a DDS reference on a lot answers “what is on file.” A weekly gap review answers “what is still missing” after catalog edits.

Install EUDR Records Manager, record lot-to-DDS references per product, then run a gap review for missing fields.

How to run a weekly EUDR gap review

  1. Register supplier and commodity lots with DDS reference numbers per product.
  2. Enable the weekly scheduled gap review.
  3. Open flags for missing supplier, country, or DDS fields.
  4. Close gaps and confirm the audit trail recorded the change.
