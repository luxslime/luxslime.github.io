Prop 65 ship-to-California checkout

Ship-to-California is a checkout job — US-CA on the disclosure is not the same control

Prop 65 Warning Manager (Shopify App Store) is a Shopify app that publishes Prop 65 product-page warnings from templates citing 27 CCR §§ 25601–25607, including 2028 short-form text that names a listed chemical, and requires merchant approval before any warning goes live, with an audit log of every pick, edit and activation. The live listing does not claim IP geo-fencing, a ship-to-California checkout UI, or legal compliance. It does not decide whether a product legally requires a warning. This page is not legal advice.

Three jobs — do not conflate them

Merchants asking “show a Prop 65 warning when the shipping address is California — not only when the shopper’s IP or market looks like CA” are mixing three jobs. Only C is the checkout shipping-address trigger.

Jurisdiction, PDP/cart render, and ship-to-CA checkout are different jobs
Job What it actually is
A. Jurisdiction Attach a Prop 65 disclosure whose required jurisdictions field includes US-CA (native Disclosures / taxonomy entry types such as shopify--disclosure-us-ca-prop65-*).
B. PDP / cart render Supported themes show structured disclosures on the product page and cart. That is storefront render, not a mid-checkout shipping-address flip.
C. Ship-to-CA mid-checkout A shopper outside California enters a California shipping address. That needs a Checkout UI extension (or equivalent checkout surface) that reads shipping province/country and shows the warning. It is not solved by an IP pop-up or a “California market” alone.

Job A is the US-CA field. Job B is where native Disclosures already render. Job C is the Wisconsin-browse → California-ship case. Setting US-CA on the disclosure does not, by itself, watch the checkout shipping field. The California-only / US-CA jurisdiction page covers A and B. This page is C.

Native / platform path for ship-to-CA

Shopify does not document a no-code “show Prop 65 when ship-to is California” toggle. Start with the live product disclosures documentation:

  • Disclosures render natively on the product details page and cart.
  • To also surface them in checkout, use a Checkout UI extension that reads each product’s disclosure metaobjects.
  • display_preferences.surfaces may include product_page, cart, and checkout. A checkout surface flag is not a shipping-address trigger by itself.

A ship-to-CA trigger still has to read the buyer’s shipping address. Shopify’s Checkout UI Addresses API exposes shippingAddress (province/country, including provinceCode) on purchase extension targets. That value updates when the shipping field is committed. It is undefined when delivery is not required. Access requires protected customer data approval — confirm the live Addresses API page.

For whether your store can install a Checkout UI extension at all, check that live product-disclosures page and the Help Center. This page does not invent which Shopify plan includes Checkout UI extensions.

Product listings gained a disclosures field on 17 June 2026. That changelog is the native Disclosures date. It is not a ship-to-CA checkout control.

Honest limits

One-page versus three-page checkout layout changes do not, by themselves, create a compliant ship-to-CA trigger. Changing checkout chrome is not the same as reading the committed shipping province.

Third-party “geo” apps that only use IP (or a California market / catalog) are a different, weaker job than shipping address. A Wisconsin IP plus a later California ship-to is exactly the Community case those tools miss. Do not treat IP, GPS, or “California market” as a substitute for shippingAddress.

This page does not invent a native Admin switch that Shopify does not document. If you need job C, plan a Checkout UI extension (or equivalent checkout surface) against the live Addresses API — then confirm it on a real checkout with a non-CA browse and a CA ship-to.

Use Prop 65 Warning Manager for the product-page short-form + approval + audit trail you still need regardless of checkout. That is jobs you can document on the PDP. It does not replace job C. The listing does not claim IP geo-fencing or a ship-to-CA checkout UI. This page does not claim that the app reads checkout shipping address.
