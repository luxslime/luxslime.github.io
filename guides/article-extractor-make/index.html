How to use Article Content Extractor in Make

Article Content Extractor (taroyamada/article-content-extractor) runs inside Make through Apify’s official module. Connect with OAuth (recommended) or an API token, add Run an Actor, then Get Dataset Items, and map articleText (Markdown by default) into Sheets or your RAG store. For long runs past Make’s sync timeout, use Watch Actor Runs instead. Listing: about $0.008 per useful article URL; from $8.00 / 1,000 useful rows.

What this scenario does

Make starts a bounded HTML cleanup on public news, blog, newsroom, or press URLs you already have, then writes headline, byline, date, and Markdown body into the next module. It is not Google News discovery and not a full-site crawler. Docs and help-center pages belong on Website Content Extractor.

Connect Apify to Make

Steps below match Apify’s Make integration doc read on 2026-10-30.

  1. In a Make scenario, search the module bar for Apify and add a module.
  2. Open Connection. Prefer OAuth. Or paste an Apify API token from Console Settings → API & Integrations.
  3. Save the connection.

Synchronous path (short runs)

  1. Add Run an Actor. Select taroyamada/article-content-extractor.
  2. Set Run synchronously to Yes only when you expect the run to finish inside Make’s plan timeout. If it may exceed the timeout, use the async path below.
  3. Override input JSON with one public article URL (leave generateReport / emitExport false).
  4. Add Get Dataset Items. Map Dataset ID from the Run module’s default dataset variable.
  5. Map articleText, headline, and sourceUrl into Google Sheets, Airtable, or your vector ingest webhook.

Suggested Input override:

{
  "urls": [
    "https://en.wikipedia.org/wiki/Web_scraping"
  ],
  "outputFormat": "markdown",
  "includeImages": false,
  "delivery": "dataset",
  "dryRun": false
}

Asynchronous path (long or scheduled runs)

  1. Start the Actor from Apify Console, a schedule, or another scenario.
  2. In Make, add trigger Watch Actor Runs for this Actor.
  3. Add Get Dataset Items using the trigger’s default dataset ID.
  4. Continue with the same field mapping as the sync path.

Make’s listed Apify actions also include Run a Task, Scrape Single URL, and Make an API Call; searches include Get Dataset Items. Triggers: Watch Actor Runs and Watch Task Runs.

Not this path

  • Not Google News queries or RSS feedUrls — discover URLs first, then extract here.
  • Not Website Content Extractor fields (includeMetadata, maxChargeUsd, HTML emit).
  • Failed or no-content fetches stay out of the default dataset (not billed as useful rows).
