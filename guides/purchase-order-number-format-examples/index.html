PO number format examples

Purchase-order number format: no universal pattern, buyers set their own

Direct answer. There is no universal purchase-order number format. Buyers set their own. Common patterns include a year-and-sequence string such as PO-2026-00123, a numeric-only string, and a fixed-length alphanumeric code. The regexes below are examples of those patterns, with what each accepts and rejects — not a standard anyone must use.

Common patterns buyers actually send

A purchase-order number is the buyer’s reference, so the shape follows their system, not yours. You will see strings like PO-2026-00123, a run of digits such as 4500012345, or a fixed-length mix of letters and digits such as AB12CD34. Hyphens, prefixes, year segments, and length are conventions, not a shared specification.

Requiring the field to be filled is a different job from checking that the string matches a pattern. Walk required vs empty on why a B2B checkout can skip a PO number unless a rule requires it, and walk prefix, regex, and length as checkout rules on format, prefix, regex, and length.

Example regexes: what each accepts and rejects

These patterns use JavaScript syntax with start and end anchors, the same whole-string match the PO number format tester applies. They are case-sensitive unless you turn ignore-case on. Copy only the pattern that matches the convention you actually need; do not treat the set as a catalogue of every valid PO.

Example PO number regexes
Pattern Regex Accepts Rejects
Prefix, four-digit year, five-digit sequence ^PO-\d{4}-\d{5}$ PO-2026-00123 PO-26-00123, po-2026-00123, PO2026-00123, PO-2026-123
Numeric-only, ten digits ^\d{10}$ 4500012345 450001234, 45000123456, PO-4500012345, 4500-012345
Fixed-length alphanumeric, eight characters ^[A-Z0-9]{8}$ AB12CD34 ab12cd34, AB12-CD34, AB12CD3, AB12CD345
Prefix plus six digits ^PO-\d{6}$ PO-123456 PO123456, PO-12345, PO-1234567, po-123456
Three letters plus seven digits ^[A-Z]{3}\d{7}$ ACM1234567 AC1234567, ACM-1234567, acm1234567, ACM123456

Spaces inside a number fail these patterns. A uniqueness check (the same number used twice) is not a regex; that job is a separate rule against previously used numbers.
