Why are iTunes customer-review RSS pages empty for some storefronts?

The public Customer Reviews RSS JSON is per storefront: itunes.apple.com/{country}/rss/customerreviews/id=…. A show that has US reviews often has an empty GB or JP feed. Page 2–10 of a storefront that only filled page 1 is also empty (about 50 reviews per page; iTunes cap). Empty feeds are not an API-key failure.

Does an empty storefront page create a billed dataset row?

No. Canonical delivery writes non-empty podcast_review rows (or one report row). Empty output does not issue a dataset POST. You are billed per delivered raw review ($0.003) or per report ($1.50), not per RSS request. Keep maxPagesPerPair at 1 until page 1 for that show/country actually has reviews.

What input do I pass for a cheap first review run?

Prefill × 1 page, report OFF ≈ ≤$0.15; cap $0.50. From $3.00 / 1,000 rows. Do not raise pages or add storefronts until those rows look right.

How do I skip empty pages when I add more storefronts?

Add one ISO country at a time (max 10 unique). If a pair has no reviews, you get zero rows for that pair and a possible meta.warnings entry if the request failed — successful pairs remain. Do not set maxPagesPerPair to 10 “just in case”: later empty pages are skipped for billing because they produce no rows, but they still cost fetch time. Leave generateReport false until you want one $1.50 report instead of raw rows.

Do I need an Apple API key or login?

No. The Actor reads public Customer Reviews RSS JSON only. No Apple ID, cookie, or private dashboard. You do need an account on the run platform to click Start. It is not affiliated with or endorsed by Apple. Review text is public source material; do not use it to target individual reviewers.

Does this export chart ranks or a keyword search?

No. additionalProperties is false: searchTerm, chartRequests, and lookupIds are rejected. Get collection IDs first from Apple Podcasts search Input (live default limit 3, not 50). Chart rank movement belongs on the chart-rank movement guide. This page is reviews RSS by storefront.

What columns are on a review row after CSV export?

rowType podcast_review. Fields include podcastId, country, page, reviewerName, rating, title, content, version, voteCount, updated, reviewId, sourceUrl (the RSS URL used for that row), and fetchedAt. country is the storefront you requested. Empty storefronts simply omit rows.
