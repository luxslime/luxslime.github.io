Smallest useful input JSON

Required input is reviewPageUrls. The published G2 format is g2.com/products/{slug}/reviews. Live schema prefill is https://www.g2.com/products/notion/reviews. Use that one URL for the first paid G2 check. Set reviewLimit to 1 (live schema default, prefill, minimum 1, maximum 5000). Leave delivery on dataset. Set dryRun false.

{
  "reviewPageUrls": [
    "https://www.g2.com/products/notion/reviews"
  ],
  "reviewLimit": 1,
  "delivery": "dataset",
  "dryRun": false
}

Do not add a Capterra URL on this first paid run. Mix G2 and Capterra only after this one-URL schema check. Do not send unpublished fields such as products, source, slug, maxReviewsPerProduct, or emitDeltas. There is no login, cookie, or private-review API field.

What this first run returns

A good first run gives you a per-product row with ratings and review samples, plus status / warnings when a page is thin, blocked, or structurally changed. Documented product fields include source (g2), productName, overallRating, totalReviewCount, ratingBreakdown, and nested reviews[] (title, rating, date, author, body, pros, cons, verified).

Reviews are extracted from server-rendered HTML on public G2 review pages. Blocked requests are reported honestly. This independent Actor is not affiliated with or endorsed by G2 or Capterra. Do not use the output to target individual reviewers.

What not to add yet

  • Do not add a second reviewPageUrls item until the one-URL output is useful.
  • Do not mix a Capterra URL until after this G2 schema check.
  • Do not raise reviewLimit above 1 until the nested reviews[] shape is approved.
  • Do not invent products, source, slug, maxReviewsPerProduct, or emitDeltas. They are not in the live schema.
  • Do not set delivery to webhook until the payload shape is approved.

Does a dryRun count as a first paid G2 reviews scraper run?

No. dryRun true validates input and returns scaffold output without fetching live data, so it does not write payable result rows. A first paid run needs dryRun false so a default-dataset result can be billed at $0.003.
