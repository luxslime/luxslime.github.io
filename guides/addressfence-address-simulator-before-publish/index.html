Address rule simulator

Test any address in a simulator before you publish the rule — then roll back in one click if needed

Short answer: Before you publish a PO Box rule, type a few real addresses into the simulator: one that should be blocked and one that should pass. Publish only when both results are right. If a live rule blocks good orders, roll it back in one click.

PO Box Blocker — AddressFence (Shopify App Store). Blocks PO Boxes and parcel lockers on the shipping address at checkout, with street-number and billing-address rules. Test any address in the simulator before publishing, with one-click rollback.

Free check first: PO box and street number address checker runs in your browser and sends nothing. Paste addresses and see which look like a PO box or lack a street number.

Publishing without a simulator is a different risk than shipping-only native rules

Checkout Blocks address format validation can block PO boxes on shipping and has been available to all merchants since the 17 June 2026 changelog. Shopify Help states it cannot target billing. Before you turn on a billing PO box or street-number rule, run sample addresses through a simulator so you see the block or pass result, then publish — and keep one-click rollback if a real checkout surprises you.

How to simulate, then publish

  1. Draft the billing PO box and/or street-number rule you intend to enforce.
  2. Test sample addresses in the simulator (pass and fail cases) before publish.
  3. Publish the rule for live checkout. Shipping PO Box and parcel-locker rules publish on Free; billing-address and street-number rules need a paid plan.
  4. Use one-click rollback if you need to reverse the publish quickly.
