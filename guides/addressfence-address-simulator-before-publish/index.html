Address rule simulator

Test any address in a simulator before you publish the rule — then roll back in one click if needed

AddressFence: PO Box Billing (Shopify App Store) provides billing-address rules and street-number checks for Shopify checkout — the address rules built-in validation cannot apply. Native Shopify covers PO boxes on the shipping address only. Billing PO boxes and missing street numbers need AddressFence. Test any address in the simulator before publishing, with one-click rollback.

Publishing without a simulator is a different risk than shipping-only native rules

Checkout Blocks address format validation can block PO boxes on shipping. It cannot target billing. Before you turn on a billing PO box or street-number rule, run sample addresses through a simulator so you see the block or pass result, then publish — and keep one-click rollback if a real checkout surprises you.

How to simulate, then publish

  1. Draft the billing PO box and/or street-number rule you intend to enforce.
  2. Test sample addresses in the simulator (pass and fail cases) before publish.
  3. Publish the rule for live checkout.
  4. Use one-click rollback if you need to reverse the publish quickly.
