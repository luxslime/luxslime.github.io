How to block a PO Box at Shopify checkout

Direct answer. To stop customers finishing Shopify checkout with a PO box as the shipping address, turn on address validation that checks address line 1 and line 2. Shopify’s built-in Checkout Blocks address format validation (Help Center; available to all merchants since the 17 June 2026 changelog) can block the PO box address type on shipping only — billing fields are not validated. AddressFence (App Store: address-guard) on the free plan blocks PO boxes and parcel lockers on the shipping address at checkout, plus a small set of ZIP rules; street-number checks and billing-address rules are paid upgrades. Test any address in the simulator before publishing, with one-click rollback. Free plan; Pro $9.99/mo; Plus $19.99/mo.

Why merchants ask this

Public threads keep repeating the same job: force a street address at checkout so carriers can deliver. Examples checked on 2026-10-30: Google results for “how to block PO box Shopify checkout”, Shopify Community “Validating address field and excluding PO Boxes?”, and Reddit r/shopify posts such as “Is there a way to force customers not to put a PO Box in the checkout field?”. This page is that shipping-checkout how-to — not the billing-only sibling.

Option A — Shopify native (shipping only)

Shopify Help: Settings path leads to Checkout Blocks address format validation. Use Block specific address types, select PO box, validate address line 1 and line 2, write a short error such as “Enter a street address (no PO boxes).”, save, then set the function to Active. Shopify states billing address fields are not validated by that rule.

  1. Open Apps → Checkout Blocks → Functions → Create → Address format validation (or Settings → Checkout → Checkout rules, depending on your admin).
  2. Enable Block specific address types → PO box. Add both address lines.
  3. Save as Active. Test P.O. Box, PO BOX, and Post Office Box on line 1 and line 2.

Option B — AddressFence free shipping rules

Install AddressFence from the App Store. On the free plan, turn on PO box and parcel locker rules for the shipping address; a small set of ZIP/postal rules is included. Publish only after the in-app simulator accepts real street samples and rejects the PO variants you care about. One-click rollback undoes a bad publish.

Test before you trust the rule

  • PO Box, P.O. Box, Post Office Box on line 1, then on line 2 with a street on line 1.
  • A real suite or apartment on line 2 should pass.
  • Street names that contain “Box” (for example Boxelder) should pass if your pattern is word-aware.
  • Saved addresses and Shop Pay / express paths — not only a freshly typed address.

What this page is not

  • Not “block PO box on billing” — that needs AddressFence Plus billing rules; native checkout rules cannot target billing. See billing PO box guide.
  • Not a carrier guarantee that every street address is deliverable.
  • Not a food-labelling completeness app, and not an EU repair-request tracker.
