Smallest useful input JSON

One source, maxItemsPerSource 1, delivery dataset, and dryRun false. maxItemsPerSource is the upper bound fetched per source request (schema default 40). Leave generateReport and emitExport at their defaults (false). A grants scraper run needs no required key:

{
  "jurisdictions": "grants",
  "keywords": "cybersecurity",
  "maxItemsPerSource": 1,
  "delivery": "dataset",
  "dryRun": false
}

A SAM.gov scraper run uses the same bound. samApiKey is required for the US lane. Replace the placeholder with the key from SAM.gov Account Details:

{
  "jurisdictions": "us",
  "keywords": "cybersecurity",
  "maxItemsPerSource": 1,
  "samApiKey": "YOUR_SAM_GOV_API_KEY",
  "delivery": "dataset",
  "dryRun": false
}

keywords is a documented theme sent to TED titles, SAM.gov titles, and Grants.gov queries; cybersecurity is one term from the schema default cloud,cybersecurity,IT services. If us is present without a SAM.gov key, the actor warns and skips that source instead of failing the whole run. grantsApiKey is optional. Do not send unpublished field names; live schema additionalProperties is false.

What is the cheapest first paid run for a SAM.gov scraper or grants scraper?

Why is maxItemsPerSource 1 instead of the Store Quickstart 40?

The published Store Quickstart is TED-only with maxItemsPerSource 40. If all 40 fetched items are delivered, 40 × $0.008 = $0.32. maxItemsPerSource is the upper bound fetched per source request; 1 is the smallest useful cap on that integer field. Same PPE rate; fewer row events. This page does not suggest a price change.

Does a SAM.gov scraper first paid run need an API key?

Yes. samApiKey is required for the US lane. If us is present without a SAM.gov key, the actor warns and skips that source instead of failing the whole run, which can emit zero rows and zero charges. Grants.gov is additive; grantsApiKey is optional. This Actor calls official notice APIs at https://api.sam.gov/opportunities/v2/search and https://api.simpler.grants.gov/v1/opportunities/search; it does not scrape a SAM.gov or Grants.gov HTML UI.

Does a dryRun count as a first paid SAM.gov or grants scraper run?

No. dryRun skips dataset writes and webhook delivery side effects while validating inputs. A first paid run needs dryRun false so a delivered opportunity or alert row can be billed at $0.008.

Why leave generateReport and emitExport off on the first paid run?

The live Store PPE tab currently bills only the opportunity or alert row event (apify-default-dataset-item at $0.008). generateReport and emitExport default to false. Leave them false so the first paid run is that row event only. The published README also names other report and export event titles; check the live pricing tab before treating those names as current billed events.
