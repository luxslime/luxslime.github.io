How to import EUDR supplier lots by CSV on Shopify

Direct answer. Shopify Admin has no EUDR supplier-lot CSV importer. To load supplier and commodity lots with DDS reference numbers in bulk, install EUDR Records Manager (App Store: eudr-records-manager) and use atomic CSV import: one bad row blocks the whole batch so you never get a partial write. Free includes 3 suppliers + 10 lots + DDS registry. Starter ($29/mo, or $290/year) adds hashed packs + CSV. Growth ($79/mo, or $790/year) adds weekly gap flags. The app stores records; it does not submit a DDS to the EU information system for you.

Why merchants ask this

EUDR enforcement for many operators starts 30 December 2026. Merchants with dozens of supplier lots need a bulk load path, not one row at a time in Admin. Search interest in “EUDR DDS lot”, “supplier lot CSV”, and “Shopify EUDR records” maps to that import job. This how-to is the atomic CSV path — not the weekly gap review and not the SHA-256 pack export.

Steps — atomic CSV import

  1. Install EUDR Records Manager from the Shopify App Store (handle: eudr-records-manager).
  2. Prepare a CSV with supplier, lot, production country, and DDS reference fields your registry expects.
  3. Run atomic CSV import. If any row fails validation, fix the file and re-import the whole batch — nothing partial is written.
  4. Confirm each lot shows supplier, country, and DDS reference. On Growth, turn on weekly gap flags for missing fields.
