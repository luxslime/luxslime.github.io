Street-number rule test list

Require a street number at Shopify checkout: test house-name and no-number addresses first

Direct answer. Royal Mail says some UK homes and businesses use a name instead of a street number, so a rule that requires a number in the billing address can stop a customer whose address is deliverable. Run name-only and number-after-the-name lines through the AddressFence simulator before you publish, and decide for each country you sell to whether to allow them.

AddressFence: PO Box Billing (Shopify App Store) lets you require a street number in the billing address, the Address Blocker rule that was not migrated, and test any address in the simulator before publishing with one-click rollback. This page is a test list, not a description of what the rule matches: the simulator result is what counts.

Why a number rule needs a test list

Royal Mail’s Postcode Finder help says some homes or business addresses use a name instead of a street number, and that you can use either to address mail.

Source: Royal Mail: how to search for an address or postcode. For the rule itself, see requiring a street number after the Address Blocker sunset.

Run it

  1. Write the expected result for each line before you test.
  2. Run every line through the simulator and mark any mismatch.
  3. Decide where a name-only address should pass, and adjust the rule or leave that case to manual review.
  4. Test again, then publish.
  5. Place one test order with a numbered address and one with a house name, and roll the rule back with one click if a real customer is stopped.

What this page is not

  • Not a list of every pattern AddressFence matches; use the simulator for that.
  • Not a check that an address exists or is deliverable.
  • Not carrier advice.
