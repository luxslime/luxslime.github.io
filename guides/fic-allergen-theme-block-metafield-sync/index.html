FIC theme block sync

FIC allergen display can sync through a theme block — you do not have to edit product Liquid

Direct answer. Online Store 2.0 themes let you add app blocks in the theme editor without editing Liquid templates, but wiring allergen fields yourself still means choosing metafields and placing theme code or blocks by hand. EU Food Info Guard syncs allergen display to a storefront theme block via an app-owned metafield, with no template edits.

EU Food Info Guard (Shopify App Store) detects all 14 EU Annex II allergens from ingredient text, flags an allergen your ingredients mention but your declared list omits, runs weekly completeness reviews with an audit trail, and syncs to a storefront theme block via an app-owned metafield with no template edits. This page is the theme-block metafield sync slice — not allergen detection alone, ingredient-vs-declared flags, or weekly completeness. This page is not legal advice.

Theme editor app blocks vs hand-edited Liquid

Shopify’s theme app extension model lets merchants place app blocks in the theme editor without touching Liquid files. That is different from pasting metafield Liquid into a product template yourself.

How to sync FIC allergen display without template edits

  1. Keep allergen and related FIC fields current in the app.
  2. Use the app-owned metafield sync so the storefront theme block can read them.
  3. Add the theme block in the theme editor — no product Liquid template edits.
  4. Confirm the live product page shows the allergen display from the block.
