How to use ClinicalTrials.gov Sponsor Pipeline Monitor with Python

ClinicalTrials.gov Sponsor Pipeline Scraper (taroyamada/clinical-trials-pipeline-monitor) runs from Python through the official apify-client package. Authenticate with an Apify API token, call client.actor(...).call(run_input=...), then client.dataset(run['defaultDatasetId']).list_items() for new or changed study rows. Listing: from $10.00 / 1,000 clinical trial change rows ($0.01 per delivered new or changed study row). No Actor Start. No ClinicalTrials.gov API key required.

What this script does

A short Python job starts a watchlist query against the official ClinicalTrials.gov API v2, waits for the run, and prints digest rows for new or changed studies (plus sponsor watch-terms). It is not PubMed literature watch and not a bulk historical dump Actor.

Install and authenticate

Steps below match Apify's Python client quick start read on 2026-10-30. Requires Python 3.11+.

  1. pip install apify-client (or conda install conda-forge::apify-client).
  2. Copy an API token from Apify Console Settings → Integrations (Integrations tab).
  3. Initialize ApifyClient(TOKEN). Do not ship the token in browser-side code.

Run the Actor and read the dataset

Pattern from the official quick start: actor().call(run_input=...) starts the Actor and waits; then dataset(...).list_items() reads the default dataset.

from apify_client import ApifyClient

TOKEN = "MY-APIFY-TOKEN"  # Console → Settings → Integrations

def main() -> None:
    client = ApifyClient(TOKEN)
    run_input = {
        "watchlist": [
            {
                "id": "diabetes-recruiting",
                "name": "Diabetes Recruiting Studies",
                "condition": "diabetes",
                "recruitmentStatus": "RECRUITING",
                "phase": "PHASE3,PHASE4",
            }
        ],
        "watchTerms": "Pfizer,Eli Lilly,Novo Nordisk,AstraZeneca",
        "maxStudiesPerQuery": 50,
        "delivery": "dataset",
        "datasetMode": "all",
        "snapshotKey": "clinical-trials-monitor-quickstart",
        "notifyOnNoNew": True,
        "dryRun": False,
    }
    run = client.actor("taroyamada/clinical-trials-pipeline-monitor").call(
        run_input=run_input
    )
    if run is None:
        print("Actor run failed.")
        return
    items = client.dataset(run["defaultDatasetId"]).list_items().items
    for row in items:
        print(row)

if __name__ == "__main__":
    main()

Optional: pass wait_duration (a datetime.timedelta) to call() if you want a client-side wait cap, as shown in Apify's "Pass input to an Actor" guide. Raise watchlist size only after one digest looks right. Prefer datasetMode that matches how you bill change rows on the live Store pricing tab.

Not this path

  • Not PubMed PMID packs — use PubMed Literature Watch for papers.
  • Not a browser scraper of ClinicalTrials.gov HTML; this Actor uses the official API v2.
  • Do not invent unpublished input aliases; use the Store Input schema.
