Shopify PO Boxes

Does Shopify ship to PO Boxes? Checkout can collect one; carriers decide delivery

Direct answer. Checkout can collect a PO Box, and since the 17 June 2026 changelog Checkout Blocks address format validation is available to all merchants and can block a PO box on shipping; Shopify Help names PO box among the types you can block. Whether that address receives the parcel is a carrier question: UPS’s U.S. Tariff/Terms (section 14) says UPS does not provide delivery to a P.O. Box; FedEx’s own Address Validation documentation says FedEx does not deliver to P.O. Boxes except via FedEx Ground Economy; USPS says a PO Box receives USPS mail, and Street Addressing (where offered) is how USPS describes receiving packages from private carriers that meet USPS mailing standards. Confirm each carrier’s live terms for the service you actually buy. This page is not legal advice.

AddressFence: PO Box Billing (Shopify App Store) publishes billing-address rules — built-in checkout rules cannot target billing — and a street-number check, then tests any address in the simulator before you publish. This page is the carrier-and-checkout question, not the billing-rule how-to. That job is PO box blocker for the billing address.

Free check first: PO box and street number address checker runs in your browser and sends nothing. Paste addresses and see which look like a PO box or lack a street number.

Checkout collection is not carrier delivery

A Shopify order can store a PO Box on shipping, on billing, or on both. That is an address field, not a promise that a carrier will attempt delivery. Since 17 June 2026, Checkout Blocks address format validation is available to all merchants and can block a PO box on shipping; Shopify Help names PO box among the address types you can block, and states that billing fields are not validated.

Hiding a shipping rate for a PO Box only affects whether a rate is offered. It does not decide billing, and it does not rewrite a carrier’s delivery rule. Walk that split on shipping-rate hide vs checkout validation.

Carrier PO Box rules this page can cite

Only the lines below come from the carrier’s own pages. Other carriers and other countries may differ; read the live terms for the account and service you use.

  • UPS (United States terms). Section 14 of the UPS Tariff/Terms & Conditions of Service states that UPS does not provide delivery to a P.O. Box, that the shipper must make every effort to obtain a street address, and that a package addressed to a P.O. Box may be delayed, is not covered by the UPS service guarantee, and is subject to an address-correction charge. Army Post Office (APO) and Fleet Post Office (FPO) addresses are not accepted under that section.
  • FedEx. FedEx’s Address Validation documentation states that FedEx does not deliver to P.O. Boxes except via FedEx Ground Economy (formerly FedEx SmartPost). That exception is a FedEx-stated service path, not a general “FedEx delivers to PO Boxes” rule.
  • USPS. The USPS PO Box page describes Street Addressing as an additional service (where available) that lets the box holder use the Post Office street address plus the box number so packages from private carriers such as UPS, FedEx, DHL, and Amazon can be received if they comply with USPS mailing standards. A line that still reads “PO Box” is not the same address form as that street-style option.

This page does not state a DHL, Royal Mail, or other-carrier PO Box rule. If you cannot open that carrier’s own current terms, treat delivery to a PO Box as unconfirmed.

Shipping block vs billing block

A shipping-only PO Box block can still leave a PO Box on the card billing address. Requiring shipping and billing to match is not a PO Box detector. Those jobs sit on block PO Box on billing and billing match is not a PO Box block. AddressFence is the listing this site already uses for billing-address rules.
