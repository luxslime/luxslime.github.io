Hold for review, not a checkout block

Hold a PO box ship-to billed to a commercial suite — Flow hold is not a checkout rule

Direct answer. Shopify has no documented “commercial suite” address type and no one-click hold for “ship to a PO box, bill to a commercial suite.” A checkout address blocker on shipping can stop a PO box before the order exists; that is a block, not a review hold. After the order exists, Hold fulfillment order in Shopify Flow sets the order On hold until you release it. Flow conditions can read order shipping and billing address fields — Help Center examples include order.shippingAddress.country and comparing billing country to shipping country on Conditions in Shopify Flow. Shopify’s fraud panel is a platform risk label, not your store’s address-pair policy. This page is not legal advice and not a fraud determination.

AddressFence: PO Box Billing (Shopify App Store) publishes billing-address rules — built-in checkout rules cannot target billing — and a street-number check, then tests any address in the simulator before you publish, with one-click rollback. It does not hold fulfillment and it does not detect a commercial suite. On this pattern the billing address is a commercial suite, not a billing PO box, so a billing PO box rule would not match. This page is hold-for-review after checkout — not the billing-PO-box how-to.

Free check first: PO box and street number address checker runs in your browser and sends nothing. Paste addresses and see which look like a PO box or lack a street number.

What native Shopify can and cannot do

Native Shopify can block some shipping address types, including PO boxes, with checkout address format validation / an address blocker. That control is shipping, not billing, and it prevents checkout rather than holding the order. Address collection preferences can require shipping and billing to match; that forces the two addresses to be identical and does not detect a PO box or a commercial suite — see billing match is not a PO Box block. After an order is placed, Flow can start on Order created (or Order risk analyzed), add tags, send an internal email, and Hold fulfillment. Payment-capture workflows need manual capture in admin, as Shopify documents on Capture payment.

Native Shopify cannot label an address as a commercial suite, and Help Center does not document a Flow operator named “is a PO box.” You can compare address fields Flow exposes; you still choose the text or mismatch you treat as review-worthy. Shopify’s order risk analysis is a separate Shopify assessment, not a custom ship-to / bill-to rule. A Cart and Checkout Validation function, documented on shopify.dev, returns checkout errors — again a block, not a hold.

Checklist: hold for review instead of blocking checkout

  • Decide the job: stop the checkout, or let the order in and hold fulfillment. This page is the hold path.
  • In Flow, start from Order created (or Order risk analyzed if you also want Shopify’s risk fields).
  • Add conditions on the shipping and billing address fields Flow exposes. Confirm operators on the live conditions article. Do not assume a commercial-suite detector exists.
  • Use Hold fulfillment order so the order stays On hold until a person releases it. Optionally Add order tags and send an internal email.
  • If you instead need to stop a billing PO box at checkout, that is a different surface: PO box blocker for the billing address. Test addresses in the simulator before you publish.

  • Not a claim that AddressFence holds orders or detects commercial suites. The listing is billing-address rules and a street-number check.
