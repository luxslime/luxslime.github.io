How to use Contact Details Extractor in Make

Contact Page Audit & Business Channel Extractor (taroyamada/contact-details-extractor) runs inside Make through Apify’s official module. Connect with OAuth or an API token, add Run an Actor, then Get Dataset Items, and map public business emails, phones, and social URLs into Sheets or your CRM. Pricing page: result $0.002 per default-dataset row; Actor Start $0.001 per GB (minimum one event). Store quickstart: first paid proof ≈ $0.005 for the two prefilled contact pages. No API key or login on the target sites.

What this scenario does

Make starts a bounded audit on public contact/about/support URLs you supply, then exports one structured row per page. Person-level private email candidates stay suppressed per the listing. It is not a full-site crawler and not Phone Number Validator.

Connect Apify to Make

  1. In a Make scenario, search for Apify and add a module.
  2. Open Connection. Prefer OAuth, or paste an Apify API token from Console Settings → API & Integrations.
  3. Save the connection.

Synchronous path (short proof)

  1. Add Run an Actor. Select taroyamada/contact-details-extractor.
  2. Set Run synchronously to Yes only when the run fits Make’s plan timeout; otherwise use Watch Actor Runs.
  3. Override input with the Store quickstart (two prefilled contact URLs) or your authorized contact pages.
  4. Add Get Dataset Items. Map Dataset ID from the Run module.
  5. Map email, phone, social, and source URL fields into Google Sheets, HubSpot, or Slack.

Suggested Input override (Store prefill shape):

{
  "urls": [
    "https://www.icann.org/contact",
    "https://automattic.com/contact/"
  ],
  "concurrency": 5,
  "timeoutMs": 15000,
  "delivery": "dataset",
  "dryRun": false,
  "maxChargeUsd": 0.01
}

Asynchronous path

  1. Start the Actor from Apify Console, a schedule, or another scenario.
  2. In Make, add trigger Watch Actor Runs for this Actor (Succeeded).
  3. Add Get Dataset Items using the trigger’s default dataset ID.

Not this path

  • Not Phone Number Validator (bulk E.164 format check) — different Actor.
  • Do not invent unpublished crawl fields such as startUrls or followLinks.
  • Never edit the Actor on Apify from this guide; read-only Store usage only.
