How to use Phone Number Validator in Zapier

Direct answer. To validate and normalize phone numbers to E.164 in Zapier without a carrier-lookup API key, run Apify Actor taroyamada/phone-number-validator via Apify’s Zapier app: trigger on Finished Actor run, then Fetch dataset items, and map international/national formats into Sheets or your CRM. Validation is offline libphonenumber.

Open Phone Number Validator Input on Apify Store

Last updated: 2026-10-30 (Asia/Tokyo). Integration steps verified on Apify docs and the Actor Store listing the same day.

What this Zap does

Zapier reacts when a validation run finishes, then writes structured phone rows (region, E.164, line-type signals when available, validation status) to Sheets or a CRM. It validates formats offline; it is not Contact Details Extractor (page crawl).

Connect Apify with Zapier

  1. Create a Zap. Choose Apify as the trigger or action.
  2. Connect to Apify → Allow Access.
  3. Use Test Trigger after you have at least one Console run.

Cleanup path: Finished Actor run → Sheets

  1. Trigger: Apify Finished Actor run. Select taroyamada/phone-number-validator.
  2. Add Apify Fetch dataset items for the finished run’s default dataset.
  3. Add Google Sheets (or HubSpot). Map E.164, national format, country, and validation status.
  4. Publish. Start the Actor from Console or from a Zap Run Actor step with your number list.

Optional: start a one-number proof from Zapier

  1. Action: Apify Run Actor. Select the same Actor.
  2. Prefer async + Finished trigger — Zapier sync has a hard 30 second timeout.
{
  "numbers": ["+14155552671"],
  "defaultCountry": "US",
  "delivery": "dataset",
  "dryRun": false
}

Paste up to 1–1,000 user-supplied numbers per the Store input after one row is useful.

Not this path

  • Not a live carrier HLR lookup product beyond what the listing documents for offline libphonenumber signals.
  • Not Contact Details Extractor page crawling.
  • Do not invent unpublished input aliases; use the Store Input schema.
  • Never edit the Actor on Apify from this guide; read-only Store usage only.
