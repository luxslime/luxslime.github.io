Built-in vs billing rules

Built-in Shopify checkout address rules cannot target the billing address

Direct answer. Shopify’s built-in, no-code checkout settings — shipping zones and Checkout Blocks address validation for ship-to — do not target the billing address; they apply to shipping. A Cart and Checkout Validation function (such as AddressFence) is the way to read billingAddress and return field errors on it.

Shipping rules are not billing rules

Native ship-to validation and shipping-rate hides are built-in, no-code settings. They can stop a PO box on delivery addresses. Billing is a different checkout field. When the buyer pays with a card billed to a PO box while shipping to a street address, those shipping-only settings never see the billing line. Cart and Checkout Validation functions can read billingAddress and return field errors on it; AddressFence publishes to that function path.
