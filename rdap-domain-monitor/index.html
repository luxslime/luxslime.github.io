How is RDAP Domain Expiry & Whois Scraper different from SSL/TLS Certificate Scraper and DNS Propagation Checker?

This Actor looks up domains you already have through RDAP: expiry timestamps, registrar, registrant/ownership, nameservers, change history, and expiry warnings. Required input is domains (maximum 500). Store ID taroyamada/rdap-domain-monitor. SSL/TLS Certificate Scraper inspects TLS certificates on hostnames (maximum 200): expiry, issuer, SHA-256 fingerprints, optional Google Web Risk; it does not query RDAP. DNS Propagation Checker queries public A/AAAA/MX/TXT/CNAME/NS/SOA across eight resolvers (maximum 200) and does not fetch RDAP registration records. DMARC & Email Security Checker grades SPF, DMARC, MX, and optional DKIM on domains. Use this Actor for RDAP expiry and ownership monitoring.

What does a monitoring result contain?

The published README output table lists meta and results[]. Per-result fields are domain, status, rdap, changes, warnings, checkedAt, and error. The README sample uses fictional dates and is truncated; treat it as an illustration, not a live coverage guarantee. Lookup failures stay in the free OUTPUT diagnostic record and are never billed as result rows.

How do unchanged rows, snapshots, and webhooks work?

Recurring runs write only initial or changed successful checks to the billable Dataset by default. Stable checks produce 0 Dataset rows and 0 result charges. emitUnchanged defaults to false; keep it off for recurring monitoring. Keep snapshotKey constant across runs for change detection (schema default rdap-domain-snapshots). delivery defaults to dataset. Set delivery to webhook and provide webhookUrl to POST the same summary-plus-results JSON. dryRun true skips saving snapshots and sending webhooks.

Does this Actor crawl websites or solve CAPTCHAs?

No. It looks up registration data through RDAP for hostnames you supply. It is not a page crawler, not HTTP status QA, not TLS handshake inspection, and not a CAPTCHA or anti-bot bypass. Keep concurrency low (README tip: typically 1–10, often at or below 5). Unreachable lookups produce an error row; other domains continue.
