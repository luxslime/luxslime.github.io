How is AWS Cloud Pricing Cost Impact Report different from Azure Retail Price Cost Impact Report and Multi-Cloud Pricing Cost Impact Report?

AWS Cloud Pricing Cost Impact Report (taroyamada/aws-cloud-pricing-cost-impact-report): Read official AWS public USD offer files for Lambda, S3, and RDS and emit stable price changes and cost-impact report rows. Not Azure Retail Prices (use Azure Retail Price Cost Impact Report). Not a multi-cloud scenario compare. Not a SaaS marketing-page scrape. No AWS account key. Azure Retail Price Cost Impact Report is for Azure Retail Prices public API (input scopes; Azure Retail Prices; Price-change / cost-impact rows). Not AWS offer files. Multi-Cloud Pricing Cost Impact Report is for Normalized AWS vs Azure scenarios (input scenarios; AWS + Azure public prices; Cross-cloud comparison report). Not an AWS-only SKU watch. SaaS Pricing Tracker is for Competitor SaaS page changes (input urls; Public HTML; Page-change rows). Not AWS list prices.

What input is required?

Live required fields: scopes. Published exampleRunInput is shown below.

Field Type Default Notes
scopes any[] [{"serviceCode": "AWSLambda", "region": "us-east-1", "usage": {"Requests": 1000000, "GB-Seconds": 100000}}] Pricing scopes. Each scope selects one supported AWS service and one required AWS region. Scope order is normalized for durable state. Required.
mode string enum "report" Run mode. report creates a current cost-impact report; watch emits stable SKU/term changes. enum: report, watch
initialRunMode string enum "baseline_only" Initial run mode. baseline_only stores the first successful snapshot with zero rows; emit_current permits current rows/report output on a new scope fingerprint. enum: baseline_only, emit_current
generateReport boolean true Generate cost-impact report. Emit one aws_cost_impact_report row when the selected mode has a report-worthy observation.
emitUnchanged boolean false Emit unchanged rows. When false, repeated identical rows and reports are suppressed. The default watch no-change run emits zero rows and zero charges.
emitRawRows boolean false Emit raw price rows. Emit canonical aws_price_row rows and an aws_price_export handoff row. Use filters and maxChargeUsd for broad services.
maxChargeUsd number 25 Maximum run charge. Hard PAY_PER_EVENT cap. A run exceeding it fails before delivery and state commit. minimum=0 maximum=100000
dryRun boolean false Dry run. Return deterministic sample rows without network access, delivery, charges, or state writes.
