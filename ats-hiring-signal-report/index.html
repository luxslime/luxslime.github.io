How is ATS Hiring Signal Report different from Career Site Scraper and Trade Show Exhibitor Intelligence?

ATS Hiring Signal Report (taroyamada/ats-hiring-signal-report): This Actor turns public Greenhouse, Lever, and Ashby job boards into decision-ready hiring signal reports with role priorities, keyword matches, region signals, warnings, and next actions. No user API key required. Not the row-priced ATS Hiring Signal Scraper. Not a career-site HTML crawler. Not applicant PII. Public boards only. Not a hiring recommendation. Career Site Scraper is for Public /jobs HTML signals (input careerUrls; Public career pages; Hiring-signal rows). Not Greenhouse/Lever/Ashby board APIs. Trade Show Exhibitor Intelligence is for Booth fields from supplied URLs (input exhibitor URLs; User-supplied show pages; Exhibitor rows). Not ATS job boards. NIH RePORTER Funding Landscape Report is for NIH award landscape (input topic watches; NIH RePORTER; Award landscape reports). Not ATS hiring reports.

What input is required?

Live required fields: none listed (see live fields). Published exampleRunInput is shown below.

Field Type Default Notes
companies any[] [{"ats": "greenhouse", "slug": "stripe", "companyName": "Stripe"}] Public ATS companies. Public Greenhouse, Lever, or Ashby job boards to analyze. Example item: {"ats":"greenhouse","slug":"stripe","companyName":"Stripe"}.
keywords any[] ["AI", "data", "security", "platform"] Priority keywords. Optional terms to score, such as AI, security, platform, sales, enterprise, data, or customer success.
regions any[] ["Remote", "United States"] Priority regions. Optional location terms to score, such as Remote, United States, Europe, Japan, London, or Singapore.
remoteOnly boolean false Remote only. Only include jobs whose public location mentions remote, anywhere, or distributed.
sinceDays integer 30 Recent job window days. Jobs updated or created within this many days are treated as new hiring signals. minimum=1 maximum=365
maxJobs integer 150 Max jobs per company. Maximum normalized public jobs to analyze per company before scoring. minimum=1 maximum=1000
reportTier string enum snapshot Report tier. Choose the public launch tier. Watch summary is proof-gated and not selectable publicly. enum: snapshot, signal_report
maxReports integer 1 Max reports. Maximum report groups to charge. This Actor currently creates one combined report per run. minimum=1 maximum=5
maxChargeUsd number 9 Max charge USD. Hard safety cap. If the selected report would exceed this cap, the Actor returns a no-charge limit_reached summary. minimum=0 maximum=100
demoMode boolean false Demo mode. Return a no-charge sample preview without calling public job board APIs.
dryRun boolean false Dry run. Return a no-charge previewReport and nextRunInput.
sourceDatasetId string empty Advanced source dataset ID. Advanced only. Optional future hook for prepared company rows; not needed for first run.
