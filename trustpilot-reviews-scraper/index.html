How do I use Trustpilot Reviews Scraper Apify?

Pass one or more companyUrls. Schema prefill is two public Trustpilot review URLs. Keep reviewLimit modest while you validate a row. Leave delivery on dataset and dryRun false for a paid first run.

{
  "companyUrls": [
    "https://www.trustpilot.com/review/www.shopify.com"
  ],
  "reviewLimit": 50,
  "delivery": "dataset",
  "dryRun": false
}

Which live input fields does Trustpilot Reviews Scraper accept?

companyUrls is required. Optional published fields are reviewLimit (default 50), delivery (dataset or webhook), webhookUrl, and dryRun. additionalProperties is false.

What does a Trustpilot company row include?

The published README summary lists company metadata, star ratings and rating distributions, recent review text samples with timestamps, language distribution, verification and reply indicators, company reply timestamps, collection-health signals, and warnings for blocked, missing, partial, or invalid sources. Outputs are normalized per company. There is no separate published dataset/output JSON schema on the Store page.

How is Trustpilot Reviews Scraper priced?

How do dataset, webhook, and dryRun work?

delivery defaults to dataset. Set delivery to webhook and provide webhookUrl to POST the full normalized payload. dryRun true runs collection without pushing company rows to the dataset.

Does Trustpilot Reviews Scraper Apify accept a login or private API field?

No. The published input schema is companyUrls, reviewLimit, delivery, webhookUrl, and dryRun. This independent Actor is not affiliated with or endorsed by Trustpilot. Do not use the output to target individual reviewers.
