How is Multi-Cloud Pricing Cost Impact Report different from AWS Cloud Pricing Cost Impact Report and Azure Retail Price Cost Impact Report?

Multi-Cloud Pricing Cost Impact Report (taroyamada/multi-cloud-pricing-cost-impact-report): Compare official AWS public price-list and Azure Retail Prices data for explicitly normalized workload scenarios. Get source-linked cross-provider cost comparison reports and optional exports. Not an AWS-only SKU watch. Not an Azure-only retail watch. Not AI API token prices. You supply normalized scenarios. AWS Cloud Pricing Cost Impact Report is for AWS public offer files (input scopes; AWS price list; SKU change / cost-impact rows). Not a cross-cloud scenario compare. Azure Retail Price Cost Impact Report is for Azure Retail Prices public API (input scopes; Azure Retail Prices; Price-change / cost-impact rows). Not a cross-cloud scenario compare. AI API Pricing & Model Lifecycle Report is for OpenAI/Anthropic/Gemini public pages (input providers; Official API pricing pages; Model price / lifecycle rows). Not AWS/Azure IaaS SKUs.

What input is required?

Live required fields: scenarios. Published exampleRunInput is shown below.

Field Type Default Notes
scenarios any[] [] Comparable workload scenarios. Each scenario must define one AWS selector, one Azure selector, the provider quantities, a shared normalized unit/quantity, and explicit comparison assumptions. Required.
monitorKey string "multi-cloud-finops-watch" Monitor key. Stable state namespace for the same scenario portfolio.
initialRunMode string enum "baseline_only" Initial run mode. Store a free baseline or emit the current comparison. enum: baseline_only, emit_current
generateReport boolean true Generate comparison report. Generate one source-linked comparison report when current or changed prices are emitted.
emitRawRows boolean false Emit provider price rows. Optional low-cost provider rows. Reports and alerts remain the primary output.
emitExport boolean false Generate pricing export. Generate a compact JSON export with the comparison.
emitUnchanged boolean false Emit unchanged rows. Accepted for compatibility; unchanged runs always emit zero rows and zero charges.
maxPagesPerScope integer 2 Maximum Azure pages per scenario. Maximum official Azure continuation pages fetched per scenario. minimum=1 maximum=5
maxItemsPerProvider integer 20 Maximum matched rows per provider. Maximum exact public price matches retained per provider. minimum=1 maximum=100
maxChargeUsd number 25 Maximum run charge USD. Fail closed before delivery if planned PAY_PER_EVENT charges exceed this cap. minimum=0 maximum=250
dryRun boolean false Dry run. Return representative rows for all event types without network, state, delivery, or charges.
