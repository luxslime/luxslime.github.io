Shopify App Store Rank Tracker — keyword and category rank, rating, and Built for Shopify

Shopify App Store Rank Tracker records where your app ranks for each App Store keyword or category page, with rating, review count, Built for Shopify badge, and change since the last run. Store id taroyamada/shopify-app-store-rank-tracker. The default input is one keyword and one tracked app, and that run returns one row for that app.

Use this page when the job is organic rank on public apps.shopify.com search or category pages. Use Shopify App Store Review Scraper when you already have a listing and need review text and theme rollups. Use Apify Store Ranking Scraper for Apify Store keyword rank, not the Shopify App Store. This Actor reads public App Store pages. It does not need a login or an API key. It is not affiliated with or endorsed by Shopify.

Use cases

  • App developers: track rank for the keywords a listing targets, on a schedule, and keep the change since the previous run.
  • Competitor research: see who sits above a tracked app, with rating, review count, and Built for Shopify status.
  • Agencies and investors: snapshot a category page to see which apps are listed there.

How to start a run

  1. Open the Actor on the Apify Store and start with the default input: one keyword and one app handle.
  2. Replace the keyword and the app handle with your own. Category handles or full category URLs are optional.
  3. Leave onlyTrackedApps on to save rows for the apps you listed. Turn it off to save the full ranked list from the scanned pages.
  4. Leave compareWithPreviousRun on. previousPosition is null on the first run and filled from the second run on.
  5. Schedule the Actor (Apify Schedules) to build a rank history, then export the dataset to Google Sheets or CSV.

Input

Published input fields:

Field Default Notes
keywords ["po box blocker"] App Store search terms
categoryHandles [] Category handle (for example store-design-search-and-navigation or orders-and-shipping-shipping-solutions-address-validation) or a full category URL
appHandles ["address-guard"] Apps to flag, as handles or URLs. If one is missing from the scanned pages, you still get a row with notRankedInScannedPages: true
onlyTrackedApps true Save only rows for tracked apps. Needs at least one tracked app. Turn off to save the full ranked list
maxPages 1 Pages per keyword or category. Minimum 1, maximum 10. Each page lists up to 24 apps
compareWithPreviousRun true Fills previousPosition and positionDelta from the last run. Positive positionDelta means the app moved up

Input example:

{
  "keywords": ["po box blocker", "address validation"],
  "categoryHandles": ["store-design-search-and-navigation"],
  "appHandles": ["address-guard"],
  "maxPages": 2
}

Output fields

One row per app per keyword or category. If a tracked app is not found in the scanned pages, the row still arrives with notRankedInScannedPages set, so a drop off the list is visible.

Field Meaning
surface, query Keyword search or category page, and the query or category that was scanned
position Organic rank across all scanned pages. 1 is the top. Sponsored slots are flagged and do not receive an organic position
previousPosition, positionDelta Rank on the previous run, and the change. Positive delta means the app moved up. previousPosition is null on the first run
appName, appHandle, appUrl, tagline, iconUrl Listing identity from the public App Store page
rating, reviewCount Rating and review count shown on the listing
pricingSummary Pricing label published on the listing
builtForShopify Whether the listing shows the Built for Shopify badge
isAd, isTrackedApp Sponsored slot versus organic row, and whether the app was in appHandles
page, positionOnPage, sourceUrl, scrapedAt Page number, rank on that page, source URL, and scrape time
notRankedInScannedPages Present when a tracked app was not found in the scanned pages

Limitations

  • No login and no API key. The Actor reads public App Store pages.
  • Results reflect what an anonymous visitor in the US sees. Personalised placements and ads may differ.
  • Sponsored slots are often absent for anonymous visitors, so isAd is often false. When a sponsored slot appears, it is flagged and it does not get an organic position.
  • maxPages stops at 10. A tracked app past the scanned pages is a not-ranked row, not a silent omission.
  • onlyTrackedApps needs at least one app in appHandles.
