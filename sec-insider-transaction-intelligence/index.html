How is SEC Insider Transaction Scraper different from SEC EDGAR Scraper and SEC Material Contract Intelligence?

SEC Insider Transaction Scraper (taroyamada/sec-insider-transaction-intelligence): This Actor reads official EDGAR ownership forms for issuers you list and emits insider purchase, sale, grant, and holding rows, with optional transactionCodes and minTransactionValue filters. Not investment advice. Not 8-K material contracts. Not a copy of paid insider-trading products. Public EDGAR ownership XML/HTML only. SEC EDGAR Scraper is for 8-K/S-1 filing alerts (input companies; SEC EDGAR; SEC filing rows). Not ESG report packs. SEC Material Contract Intelligence is for SEC exhibit contracts (input tickers / CIKs; SEC EDGAR exhibits; contract-intel rows). Not Form 4 insider trades. Campaign Finance Scraper is for FEC/LDA filings (input feeds / watchTerms; OpenFEC / LDA.gov; campaign digest rows). Not OFAC sanctions or Federal Register.

What input is required?

Live required fields: issuers. Published exampleRunInput is shown below. Track SEC Forms 3, 4, and 5 insider ownership transactions by ticker or CIK using official EDGAR data.

Field Type Default Notes
issuers any[] required empty required Issuers. Ticker symbols or CIK numbers. Example: MSFT, NVDA, 0000789019.
formTypes any[] ["3", "4", "5"] Ownership form types. SEC ownership forms to include. Allowed values: 3, 4, 5.
daysBack integer 120 Days back. How far back to scan issuer submissions for Forms 3, 4, and 5. min=1 max=3650
maxFilingsPerIssuer integer 20 Max filings per issuer. Maximum ownership filings to inspect for each issuer. min=1 max=200
transactionCodes any[] empty Transaction codes. Optional filter such as P, S, A, M. Leave empty to include all transaction codes.
minTransactionValue number 0 Minimum transaction value. Minimum absolute transaction value to keep. Set 0 to include all values. min=0
includeDerivativeTransactions boolean true Include derivative transactions. Include derivative transaction rows such as options, restricted stock units, and conversions.
includeHoldings boolean false Include holding rows. Also emit non-transaction holding rows from ownership documents.
requestDelayMs integer 120 Delay between filing requests. Delay between SEC Archives filing requests to stay within polite API usage. min=0 max=2000
timeoutMs integer 20000 Timeout (ms). HTTP request timeout for SEC API and Archives requests. min=1000 max=60000
secUserAgent string empty SEC User-Agent. Optional declared SEC User-Agent with contact information. The actor has a default, but production users should provide their own contact.
delivery string enum dataset Delivery. Where to send results. Webhook delivery does not also push dataset rows. enum: dataset, webhook
webhookUrl string empty Webhook URL. Webhook URL to POST the full normalized payload to when delivery=webhook.
dryRun boolean false Dry run. Run without pushing rows to the dataset or webhook.
