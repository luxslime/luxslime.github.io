How is Podcast Media Buyer Shortlist Scraper different from Apple Podcasts Scraper and Apple Podcasts Chart Scraper?

Podcast Media Buyer Shortlist Scraper (taroyamada/podcast-media-buyer-shortlist-scraper): This Actor builds a podcast media-buyer shortlist from RSS feeds and show URLs you supply. First paid Input: 1 RSS + maxEpisodes 1, search off, export off. Not iTunes Search or Apple charts. Not sponsor-evidence extraction (use Podcast Sponsor Evidence Report Scraper). Not a contact/outreach list. Apple Podcasts Scraper is for iTunes search, charts, episodes (input searchTerm; Apple/iTunes endpoints; Podcast metadata rows). Not RSS-only sponsor evidence. Apple Podcasts Chart Scraper is for Top Podcasts ranks (input chart params; Apple chart endpoints; Chart rows). Not episode watchlists. RSS & Atom Feed Extractor is for Known-publisher feed XML (input feed URLs; RSS/Atom XML; Feed item rows). Not sponsor-evidence extraction.

What input is required?

Live required fields: none listed (see live fields). Published exampleRunInput is shown below.

Field Type Default Notes
rssFeedUrls string[] ["https://feeds.npr.org/510289/podcast.xml"] RSS feed URLs. Public podcast RSS feed URLs to score for shortlist fit.
showUrls string[] empty Show URLs. Public podcast show or publisher pages to include as fit evidence surfaces.
searchTerms string[] empty Apple Podcast search terms. Apple iTunes Search API terms for public feed discovery.
targetKeywords string[] ["business"] Target keywords. Campaign, audience, category, or topic keywords used to score candidate shows.
maxEpisodesPerFeed integer 1 Max episodes per feed. Maximum RSS episode items to inspect per feed. minimum=1 maximum=50
emitShortlistExport boolean false Emit shortlist export. Emit one shortlist export row when candidate rows are found.
emitUnchanged boolean false Emit unchanged rows. When false, previously seen candidate rows are suppressed.
dryRun boolean false Dry run. When true, emit sample rows locally without external live calls or billing.
