How is SaaS Pricing Changelog Battlecard Watch different from SaaS Pricing Tracker and B2B Pricing Scraper?

SaaS Pricing Changelog Battlecard Watch (taroyamada/saas-pricing-changelog-battlecard-watch-scraper): This Actor unofficially watches public SaaS pricing and changelog pages, then emits source-linked pricing changes and battlecard report rows. Not authenticated billing portals. Not the cheaper SaaS Pricing Tracker row Actor. Not a legal-page SHA256 watcher. Public pages only. SaaS Pricing Tracker is for Public SaaS page change rows (input targets; Public pricing/terms HTML; SaaS change rows). Not premium SHA256 legal diffs or battlecards. B2B Pricing Scraper is for Public subscription-tier changes (input competitors[]; Public pricing HTML; Pricing change rows). Not Shopify catalog maps or ads-library pages. Docs & Changelog Drift Scraper is for API docs/changelog drift (input doc URLs; Public docs HTML; Drift rows). Not legal-page SHA256 diffs.

emitExport boolean false Generate export row. Generate an export row for handoff workflows.
emitUnchanged boolean false Emit unchanged rows. When false, repeated unchanged runs emit zero rows and zero charges.
dryRun boolean false Dry run. Emit local sample rows without charging.
initialRunMode string enum emit_backfill Initial run mode. Deployment canary control used by automation; emit_backfill allows first-run proof rows, baseline_only is used for no-change proof. enum: emit_backfill, baseline_only
snapshotKey string empty Snapshot key. Optional state namespace for canary and recurring no-change proof runs.
