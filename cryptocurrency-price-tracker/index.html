CoinGecko watchlist prices, market cap, and 24-hour change rows

Cryptocurrency Price Scraper monitors live CoinGecko market data for CoinGecko ids you supply (maximum 50 per run). It captures fiat- and crypto-quoted prices, localized conversions, market cap, circulating supply, 24-hour volume and percentage change, sparklines, and optional history up to 365 days. It is not a forex pair monitor — that job is Forex Exchange Rate Scraper — and it is not a weather or generic time-series fetcher (Weather Forecast Scraper).

How is Cryptocurrency Price Scraper different from Forex Exchange Rate Scraper and CSV Cleaner?

Cryptocurrency Price Scraper (taroyamada/cryptocurrency-price-tracker) reads CoinGecko public market data for coins you supply as CoinGecko ids (required coins, maximum 50). It returns cryptocurrency price rows billed at $0.003 per delivered default-dataset item on the live Store card ($3.00 / 1,000). Forex Exchange Rate Scraper is for fiat FX snapshots, not CoinGecko ids. CSV Cleaner & Deduplication Tool is offline CSV hygiene and does not fetch market APIs. Use this Actor for token watchlists. Use Forex Exchange Rate Scraper for FX. Use CSV Cleaner when you already have a file.

What input is required?

coins is required: CoinGecko ids (maximum 50). Live schema fields are coins, vsCurrencies, includeHistory (default false), historyDays (default 7, min 1, max 365), timeoutMs (default 15000, min 1000, max 30000), delivery (dataset or webhook, default dataset), webhookUrl (when delivery is webhook), and dryRun (default false). Schema prefill is bitcoin and ethereum with vsCurrencies usd. README Input Examples that send include24hChange, include7dChange, category, vsCurrency, or perPage are not live schema fields.

What does a result contain?

The live dataset view in actor.json titles the view Crypto Prices and lists overview columns id and lastUpdated. The README output table (not a published dataset_schema.json) lists coin, symbol, currency, price, marketCap, change24h, volume24h, and fetchedAt. README examples also show id, name, a price object, and sparkline7d. There is no published output JSON schema on the Store page. Treat README samples as illustrations, not a live coverage guarantee.

How do dataset, webhook, and dry-run delivery work?

delivery defaults to dataset. webhookUrl is used when delivery is webhook. dryRun defaults to false; set it true only to run without saving results. The cheapest first paid path keeps dryRun false so a payable row can be written.
