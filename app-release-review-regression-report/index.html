How is App Release Review Regression Report different from App Review Regression & Release Report and iOS & Android App Review Scraper?

App Release Review Regression Report (taroyamada/app-release-review-regression-report): This Actor turns public App Store and Google Play review signals into release regression reports, QA backlog candidates, and prioritized product actions. Not the monitor Actor (taroyamada/app-release-review-regression-monitor). Not a review generator. Not reviewer targeting. Sample-based public storefront signals only. App Review Regression & Release Report is for Store review regression monitor (input appleAppIds / googlePlayIds; Public storefront samples; Regression alerts/reports). Not the $9/$29 report-only Actor. iOS & Android App Review Scraper is for Cross-store review samples (input app IDs; App Store / Play reviews; Review rows). Not a release-regression report. App Store & Google Play Listing Gap Report is for ASO listing checklist (input app IDs; Public listings; Listing-gap reports). Not release-regression reviews.

What input is required?

Live required fields: none listed (see live fields). Published exampleRunInput is shown below.

Field Type Default Notes
appleAppIds any[] ["284882215"] App Store app IDs. Public App Store numeric app IDs to check. Uses public iTunes Lookup and public review RSS only.
appleCountries any[] ["us"] App Store countries. Storefront country codes such as us, jp, gb.
googlePlayIds any[] ["com.duolingo"] Google Play package IDs. Public Google Play package IDs to include in the app coverage.
reportTier string enum snapshot Report tier. Snapshot returns a compact release review checklist. Regression adds deeper issue grouping and QA backlog suggestions. enum: snapshot, regression
releaseVersion string empty Release version. Optional version label for the release you want to triage.
releaseDate string empty Release date. Optional release date in YYYY-MM-DD format. Used as report context, not as a guarantee that every source exposes release-level review attribution.
lookbackDays integer 30 Review lookback days. Recent public review window used for theme and risk scoring. minimum=1 maximum=180
reviewLimit integer 25 Review sample limit. Maximum public review samples per app/source. minimum=1 maximum=100
maxChargeUsd number 9 Maximum charge USD. Safety cap. If below the selected report tier price, the Actor returns a no-charge limit_reached summary. minimum=0
maxReports integer 1 Maximum reports. This Actor produces one decision report per run to keep pricing predictable. minimum=1 maximum=1
demoMode boolean false Demo mode. Returns a no-charge example report shape without using public sources.
dryRun boolean false Dry run. No-charge validation path. Does not fetch public sources or create a paid report.
sourceDatasetId string empty Advanced source dataset ID. Advanced only. Optional future workflow hook for user-provided app lists. The first-run example does not require it.
