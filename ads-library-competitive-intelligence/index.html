How is Ads Library Competitive Intelligence different from Chrome Web Store Extension Intelligence and B2B Pricing Scraper?

Ads Library Competitive Intelligence (taroyamada/ads-library-competitive-intelligence): This Actor is a direct-source parser for user-provided public ad-library pages, exports, and saved HTML snapshots. It structures ad creatives and advertiser signals without search, crawling, login, browser automation, pagination, or API replay. Not an ads-library search engine. Not landing-page CRO analysis. Not authenticated ads-manager access. You must supply the source URLs or HTML. Chrome Web Store Extension Intelligence is for Extension listing metadata (input extension URLs; Chrome Web Store HTML; Extension metadata). Not ads-library creatives. B2B Pricing Scraper is for Public subscription-tier changes (input competitors[]; Public pricing HTML; Pricing change rows). Not Shopify catalog maps or ads-library pages. Website Content Extractor is for One-shot page-to-markdown (input urls; Page HTML; Markdown/text). Not recurring pricing/legal diffs or RAG audits.

What input is required?

Live required fields: none listed (see live fields). Published exampleRunInput is shown below.

Field Type Default Notes
sourceUrls string[] empty Public Ad Library or Export URLs. User-provided public ad-library pages or export URLs to fetch directly once. V1 does not discover, paginate, replay APIs, log in, or automate browsers. maxItems=100
htmlSnapshots object[] empty HTML Snapshots. Saved ad-library HTML snapshots supplied in the input. Each item can include url, html, and label. This is safest for high-risk platforms because no network request is made. item required: html maxItems=50
savedHtmlFiles string[] empty Saved HTML Files. Optional local saved HTML or export files to parse. Files must be inside the Actor working directory at runtime. maxItems=50
brandHints string[] empty Brand Hints. Optional advertiser or competitor names used only for local matching in parsed rows. maxItems=50
maxAdsPerSource integer 25 Max Ads per Source. Maximum ad creative rows emitted from each direct source. minimum=1 maximum=100
maxSources integer 50 Max Sources. Maximum normalized direct sources to process. minimum=1 maximum=150
dryRun boolean false Dry Run. Validate input, parse sources, and write local output without pushing dataset rows or charging custom PPE events.

Published Store example run input (omitted fields take schema defaults):

{
  "sourceUrls": [
