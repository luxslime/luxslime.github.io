Monitor NIH RePORTER awards by topic, institution, and fiscal year

NIH RePORTER Funding Landscape Report queries the official NIH RePORTER v2 Project API for awards matching bounded watches: terms, institutions, fiscal years, agencies, and activity codes. It returns source-linked funding change alerts, landscape reports, and compact exports from public award data. Baseline and unchanged checks are free.

Descriptive public funding fields only. Not a directory or prospecting tool. Not financial, medical, clinical, legal, grant-writing, award-probability, or institutional-performance advice. This independent Actor is not affiliated with, sponsored by, or endorsed by NIH or HHS.

How is NIH RePORTER Funding Landscape Report different from TED/SAM.gov Bid Alerts and PubMed Literature Watch?

This Actor queries the official NIH RePORTER v2 Project API for awards matching bounded watches (terms, institutions, fiscal years, activity codes, agencies, project numbers). Store ID taroyamada/nih-research-funding-landscape-report. TED, SAM.gov & Grants Bid Alerts Scraper queues TED tenders, SAM.gov opportunities, and Grants.gov notices — public-sector procurement, not NIH RePORTER awards. PubMed Literature Watch is NCBI citation metadata. OpenAlex Scholarly Works Scraper is scholarly works. PubMed & Clinical Trials Evidence Gap Report matches trials to PubMed. This page is NIH award landscape only.

What is the best first run?

Default initialRunMode is baseline_only: the first successful run stores a free baseline with zero rows and zero charge. Published example run input (small live backfill under a $3 cap — omitted initialRunMode therefore stays baseline_only unless you set emit_backfill):

{
  "watches": [{
    "id": "oncology-immunotherapy",
    "terms": ["immunotherapy", "oncology"],
    "fiscalYears": [2025, 2026],
    "activityCodes": ["R01"]
  }],
  "maxProjectsPerWatch": 3,
  "maxChargeUsd": 3,
  "dryRun": false
}

Use initialRunMode emit_backfill when you want the first matching awards billed. Store Quickstart uses emit_backfill, generateReport true, emitExport true, maxProjectsPerWatch 10, and maxChargeUsd 30. Default generateReport is true ($12.00 when a new or changed landscape is emitted). If planned PPE exceeds maxChargeUsd, the run fails closed with no delivery. Default maxChargeUsd is 25.

What input is required?

watches is required. Root and watch-item additionalProperties are false.

Field Type Default Notes
watches object[] required id, terms, institutions, fiscalYears (2000–2100), activityCodes, agencies, projectNumbers, includeActiveProjects (default true)
monitorKey string nih-funding-watch Isolated state namespace
initialRunMode string baseline_only baseline_only or emit_backfill
generateReport boolean true Aggregate landscape only when new/changed awards are emitted
emitRawRows boolean false Low-priced award rows
emitExport boolean false Compact JSON export
emitUnchanged boolean false Compatibility; unchanged still 0 rows / 0 charge
maxProjectsPerWatch integer 50 NIH request limit never greater than 500
maxChargeUsd number 25 Fail closed if planned PPE exceeds the cap
dryRun boolean false Representative rows; no NIH, no state, no PPE

What does a result contain?

README sample JSON lives in docs/sample-output.json and is illustrative, not a live NIH result. A landscape report includes matched project count, new/changed counts, observed award totals, FY/org/activity/agency distributions, and an official source URL. Descriptive public funding fields only. The Actor excludes investigator identity and direct communication fields. It is not a directory or prospecting tool.

Is this medical, financial, or grant-writing advice?

No. Not financial, medical, clinical, legal, grant-writing, award-probability, or institutional-performance advice. No NIH or HHS endorsement. Sequential RePORTER requests are spaced at least 1 second apart. State is isolated by monitorKey plus caller; a state failure does not mark the monitor successful.
