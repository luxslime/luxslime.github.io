How is SEC Form D Exempt Offering Notices different from SEC EDGAR Scraper and SEC Insider Transaction Scraper?

SEC Form D Exempt Offering Notices (taroyamada/sec-form-d-offering-notices-scraper): This Actor tracks as-filed SEC Form D and D/A exempt offering notices from EDGAR with stable IDs for recurring regulatory trigger monitoring. Not 8-K/S-1 filing-index alerts. Not Forms 3/4/5. Not exhibit-contract extraction. Informational only. Not investment advice. SEC EDGAR Scraper is for 8-K and S-1 filing alerts (input companies; Public EDGAR; Filing-index rows). Not Form D notices or 8-K item candidates. SEC Insider Transaction Scraper is for Forms 3, 4, 5 (input issuers; EDGAR ownership forms; Insider transaction rows). Not Form D exempt offerings. SEC Material Contract Intelligence is for Exhibit/contract leads (input issuers; EDGAR exhibits; Contract intelligence rows). Not Form D or insider Forms 3/4/5.

What input is required?

Live required fields: none listed (see live fields). Published exampleRunInput is shown below.

Field Type Default Notes
mode string enum latest Mode. latest scans the current Form D Atom feed. issuers scans Form D/D-A filings for supplied CIKs or tickers. enum: latest, issuers
issuers any[] empty Issuers. Ticker symbols or CIK numbers used when mode=issuers.
daysBack integer 30 Days back. Only emit filings dated within this window. minimum=1 maximum=3650

limit integer 40 Result limit. Maximum billable rows to emit. minimum=1 maximum=500
firstRunMode string enum emit_all First run mode. emit_all writes the first matching rows. seed_only stores the baseline and writes no rows. enum: emit_all, seed_only
delivery string enum dataset Delivery. Where to send emitted trigger rows. enum: dataset, webhook
webhookUrl string empty Webhook URL. Required when delivery=webhook.
dryRun boolean false Dry run. Run without external source requests or dataset writes.
