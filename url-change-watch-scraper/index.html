How is Website Change Monitor different from SaaS Pricing Competitor Monitor and Docs & Changelog Drift Scraper?

Website Change Monitor (taroyamada/url-change-watch-scraper): Watch public page content you are allowed to fetch and emit source-linked change rows when the page diff crosses your settings. Not a SaaS pricing-page specialist (use SaaS Pricing Competitor Monitor). Not a docs/changelog drift Actor. Not a full-site crawler. You supply targets (name + url); live required array is empty. SaaS Pricing Competitor Monitor is for Competitor pricing HTML (input urls; Public pricing pages; Price-change rows). Not a generic page-diff watch. Docs & Changelog Drift Scraper is for Docs/changelog drift (input urls; Public docs HTML; Drift rows). Not an arbitrary URL diff watch. SaaS Pricing Tracker is for SaaS page change alerts (input urls; Public HTML; Page-change rows). Not a generic URL watch with page diffs.

What input is required?

Live required fields: none (see live fields). Published exampleRunInput is shown below.

Field Type Default Notes
targets any[] [{"name": "Example page", "url": "https://example.com/", "cssSelector": "", "ignoreSelectors": []}] Watch targets. Public pages to monitor. Optional cssSelector narrows the hashed region; ignoreSelectors remove noisy nodes (as text patterns).
maxTargets integer 25 Max targets. Maximum targets to check in one run. minimum=1 maximum=100
emitSnapshots boolean false Emit snapshot rows. Emit a url-snapshot row whenever a page is successfully fetched (in addition to change rows).
generateDigest boolean true Generate digest report. When any change is detected, emit one change-digest-report summarizing the run.
stripDates boolean true Strip date-like tokens. Remove ISO-like dates and common timestamps before hashing to reduce false positives.
stripVolatileNumbers boolean false Strip volatile counters. Normalize long digit runs (view counts, etc.) before hashing.
maxDiffSegments integer 20 Maximum added/removed segments. Maximum number of added and removed text segments included in each change row. minimum=1 maximum=100
emitUnchanged boolean false Emit unchanged rows. When false (default), repeated unchanged runs emit zero rows and zero charges.
dryRun boolean false Dry run. Emit local sample rows without fetching or charging.
initialRunMode string enum "baseline_only" Initial run mode. emit_backfill allows first-run change rows when no baseline exists; baseline_only records hashes with zero output rows. enum: emit_backfill, baseline_only
snapshotKey string empty Snapshot key. Optional state namespace for canary and recurring schedules.
maxChargeUsd number 10 Maximum event charge per run. Fail before delivery when configured output events would exceed this buyer-approved cap. minimum=0.01 maximum=1000
