How is SEC & ESG Report Scraper different from TED, SAM.gov & Grants Bid Alerts and NIH Research Funding Landscape Report?

SEC & ESG Report Scraper (taroyamada/esg-disclosure-tracker): This Actor monitors company disclosure packs you configure: sustainability/IR URLs and optional SEC EDGAR submissions by CIK and form types. It snapshots extracted text and emits company-level change rows. Not a GHG inventory, ESG rating, or legal/audit opinion. Public IR pages and EDGAR only. TED, SAM.gov & Grants Bid Alerts is for Procurement notices (input keywords; SAM/TED/Grants; opportunity rows). Not SEC ESG disclosures. NIH Research Funding Landscape Report is for NIH awards (input org/term filters; NIH Reporter; award rows). Not corporate ESG filings. Website Content Extractor is for One-shot page markdown (input urls; HTML; markdown). Not recurring EDGAR/IR diffs.

What input is required?

Live required fields: companies. exampleRunInput monitors Microsoft sustainability URL plus CIK 789019 10-K/10-Q/8-K. datasetMode default changes_only. email delivery is a placeholder enum.

Field Type Default Notes
companies array required empty Companies. One monitored company per output row. Use official disclosure pages and SEC / EDGAR company submissions where possible.
requestTimeoutSeconds integer 30 Request Timeout (seconds). Timeout for each disclosure page or SEC / EDGAR request.
maxChars integer 30000 Max Extracted Characters per Surface. Upper bound for extracted page text per monitored disclosure surface.
delivery string dataset Delivery. dataset writes results to the Apify dataset. webhook posts the digest JSON. email is a placeholder for later delivery expansion.
datasetMode string changes_only Dataset Mode. changes_only emits only changed companies. all emits every company row. action_needed limits results to higher-severity disclosure changes.
webhookUrl string empty Webhook URL. POST target for webhook delivery. Leave empty for dataset runs.
notifyOnNoChange boolean false Notify On No Change. When false, webhook delivery is skipped if no company changed.
snapshotKey string esg-disclosure-tracker-snapshots Snapshot Key. Stable key used to persist disclosure snapshots between recurring runs.
diffMode string line_summary Diff Mode. line_summary includes compact added/removed disclosure text snippets. hash_only only compares snapshot hashes.
summaryMaxLines integer 12 Max Diff Summary Lines. Maximum added and removed lines included in disclosure change summaries.
concurrency integer 2 Concurrency. Concurrent disclosure fetches. Keep low for polite recurring monitoring.
batchDelayMs integer 500 Inter-batch Delay (ms). Delay between concurrency batches to reduce rate-limit pressure on disclosure surfaces.
dryRun boolean false Dry Run. Preview fetch and diff behavior without persisting snapshots or posting webhooks.
nowIso string empty Override Current Time. Optional ISO timestamp override for deterministic fixture or replay tests.

How do dataset, webhook, and dry-run delivery work?

delivery defaults to dataset on the live schema. Dataset output is the billable surface when rows are written. webhookUrl is used when delivery is webhook (and typically not during dryRun). dryRun true validates or samples without the usual dataset/webhook side effects described on the Store schema. datasetMode can limit emits to changes_only versus all. Unchanged runs that write zero default-dataset rows typically charge $0.00 on current PPE.
