How is CourtListener Public Opinion Watch different from USPTO Patent Search Scraper and SEC EDGAR Scraper?

CourtListener Public Opinion Watch (taroyamada/courtlistener-public-docket-opinion-watch-scraper): This Actor watches public CourtListener opinion search results with stable IDs for litigation trigger monitoring. delivery string enum dataset Delivery. Where to send emitted trigger rows. enum: dataset, webhook
webhookUrl string empty Webhook URL. Required when delivery=webhook.
dryRun boolean false Dry run. Run without external source requests or dataset writes.
