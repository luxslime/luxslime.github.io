How is FDA Orange Book Patent & Exclusivity Change Report different from FDA Warning Letters Scraper and USPTO Patent Search Scraper?

FDA Orange Book Patent & Exclusivity Change Report (taroyamada/fda-orange-book-patent-exclusivity-change-report): Monitor official FDA Orange Book product, patent, exclusivity, and therapeutic-equivalence records. What input is required?

Live required fields: watches. Published exampleRunInput is shown below.

Field Type Default Notes
watches any[] [] Orange Book watches. Each watch needs at least one bounded product, patent, exclusivity, or TE-code filter. Use stable ids for recurring monitoring. Required.
monitorKey string "fda-orange-book-lifecycle-watch" Monitor key. Stable isolated state namespace for a recurring product lifecycle watch.
initialRunMode string enum "baseline_only" Initial run mode. baseline_only stores the first snapshot with zero rows; emit_backfill emits the current matched records for an explicit first report. enum: baseline_only, emit_backfill
generateReport boolean true Generate patent cliff report. Generate one descriptive report for changed records and patent/exclusivity dates within cliffWindowDays. It is not a legal conclusion or launch forecast.
generateCliffReport boolean true Include date-window report. Keep the report event enabled when generateReport is true.
emitRawRows boolean false Emit product rows. Emit lower-priced normalized product rows for changed or explicitly backfilled records.
emitExport boolean false Generate evidence export. Generate a compact source-linked JSON export when changed or backfilled records are selected.
emitUnchanged boolean false Emit unchanged records. Accepted for compatibility, but unchanged records always emit zero rows and zero charge.
cliffWindowDays integer 730 Date-window days. The forward-looking date window used only to group reported patent and exclusivity dates. minimum=1 maximum=3650
maxRecordsPerWatch integer 25 Maximum records per watch. Each openFDA request is capped below the official API maximum of 99 records. minimum=1 maximum=99
maxRequests integer 10 Maximum API requests. Hard upper bound on watch requests per run. minimum=1 maximum=25
maxChargeUsd number 75 Maximum charge USD. Fail closed before delivery if planned PPE charges exceed this cap. minimum=0.005 maximum=500
dryRun boolean false Dry run. Return representative event rows without calling openFDA, saving state, or charging PPE events.
