What the tester checks

  • Prefix: the number must start with the text you enter, for example PO-.
  • Length: minimum and maximum character count, prefix included.
  • Characters: digits only, letters and digits, or letters, digits and hyphens.
  • Regular expression: an optional pattern the whole number must match.
  • Duplicates: a number that already appeared earlier in your pasted list is flagged on its second and later rows.
  • Empty rows: completely blank lines are skipped. A row that holds only spaces counts as empty and fails when the required box is ticked.

Surrounding spaces are trimmed before testing. Spaces inside a number are not removed, so “PO-12 3456” fails the character rule.
