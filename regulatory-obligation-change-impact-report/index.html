Optional: emitExport (default false), delivery (dataset or webhook; default dataset), webhookUrl, requestTimeoutSeconds (default 30, min 2, max 120), rateLimitMs (default 250), maxRetries (default 2), backoffBaseMs (default 250), maxBackoffMs (default 4000), maxFederalRegisterDocuments (default 1, min 1, max 100), lookbackDays (default 30, min 1, max 365). How do dataset, webhook, and dry-run delivery work?

delivery defaults to dataset and also accepts webhook. webhookUrl is the HTTPS handoff when delivery is webhook. dryRun defaults to true (no network / state / charges). Unchanged runs still suppressed when emitUnchanged is false. Dataset output is the billable surface when rows are written.
