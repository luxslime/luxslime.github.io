How is Campaign Finance Scraper different from TED, SAM.gov & Grants Bid Alerts and NIH Research Funding Landscape Report?

Campaign Finance Scraper (taroyamada/campaign-finance-lobbying-digest): This Actor watches official OpenFEC committee reports and/or LDA.gov lobbying filings, normalizes evidence, and emits per-feed digests with docket identifiers and source URLs. lda_filings can run anonymously for modest quickstarts; fec_committee needs fecApiKey or FEC_API_KEY. Not legal/compliance advice, not a contribution processor, and not SAM/TED procurement. Unofficial research on public filings. TED, SAM.gov & Grants Bid Alerts is for Procurement notices (input keywords / jurisdictions; SAM/TED/Grants.gov; opportunity rows). Not FEC/LDA campaign filings. NIH Research Funding Landscape Report is for NIH awards (input org/term filters; NIH Reporter; award rows). Not campaign finance.

What input is required?

Live required fields: none listed (see live fields). exampleRunInput uses lda_filings clientName Google. Schema required is empty but feeds minItems 1 when present. notifyOnNoNew default true. Use fec_committee + fecApiKey for OpenFEC.

Field Type Default Notes
feeds array empty Feeds. One digest row is emitted per configured feed. Use lda_filings for anonymous/no-key quickstarts. Use fec_committee when you can provide fecApiKey or FEC_API_KEY.. minItems=1
watchTerms string empty Watch terms. Comma- or newline-separated terms. Matching committees, clients, issues, or agencies elevate digests to action_needed.
lookbackDays integer 45 Lookback days. Default lookback window used when a feed-specific override is not provided.
maxEvidencePerFeed integer 25 Max evidence per feed. Upper bound on normalized evidence items retained for each feed.
maxPagesPerFeed integer 2 Max pages per feed. Upper bound on paginated API requests per feed during one run.
delivery string dataset Delivery. dataset writes digest rows to the Apify dataset. webhook POSTs the digest payload to webhookUrl.
webhookUrl string empty Webhook URL. POST target used when delivery=webhook.
datasetMode string all Dataset mode. Choose whether dataset/webhook delivery includes all digests, only action-needed digests, or only feeds with new evidence.
snapshotKey string campaign-finance-lobbying-digest-state Snapshot key. Stable key used to persist seen evidence across recurring runs.
fecApiKey string empty FEC API key. Optional here, or provide FEC_API_KEY in the environment.
ldaApiToken string empty LDA API token. Optional. Anonymous LDA requests work for modest quickstarts.
requestTimeoutSeconds integer 30 Request timeout seconds. Timeout for each FEC or LDA HTTP request.
notifyOnNoNew boolean true Notify when no new filings. When false, stable feeds are omitted from delivery outputs unless they errored.
dryRun boolean false Dry run. Skip snapshot writes and delivery while still producing local output.

How do dataset, webhook, and dry-run delivery work?

delivery defaults to dataset on the live schema. Dataset output is the billable surface when rows are written. webhookUrl is used when delivery is webhook (and typically not during dryRun). dryRun true validates or samples without the usual dataset/webhook side effects described on the Store schema. datasetMode can limit emits to changes_only versus all. Unchanged runs that write zero default-dataset rows typically charge $0.00 on current PPE.
