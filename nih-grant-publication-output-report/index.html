How is NIH Grant Publication Linkage & Output Report different from NIH RePORTER Funding Landscape Report and PubMed Literature Watch & Research Report?

NIH Grant Publication Linkage & Output Report (taroyamada/nih-grant-publication-output-report): Monitor NIH RePORTER awards and linked public publication output for watches you configure. Generate source-linked change alerts, output reports, and optional exports. Not an NIH RePORTER funding-landscape pack without publication linkage (use NIH RePORTER Funding Landscape Report). Not a PubMed literature watch. Not a biomedical evidence-gap report. NIH RePORTER Funding Landscape Report is for NIH award landscape (input org / terms; NIH RePORTER; Award report). Not publication-output linkage. PubMed Literature Watch & Research Report is for PubMed query watch (input terms; PubMed; Paper rows). Not NIH RePORTER award linkage. PubMed & Clinical Trials Evidence Gap Report is for PubMed vs trials gap (input query terms; PubMed + ClinicalTrials.gov; Evidence-gap report). Not NIH grant publication output.

What input is required?

Live required fields: watches. Published exampleRunInput is shown below.

Field Type Default Notes
watches any[] [] Grant publication watches. Use project numbers directly or a bounded NIH project search. Required.
monitorKey string "nih-publication-output-watch" Monitor key. Stable isolated state namespace for this recurring portfolio.
initialRunMode string enum "baseline_only" Initial run mode. baseline_only stores the first observation with zero rows. emit_backfill delivers the current linked publications. enum: baseline_only, emit_backfill
generateReport boolean true Generate portfolio report. Generate one descriptive publication-output report when new or changed links are delivered.
emitRawRows boolean false Emit grant-publication link rows. Add one low-priced normalized row for each selected grant-publication link.
emitExport boolean false Generate portfolio export. Generate a compact JSON-ready export when selected links are delivered.
emitUnchanged boolean false Emit unchanged links. Accepted for compatibility. Unchanged monitoring runs always remain zero rows and zero charge.
includePubMedMetadata boolean true Add PubMed citation metadata. Use official NCBI ESummary to add title, journal, publication date, and publication types for linked PMIDs.
ncbiEmail string empty NCBI contact email. Optional valid email sent to NCBI with the tool parameter. No NCBI API key is required at this Actor's conservative request rate.
maxProjectsPerWatch integer 10 Maximum projects per watch. Bounded project portfolio size. Keep this small for fast scheduled checks. minimum=1 maximum=25
maxPublicationsPerProject integer 100 Maximum publications per project. Maximum linked publication records retained for each core project. minimum=1 maximum=500
maxChargeUsd number 35 Maximum charge USD. Fail closed before pushing any row when the planned PPE charge exceeds this cap. minimum=0.008 maximum=500
dryRun boolean false Dry run. Return representative rows without calling NIH or NCBI, saving state, or charging events.
