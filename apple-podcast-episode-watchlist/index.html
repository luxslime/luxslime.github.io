How is Apple Podcast Episode Watchlist different from Apple Podcasts Scraper and Apple Podcasts Chart Scraper?

Apple Podcast Episode Watchlist (taroyamada/apple-podcast-episode-watchlist): This Actor watches Apple Podcast episode lists from shows or RSS you already know and emits new-episode rows. Paste a term plus maxEpisodes for a first run. Not Apple Podcasts search/charts (use Apple Podcasts Scraper / Chart Scraper). Not review monitoring. Not a cheaper Store-wide episode dump of shows you did not list. Apple Podcasts Scraper is for iTunes search, charts, episodes (input searchTerm; Apple/iTunes endpoints; Podcast metadata rows). Not RSS-only sponsor evidence. Apple Podcasts Chart Scraper is for Top Podcasts ranks (input chart params; Apple chart endpoints; Chart rows). Not episode watchlists. Apple Podcasts Reviews Scraper is for Public review RSS (input collection IDs; Customer Reviews RSS; Review rows). Not sponsor-signal reports.

What input is required?

Live required fields: none listed (see live fields). Published exampleRunInput is shown below.

Field Type Default Notes
podcastIds any[] empty Apple Podcast IDs. iTunes collection IDs (numeric strings). Leave empty to resolve via searchTerms.
searchTerms any[] ["technology podcast"] Search Terms. Text queries passed to iTunes Search to discover shows. Each term resolves to its top matching show ID.
maxEpisodesPerShow integer 3 Max Episodes per Show. Cap on the number of newest episodes returned per watchlist entry. minimum=1 maximum=100
delivery string enum dataset Delivery. Where to send results: dataset or webhook. enum: dataset, webhook
webhookUrl string empty Webhook URL. Webhook URL to POST results to when delivery=webhook.
dryRun boolean false Dry Run. Run without saving results to the dataset.
