How is LEI Entity Lifecycle Watch Report different from RDAP Domain Expiry & Whois Scraper and SEC EDGAR Scraper?

LEI Entity Lifecycle Watch Report (taroyamada/lei-entity-lifecycle-watch-report): Monitor GLEIF public LEI records for source-linked entity status, registration, renewal, and legal-name changes, then produce portfolio reports and optional exports. Not RDAP/whois domain expiry. Not SEC EDGAR filings. Not a vendor-registry pack. You supply LEIs or legal names. RDAP Domain Expiry & Whois Scraper is for RDAP registration records (input domains; RDAP; Expiry rows). Not GLEIF LEI lifecycle. SEC EDGAR Scraper is for 8-K and S-1 filing alerts (input tickers / CIKs; EDGAR; Filing rows). Not LEI registration status. Public Vendor Registry Intelligence is for Public vendor registries (input names / ids; Public registries; Vendor rows). Not GLEIF LEI records.

What input is required?

Live required fields: none (see live fields). Published exampleRunInput is shown below.

Field Type Default Notes
leis string[] ["INR2EJN1ERAN0W5ZP974"] LEI codes. Up to 200 20-character LEI codes to monitor directly.
legalNames string[] [] Legal names. Optional legal-name filters sent to the GLEIF search endpoint.
countries string[] [] Countries. Optional two-letter country filters for legal addresses.
entityStatuses string[] [] Entity statuses. Optional entity status filters such as ACTIVE or INACTIVE.
registrationStatuses string[] [] Registration statuses. Optional LEI registration status filters such as ISSUED, LAPSED, or RETIRED.
pageSize integer 25 Page size. Maximum records returned for each name or country search. minimum=1 maximum=100
monitorKey string "default-lei-portfolio" Monitor key. Stable name for this portfolio. Keep it unchanged for recurring no-change detection.
initialRunMode string enum "baseline_only" Initial run mode. baseline_only stores the first snapshot with zero rows; emit_backfill emits the initial portfolio. enum: baseline_only, emit_backfill
generateReport boolean true Generate portfolio report. Emit the report row first when a baseline or lifecycle change is available.
generateExport boolean false Generate export manifest. Emit a normalized export manifest on a changed run. No file is created outside the actor output.
emitRawRows boolean false Emit entity rows for changed records. Emit the normalized entity row alongside lifecycle alerts. Report output remains first.
emitUnchanged boolean false Emit unchanged rows. Leave false for recurring monitoring so an unchanged run has zero rows and zero charges.
maxChargeUsd number 25 Maximum run charge. The actor refuses delivery before any row is pushed if the configured event prices exceed this amount. minimum=0.005 maximum=500
dryRun boolean false Dry run. Emit one sample of every billable event without external calls, state writes, or charges.
