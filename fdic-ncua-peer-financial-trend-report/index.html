How is FDIC & NCUA Peer Financial Trend Report different from US Treasury Data Scraper and SEC EDGAR Scraper?

FDIC & NCUA Peer Financial Trend Report (taroyamada/fdic-ncua-peer-financial-trend-report): Compare bounded same-source bank or credit-union peer watches across explicit quarterly metrics and periods. Receive source-linked changes, peer percentiles, reports, and exports. Not US Treasury Fiscal Data. Not SEC EDGAR 8-K. Not XBRL public-company facts. You supply FDIC certs or NCUA charter numbers. US Treasury Data Scraper is for Treasury Fiscal Data (input datasets; Treasury API; Series rows). Not FDIC/NCUA call reports. SEC EDGAR Scraper is for 8-K and S-1 filing alerts (input tickers / CIKs; EDGAR; Filing rows). Not bank call-report peers. SEC XBRL Peer Financial Change Report is for Public-company XBRL facts (input watchlists + userAgent; SEC company facts; Metric-change alerts). Not FDIC/NCUA institutions.

What input is required?

Live required fields: watches. Published exampleRunInput is shown below.

Field Type Default Notes
watches any[] [] Institution peer watches. Each watch is a bounded peer group from one source. Use at least two FDIC certificate numbers or NCUA charter numbers so peer percentiles are meaningful. Required.
monitorKey string "fdic-ncua-peer-financial-trend-watch" Monitor key. Stable isolated state namespace for recurring checks. Use a new key for a separate portfolio.
initialRunMode string enum "baseline_only" Initial run mode. baseline_only saves the first snapshot with zero rows; emit_backfill emits the current bounded observations for a deliberate paid backfill. enum: baseline_only, emit_backfill
generateReport boolean true Generate trend report. Emit one descriptive peer trend report when selected observations are new or changed.
emitRawRows boolean false Emit financial rows. Add one low-priced descriptive institution metric row per selected observation. Off by default.
emitExport boolean false Generate evidence export. Emit one compact JSON evidence export when selected observations are new or changed.
includeInstitutionDirectory boolean true Include institution labels. For FDIC, fetch the bounded institutions endpoint. NCUA labels come from FOICU.txt in the selected official ZIP.
emitUnchanged boolean false Emit unchanged observations. Accepted for compatibility. Unchanged checks always remain zero rows and zero charge.
maxChargeUsd number 50 Maximum charge USD. Fail closed before any push if the planned event total exceeds this cap. minimum=0.01 maximum=500
maxRequests integer 20 Maximum source requests. Hard upper bound for this run, including directory and financial requests. minimum=1 maximum=50
requestIntervalMs integer 250 Request interval milliseconds. Minimum interval between official source requests. Keep at least 100ms. minimum=100 maximum=10000
dryRun boolean false Dry run. Return deterministic representative rows without contacting FDIC or NCUA, reading or saving state, or charging events.
