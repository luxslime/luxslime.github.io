How is SEC Material Contract Intelligence different from SEC EDGAR Scraper and SEC & ESG Report Scraper?

SEC Material Contract Intelligence (taroyamada/sec-material-contract-intelligence): This Actor searches official SEC filings (tickers, CIKs, issuers, accessionNumbers) for material agreements and exhibits matching contractKeywords / counterpartyTerms. Optional includeExhibitText pulls capped exhibit text. Not investment, legal, or procurement advice. Not Form 4 insider trades. Not a complete contract database. Respect SEC fair-access User-Agent rules (secUserAgent on the live schema). SEC EDGAR Scraper is for 8-K/S-1 filing alerts (input companies; SEC EDGAR; SEC filing rows). Not ESG report packs. SEC & ESG Report Scraper is for ESG/climate packs (input company disclosure targets; SEC EDGAR + reports; disclosure change rows). Not 8-K/S-1 filing alerts alone. SEC Insider Transaction Scraper is for Forms 3/4/5 trades (input issuers; SEC EDGAR ownership; insider-trade rows). Not 8-K material contracts.

What input is required?

Live required fields: none listed (see live fields). Published exampleRunInput is shown below. Find material agreement, customer contract, partnership, procurement, and exhibit leads from official SEC filings.

Field Type Default Notes
tickers any[] ["MSFT"] Tickers. Ticker symbols to resolve through the SEC company ticker index.
ciks any[] empty CIKs. SEC Central Index Key values. Use this when a ticker is unavailable or ambiguous.
issuers any[] [] Issuers. Mixed ticker symbols or CIK numbers to inspect. Prefer Tickers and CIKs for clearer runs.
accessionNumbers any[] empty Accession numbers. Optional direct SEC accession numbers to inspect, such as 0000789019-26-000111.
formTypes any[] ["8-K", "10-K", "10-Q"] Form types. SEC forms to include.
startDate string empty Start date. Optional filing date lower bound in YYYY-MM-DD format. Overrides daysBack start when set.
endDate string empty End date. Optional filing date upper bound in YYYY-MM-DD format. Defaults to today when empty.
daysBack integer 365 Days back. How far back to scan recent SEC filings. min=1 max=3650
limit integer 50 Result limit. Maximum rows to emit. min=1 max=500
maxFilingsPerIssuer integer 50 Max filings per issuer. Maximum matching filings to inspect per issuer before row limiting. min=1 max=500
maxExhibitsPerFiling integer 12 Max exhibits per filing. Maximum Exhibit 10-style attachments to emit per filing. min=0 max=100
contractKeywords any[] empty Contract keywords. Additional phrases to flag in filing metadata or fetched exhibit text.
counterpartyTerms any[] empty Counterparty terms. Optional customer, partner, supplier, agency, or competitor names to highlight.
includeExhibitText boolean false Fetch exhibit text. Fetch Exhibit 10 documents for value, effective-date, and counterparty hints. Leave off for lighter metadata-only runs.
maxExhibitChars integer 12000 Max exhibit characters. Maximum exhibit text characters to analyze when Fetch exhibit text is enabled. min=1000 max=50000
emitFilingRowsWithoutExhibits boolean true Emit filing-only rows. Emit a filing-level row when a relevant filing has no Exhibit 10-style attachment in the SEC directory index.
requestDelayMs integer 120 Delay between SEC filing requests. Delay between SEC Archives filing requests. min=0 max=5000
timeoutMs integer 25000 HTTP timeout (ms). HTTP timeout for SEC API and Archives requests. min=1000 max=60000
secUserAgent string empty SEC User-Agent. Optional SEC-compliant User-Agent with contact information.
delivery string enum dataset Delivery. Where to send results. Dry runs never push dataset rows or webhooks. enum: dataset, webhook
webhookUrl string empty Webhook URL. Required when delivery=webhook.
dryRun boolean false Dry run. Run without writing dataset rows or posting webhook output.
