What input is required?

vendors is required: an array of objects. Each vendor must have statusPageUrl. README examples that send vendors as strings, incidentSinceDays, or emitChangedOnly are not live schema fields. additionalProperties is false. Use datasetMode as the change filter.

What does a digest contain?

Published README fields include vendorId, vendorName, checkedAt, executiveSummary, incidentState, incidentCount, affectedComponents, actionNeeded, recommendedActions, changedSinceLastRun, evidence, and meta (statusPageUrl, incidentFeedUrl, criticality, owner, tags, parseSource, fingerprint, previousFingerprint, isFirstRun). The published Stripe sample is a README illustration, not a live coverage guarantee. Unreachable pages set incidentState unknown and actionNeeded true.

How do datasetMode, snapshots, and webhooks work?

datasetMode default is all: always emit the digest. changes_only emits when the fingerprint changed. action_needed emits only when actionNeeded is true. Keep snapshotKey constant for change detection. notifyOnNoChange default is false: skip webhook when nothing changed. dryRun true saves no snapshots and fires no webhook.

Does this Actor log into vendor portals or render a browser?

No. It uses HTTP plus JSON/RSS parsing without a headless browser. It is not for authenticated internal portals and it does not bypass anti-bot. incidentFeedUrl is optional. Only scan public status pages you are authorized to monitor.
