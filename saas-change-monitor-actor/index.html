SaaS pricing and policy page change alerts from public URLs

Not an authenticated customer portal, CPQ, or invoice scraper. Not a PDF-contract parser. Public web only; aggressive bot walls may block fetches.

How is SaaS Pricing Tracker different from Website Content Extractor and Status Page Incident Digest Monitor?

SaaS Pricing Tracker — Competitor Page Change Alerts (taroyamada/saas-change-monitor-actor): This Actor fetches public SaaS pricing, terms, and feature pages, snapshots extracted text, and emits source-linked change rows when the page hash or filtered text drifts. Live input is a targets[] list of id, name, kind, and url — not a top-level urls array. Not an authenticated customer portal, CPQ, or invoice scraper. Not a PDF-contract parser. Public web only; aggressive bot walls may block fetches. Website Content Extractor is for One-shot page-to-markdown (input urls; page HTML; markdown/text). Not recurring pricing diffs. Status Page Incident Digest Monitor is for Vendor status-page incidents (input status page feeds/URLs; status.io-style public pages; incident digest rows). Not pricing/terms copy diffs. Trust Center Subprocessor Monitor is for Trust-center vendor lists (input trust-center URLs; public subprocessors pages; subprocessor change rows). Not plan-price text diffs.

What input is required?

Live required fields: targets. Published exampleRunInput uses three targets (Stripe pricing, Linear terms, Vercel features) with include/exclude patterns. Schema prefill is Notion pricing. datasetMode default changes_only. delivery enum includes email as a placeholder path.

Field Type Default Notes
targets array required empty Monitored Targets. List of targets. Each item supports id, name, kind, url, includePatterns, excludePatterns, maxChars, fixtureHtml, fixturePath.
requestTimeoutSeconds integer 30 Request Timeout (seconds). HTTP request timeout per target.
userAgent string empty Custom User-Agent. Optional user-agent header for target requests.
maxChars integer 25000 Global Max Chars per Page. Upper bound for extracted text length.
delivery string dataset Delivery Mode. Where to send run results.
datasetMode string changes_only Dataset Mode. Choose whether dataset/webhook sends all targets or only event items.
webhookUrl string empty Webhook URL. Required when delivery is webhook.
notifyOnNoChange boolean false Notify Even If No Change. When false, webhook mode skips if no event items.
snapshotKey string saas-change-monitor-snapshots Snapshot Key. Key used for snapshot persistence.
nowIso string empty Now (ISO, optional). Optional fixed timestamp for deterministic tests.
dryRun boolean false Dry Run. Skip delivery side effects and snapshot save.

How do dataset, webhook, and dry-run delivery work?

delivery defaults to dataset on the live schema. Dataset output is the billable surface when rows are written. webhookUrl is used when delivery is webhook (and typically not during dryRun). dryRun true validates or samples without the usual dataset/webhook side effects described on the Store schema. datasetMode can limit emits to changes_only versus all. Unchanged runs that write zero default-dataset rows typically charge $0.00 on current PPE.

What does a result contain?

The published README output sample on the Store page is truncated or not valid standalone JSON. Treat README field lists as illustrations, not a live coverage guarantee. There is no published output JSON schema on the Store page.
