How is SAM.gov Vendor Pursuit Intelligence different from TED, SAM.gov & Grants Bid Alerts and Government Contract Award Change Report?

SAM.gov Vendor Pursuit Intelligence (taroyamada/sam-vendor-pursuit-intelligence): This Actor scrapes public SAM.gov opportunities from keywords, NAICS, and optional agency filters you supply. CSV/JSON dataset output. A SAM.gov API key is optional. Not a multi-source TED/Grants bid desk (use TED, SAM.gov & Grants Bid Alerts). Not post-award spend or incumbent mapping. Not a prospecting list or outreach tool. Informational only. TED, SAM.gov & Grants Bid Alerts is for Open opportunities / tenders (input keywords / jurisdictions; SAM/TED/Grants notices; Opportunity rows). Not vendor-pursuit profiles, Form D notices, or post-award spend reports. Government Contract Award Change Report is for Post-award spend/award changes (input feeds; TED / USASpending awards; Award change rows). Not open bid queues. Grants.gov Scraper is for Grants.gov-only funding notices (input feeds / watch terms; Grants.gov; Funding digest rows). Not a multi-source TED/SAM desk.

What input is required?

Live required fields: none listed (see live fields). Published exampleRunInput is shown below.

Field Type Default Notes
keywords any[] ["software"] Keywords. Opportunity keywords to search.
naicsCodes any[] empty NAICS codes. Optional NAICS filters.
agency string empty Agency. Optional federal agency filter.
postedFrom string empty Posted from. Optional posted-from date. Accepts MM/DD/YYYY or YYYY-MM-DD and is sent to the SAM API as MM/DD/YYYY.
postedTo string empty Posted to. Optional posted-to date. Accepts MM/DD/YYYY or YYYY-MM-DD and is sent to the SAM API as MM/DD/YYYY.
samApiKey string empty SAM API key. Optional SAM.gov API key. Falls back to SAM_API_KEY environment variable.
samApiUrl string https://api.sam.gov/opportunities/v2/search SAM API URL. Optional SAM opportunities search endpoint override for testing or gateway deployments.
emitSampleOnAuthMissing boolean true Emit sample on missing auth. Compatibility flag. Live runs without SAM authentication always emit zero rows; deterministic samples are dry-run only.
limit integer 25 Result limit. Maximum rows to emit. minimum=1 maximum=100
delivery string enum dataset Delivery. Where to send results. enum: dataset, webhook
webhookUrl string empty Webhook URL. Required when delivery=webhook.
dryRun boolean false Dry run. Run without writing dataset rows or posting webhook output.

Published Store example run input (omitted fields take schema defaults):

{
  "keywords": [

How do dataset, webhook, and dry-run delivery work?

delivery defaults to dataset on the live schema. Dataset output is the billable surface when rows are written. webhookUrl is used when delivery is webhook (and typically not during dryRun). dryRun true validates or samples without the usual dataset/webhook side effects described on the Store schema. Unchanged runs that write zero default-dataset rows typically charge $0.00 on current PPE.
