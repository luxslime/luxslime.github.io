How is FTC Enforcement Case Delta & Report different from EPA ECHO Enforcement Scraper and Regulatory Alerts Scraper?

FTC Enforcement Case Delta & Report (taroyamada/ftc-enforcement-case-delta-report): Track source-linked changes on the FTC public Cases and Proceedings page and receive structured case alerts, evidence summaries, and exports. Not EPA ECHO facility enforcement. Not a Federal Register digest. Not a general regulatory-alert scraper. No actor-start event on live PPE. EPA ECHO Enforcement Scraper is for EPA ECHO enforcement (input facilities / terms; ECHO public data; Enforcement rows). Not FTC case dockets. Regulatory Alerts Scraper is for Regulatory alert pages (input urls / terms; Public regulatory pages; Alert rows). Not FTC Cases and Proceedings. Federal Register Scraper is for Federal Register documents (input terms; Federal Register; Document rows). Not FTC enforcement cases.

What input is required?

Live required fields: none (see live fields). Published exampleRunInput is shown below.

Field Type Default Notes
searchTerms string[] [] Search terms. Match any term against the case title, summary, matter number, docket number, or case key.
actionTypes string[] [] Action types. Exact case action types such as Federal or Administrative.
caseStatuses string[] [] Case statuses. Exact case statuses such as Pending, Closed, or Under Order.
updatedSince string empty Updated since. Optional ISO date. Only records with a source last-updated date on or after this value are watched.
maxPages integer 1 Maximum pages. Number of public FTC list pages to fetch, from 1 to 10. minimum=1 maximum=10
maxCases integer 50 Maximum cases. Maximum number of matched case records retained in one run. minimum=1 maximum=1000
monitorKey string "default" Monitor key. Isolates state for a watchlist. Use a stable key for recurring runs.
initialRunMode string enum "baseline_only" Initial run mode. baseline_only stores the snapshot for free; emit_backfill emits current matches as changes. enum: baseline_only, emit_backfill
emitUnchanged boolean false Emit unchanged. Retained for input compatibility. Unchanged monitoring remains zero-row and zero-charge.
emitRawRows boolean false Emit raw case rows. Add low-cost rows for changed cases in addition to alerts. Disabled by default.
generateReport boolean true Generate evidence report. Add one source-linked evidence summary when changes are detected.
emitExport boolean false Generate export event. Add one structured JSON export event when changes are detected.
maxChargeUsd number 0 Maximum charge USD. The run emits no billable rows and does not commit state when its estimated price exceeds this cap. minimum=0
dryRun boolean false Dry run. Emit deterministic local examples without source requests, state changes, or billing.
