How is FDA Drug Shortage Supply Change Report different from FDA Warning Letters Scraper and DailyMed Label Change Watch Report?

FDA Drug Shortage Supply Change Report (taroyamada/fda-drug-shortage-supply-change-report): Monitor official FDA drug-shortage records. Generate source-linked change alerts, supply reports, and optional exports. Not FDA warning letters. Not DailyMed SPL label versions. Not a CPSC/NHTSA product-safety recall digest. You supply watches. FDA Warning Letters Scraper is for FDA warning-letter pages (input search terms; FDA warning letters; Letter rows). Not drug-shortage status. DailyMed Label Change Watch Report is for DailyMed SPL metadata/versions (input watches; DailyMed; Label-change alerts). Not FDA shortage records. Product Safety Recall Scraper is for CPSC and related recalls (input terms; Public recall feeds; Recall rows). Not FDA drug shortages.

What input is required?

Live required fields: watches. Published exampleRunInput is shown below.

Field Type Default Notes
watches any[] [] Shortage watches. Bounded recurring searches. Use a stable id and at least one filter per watch. Required.
monitorKey string "fda-drug-shortage-watch" Monitor key. Stable isolated state namespace for a recurring shortage watch.
initialRunMode string enum "baseline_only" Initial run mode. baseline_only stores the first observation with zero rows; emit_backfill emits current matches for an explicit first report. enum: baseline_only, emit_backfill
generateReport boolean true Generate supply report. Generate one aggregate descriptive report when new or changed observations are emitted.
emitRawRows boolean false Emit shortage rows. Emit one normalized public shortage row for each new or changed record. This is the low-priced row event.
emitExport boolean false Generate shortage export. Generate a compact JSON-ready export when new or changed observations are emitted.
emitUnchanged boolean false Emit unchanged observations. Accepted for compatibility, but unchanged observations always remain zero rows and zero charge for billing safety.
maxRecordsPerWatch integer 50 Maximum records per watch. Maximum records requested from openFDA per watch. The official API maximum is 100. minimum=1 maximum=100
maxChargeUsd number 25 Maximum charge USD. Fail closed before pushing any row if planned PPE charges exceed this cap. minimum=0.005 maximum=250
openfdaApiKey string empty Optional openFDA API key. Optional user-supplied openFDA key. Leave blank: normal use does not require a key. The key is never written to output, source URLs, or state.
dryRun boolean false Dry run. Return representative event rows without calling openFDA, saving state, or charging PPE events.
