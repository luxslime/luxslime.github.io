Use cases

  • QA and CI gates: audit a known URL list at WCAG A, AA (default), or AAA and fail on critical or serious nodes.
  • Compliance evidence: keep snapshot diffs under snapshotKey (default wcag-accessibility-snapshots) for recurring runs.
  • SPA pages: set waitForSelector and timeout (default 30000 ms, min 5000, max 60000) when the accessibility tree is late.

What input is required?

urls is required: URLs to audit, maximum 50 per run. Schema prefill is example.com and w3.org. Live schema fields are urls, wcagLevel (A, AA, AAA; default AA), includeWarnings (default true), delivery (dataset or webhook; default dataset), webhookUrl, snapshotKey (default wcag-accessibility-snapshots), concurrency (default 2, min 1, max 5), waitForSelector, timeout (default 30000, min 5000, max 60000), and dryRun (default false). README examples that send targets or emitChangedOnly are not live schema fields.

dryRun boolean false If true, no save / no webhooks.
