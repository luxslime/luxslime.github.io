How is App Review Regression & Release Report different from Chrome Web Store Extension Intelligence and Website Content Extractor?

App Review Regression & Release Report (taroyamada/app-release-review-regression-monitor): This Actor compares public App Store and Google Play release metadata and review samples across a release window versus lookback, then can emit regression alerts and per-app reports. Default dryRun is true, so a default Start does not bill. Not a review generator, reviewer profiler, or guarantee of store performance. Sample-based signals only; do not identify or target individual reviewers. Chrome Web Store Extension Intelligence is for Chrome extension listings (input extensionUrls / searchTerms; Chrome Web Store HTML; extension metadata). Not iOS/Android release regression. Website Content Extractor is for Page markdown (input urls; HTML body; markdown). Not store review samples. G2 & Capterra Review Scraper is for B2B SaaS reviews (input reviewPageUrls; G2/Capterra pages; review rows). Not App Store/Play release windows.

What input is required?

Live required fields: none listed (see live fields). exampleRunInput sets dryRun false, reviewLimit 10, and includes limit, delivery, webhookUrl which are NOT live schema fields. Live fields include runMode audit|monitor, initialRunMode baseline_only|emit_backfill, generateReport default true, dryRun default true, maxChargeUsd default 0.

How do dataset, webhook, and dry-run delivery work?

dryRun true validates or samples without the usual dataset/webhook side effects described on the Store schema. Unchanged runs that write zero default-dataset rows typically charge $0.00 on current PPE.

What does a result contain?

No fenced output JSON. README: every row carries billingEventName, stableKey, sourceUrl, retrievedAt, source limitations, prohibited interpretations; report rows add release metadata, review-sample aggregates, regression status, recommended investigation steps. Treat README samples as illustrations, not a live coverage guarantee. There is no published output JSON schema on the Store page.
