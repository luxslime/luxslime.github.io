How is Clinical Trial & FDA Signal Alerts different from ClinicalTrials.gov Sponsor Pipeline Scraper and FDA Warning Letters Scraper?

Clinical Trial & FDA Signal Alerts (taroyamada/clinical-trials-fda-watch-monitor): Watch drugs, sponsors, and conditions across ClinicalTrials.gov and openFDA: new-trial alerts, trial status changes, and FDA drug recall signals as source-linked rows. Not a sponsor-pipeline snapshot of ClinicalTrials.gov studies (use ClinicalTrials.gov Sponsor Pipeline Scraper). Not an FDA warning-letter digest. Not a PubMed evidence-gap report. You supply watches. ClinicalTrials.gov Sponsor Pipeline Scraper is for Sponsor/condition study inventory (input sponsors / conditions; ClinicalTrials.gov; Study rows). Not FDA recall/enforcement signal alerts. FDA Warning Letters Scraper is for FDA warning-letter pages (input search terms; FDA warning letters; Letter rows). Not ClinicalTrials.gov status watches. PubMed & Clinical Trials Evidence Gap Report is for PubMed vs trials evidence gap (input query terms; PubMed + ClinicalTrials.gov; Evidence-gap report). Not openFDA recall signal alerts.

What input is required?

Live required fields: watches. Published exampleRunInput is shown below.

Field Type Default Notes
dryRun boolean false Dry run. Return sample value-event rows without fetching live sources.
watches any[] [{"id": "glp1-obesity-watch", "drugs": ["semaglutide", "tirzepatide"], "conditions": ["obesity"], "sponsors": ["Novo Nordisk", "Eli Lilly"]}] Watches. Drug, condition, sponsor, and keyword watches. Each watch needs at least one of drugs, conditions, sponsors, or keywords. Optional phases/statuses filters apply to ClinicalTrials.gov only; note a statuses filter can hide status-change alerts for trials that leave the filtered set. Required.
sources string[] ["trials", "fda"] Sources. Public sources to query. No API keys required.
monitorKey string "my-clinical-trials-fda-watch" Monitor key. Stable key for stateful no-change monitoring.
initialRunMode string enum "baseline_only" Initial run mode. baseline_only saves state and emits no billable rows. emit_backfill emits current matches for charged proof or first reports. enum: baseline_only, emit_backfill
generateReport boolean false Generate watch report ($5). Opt-in: generate a source-linked pipeline watch report row when alerts are found.
emitExport boolean false Generate export row ($7). Opt-in: generate an export bundle row when alerts are found.
emitRawRows boolean false Emit raw record rows. Optional low-priced raw rows. Main value is alert rows.
maxRecordsPerWatch integer 50 Max records per watch. Maximum source records to normalize per watch and source before dedupe and alert generation. minimum=1 maximum=100
maxChargeUsd number 25 Max charge USD. Fail closed before delivery if the estimated PPE charge would exceed this amount. minimum=0.1 maximum=250
