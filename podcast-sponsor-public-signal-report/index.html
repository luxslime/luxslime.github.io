How is Podcast Sponsor Public Signal Report different from Apple Podcasts Scraper and Apple Podcasts Reviews Scraper?

Podcast Sponsor Public Signal Report (taroyamada/podcast-sponsor-public-signal-report): This Actor reads public RSS sponsor signals from feed URLs you supply. Cheapest live path is the sponsor snapshot; keep the $29/$59 reports off until you need them. Not Apple Podcasts search or charts. Not a contact-enrichment or outreach list. Public RSS/show pages only. Informational only. Apple Podcasts Scraper is for iTunes search, charts, episodes (input searchTerm; Apple/iTunes endpoints; Podcast metadata rows). Not RSS-only sponsor evidence. Apple Podcasts Reviews Scraper is for Public review RSS (input collection IDs; Customer Reviews RSS; Review rows). Not sponsor-signal reports. RSS & Atom Feed Extractor is for Known-publisher feed XML (input feed URLs; RSS/Atom XML; Feed item rows). Not sponsor-evidence extraction.

What input is required?

Live required fields: none listed (see live fields). Published exampleRunInput is shown below.

Field Type Default Notes
reportTier string enum sponsor_snapshot Report Tier. Select the report level. Watch summaries are proof-gated and are not selectable during private validation. enum: sponsor_snapshot, sponsor_fit
rssFeedUrls any[] ["https://feeds.npr.org/510289/podcast.xml"] RSS Feed URLs. Public podcast RSS feed URLs.
applePodcastUrls any[] empty Apple Podcast URLs or IDs. Public Apple Podcast URLs or collection IDs. The actor uses the public iTunes Lookup API to resolve feed URLs when possible.
showUrls any[] empty Official Show / Advertise URLs. Official public show pages, advertise pages, media kit pages, or sponsor pages.
maxEpisodesPerFeed integer 3 Max Episodes Per Feed. Maximum RSS episodes to inspect per feed. minimum=1 maximum=50
maxChargeUsd number 9 Max Charge USD. Safety cap. If the selected tier would exceed this cap, the run returns limit_reached with no charge. minimum=0 maximum=500
maxReports integer 1 Max Reports. V1 emits one report per run. minimum=1 maximum=10
demoMode boolean false Demo Mode. Return a no-charge sample report without external requests.
delivery string enum dataset Delivery Mode. Choose where to deliver the generated sponsor signal report. Dataset delivery is recommended for first runs. enum: dataset, webhook, dataset_and_webhook
webhookUrl string empty Webhook URL. HTTPS endpoint used when delivery includes webhook.
dryRun boolean false Dry Run. Set true to validate input and emit a no-charge sample report without fetching sources or writing dataset rows.

How do dataset, webhook, and dry-run delivery work?

delivery defaults to dataset on the live schema. Dataset output is the billable surface when rows are written. webhookUrl is used when delivery is webhook (and typically not during dryRun). dryRun true validates or samples without the usual dataset/webhook side effects described on the Store schema. Unchanged runs that write zero default-dataset rows typically charge $0.00 on current PPE.
