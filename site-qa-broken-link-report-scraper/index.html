How is Site QA Broken Link Report different from Broken Link Checker and Bulk URL Status Checker?

Site QA Broken Link Report (taroyamada/site-qa-broken-link-report-scraper): Check public pages for broken links and generate source-linked URL health report rows. Not a start-URL HTML crawler that only lists 404s (use Broken Link Checker). Not a known-URL HTTP status list (use Bulk URL Status Checker). Not an AI crawler robots/llms.txt pack. You supply the URLs. Broken Link Checker is for Crawl start URLs for 404s (input start URLs; Linked HTTP statuses; Broken-link rows). Not a billed URL-health report pack. Bulk URL Status Checker is for Known URL list HTTP status (input URL list; HTTP status codes; Status rows). Not an HTML link crawl or report pack. Site QA Indexability AI Crawler Report is for robots.txt and llms.txt signals (input urls; robots.txt / llms.txt; Policy-check and indexability events). Not broken-link URL health issues.

What input is required?

Live required fields: urls. Published exampleRunInput is shown below.

Field Type Default Notes
urls any[] ["https://example.com/?siteQaCanary=links-v2"] Public page URLs. Public URLs that you are allowed to audit. Required.
maxPages integer 10 Max pages. Maximum number of input pages to check. minimum=1 maximum=100
maxLinksPerPage integer 25 Max links per page. Maximum links to check per page for URL health workflows. minimum=1 maximum=250
emitPageRows boolean false Emit raw page rows. Emit optional raw page snapshot rows in addition to value-event issue/report rows.
generateReport boolean true Generate report row. Generate a site-level report row.
emitExport boolean false Generate export row. Generate an export row for handoff workflows.
emitUnchanged boolean false Emit unchanged rows. When false, repeated unchanged runs emit zero rows and zero charges.
dryRun boolean false Dry run. Emit local sample rows without charging.
