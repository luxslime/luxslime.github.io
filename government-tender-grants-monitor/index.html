How is Government Tender & Grants Alert Report different from TED, SAM.gov & Grants Bid Alerts Scraper and Grants.gov Scraper?

Government Tender & Grants Alert Report (taroyamada/government-tender-grants-monitor): Monitor public TED, Grants.gov, UK Contracts Finder, World Bank, and optional SAM.gov opportunities and generate source-linked tender, grant, deadline, report, and export rows. Not a SAM.gov + TED bid-alert Actor focused on federal/EU tenders you already run (use TED, SAM.gov & Grants Bid Alerts). Not a Grants.gov-only digest. Not an RFP rebid watch on URLs you paste. You supply watches. SAM.gov needs samApiKey when that source is enabled. TED, SAM.gov & Grants Bid Alerts Scraper is for SAM.gov + TED bid alerts (input keywords / notices; SAM.gov / TED; Bid-alert rows). Not a multi-source UK/World Bank watch pack. Grants.gov Scraper is for Federal funding notices (input keywords; Grants.gov; Notice rows). Not TED/Contracts Finder/World Bank alerts. Public RFP Rebid Watch Report is for Public RFP pages you supply (input urls / watches; User-supplied RFP pages; Rebid report). Not TED/Grants.gov opportunity APIs.

What input is required?

Live required fields: watches. Published exampleRunInput is shown below.

Field Type Default Notes
dryRun boolean false Dry run. Return sample value-event rows without fetching live sources.
watches any[] [{"id": "cloud-modernization", "keywords": ["cloud", "cybersecurity"], "naicsCodes": ["541512"], "cpvCodes": ["72000000"], "deadlineWithinDays": 180}] Watches. Keyword, CPV/NAICS, country, and source watches. Required for non-dry runs. Required.
sources string[] ["ted", "grants", "uk", "worldbank"] Sources. Public sources to query. SAM.gov is optional and requires samApiKey.
monitorKey string "my-govcon-bid-watch" Monitor key. Stable key for stateful no-change monitoring.
initialRunMode string enum "baseline_only" Initial run mode. baseline_only saves state and emits no billable rows. emit_backfill emits current matches for charged proof or first reports. enum: baseline_only, emit_backfill
emitUnchanged boolean false Emit unchanged rows. Keep false for recurring monitoring so unchanged runs write zero dataset rows and charge zero.
generateReport boolean false Generate watch report ($5). Opt-in: generate a source-linked buyer watch report row when alerts are found.
emitExport boolean false Generate export row ($7). Opt-in: generate a tender export row when alerts are found.
emitRawRows boolean false Emit raw opportunity rows. Optional low-priced raw rows. Main value is alert/report/export rows.
maxOpportunitiesPerWatch integer 50 Max opportunities per watch. Maximum source records to normalize per watch before dedupe and alert/report generation. minimum=1 maximum=250
maxChargeUsd number 25 Max charge USD. Fail closed before delivery if the estimated PPE charge would exceed this amount. minimum=0.1 maximum=250
samApiKey string empty SAM.gov API key. Optional user-supplied official SAM.gov API key. Leave empty to use TED, Grants.gov, UK Contracts Finder, and World Bank sources only.
