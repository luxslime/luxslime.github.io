Compare ClinicalTrials.gov studies with PubMed citations for evidence gaps

PubMed & Clinical Trials Evidence Gap Report compares ClinicalTrials.gov records with PubMed citation metadata. Biomedical research, medical affairs, and evidence teams enter watchlists, NCT IDs, and PubMed queries. Outputs are source-linked evidence rows, gap alerts, reports, and exports. They are descriptive citation metadata — not medical conclusions, treatment guidance, article full text, or abstracts.

Live schema default dryRun is true: Start with defaults returns illustrative rows, does not call NCBI, and does not bill. Set dryRun false for a capped live run after preview.

This independent Actor is not affiliated with, sponsored by, or endorsed by NCBI, PubMed, or ClinicalTrials.gov.

How is PubMed & Clinical Trials Evidence Gap Report different from PubMed Literature Watch?

This Actor compares ClinicalTrials.gov studies with PubMed citation metadata and can emit evidence rows, evidence-gap alerts, a biomedical evidence report, and an export. Store ID taroyamada/biomedical-trial-literature-evidence-report. PubMed Literature Watch is NCBI E-utilities citation watch, literature-update reports, and new-PMID alerts without ClinicalTrials.gov matching. OpenAlex Scholarly Works Scraper is the official OpenAlex API, not trial matching. NIH RePORTER Funding Landscape Report is NIH awards. Google News Scraper is news RSS. Citation metadata only — not full text or abstracts. Not medical advice.

What input is required?

The live schema has no required array. additionalProperties is false. README Quickstart JSON that sends watchlist conditions, interventions, and pubmedQuery is README documentation; the live items schema is not fully expanded. Prefer nctIds as in the paid-trial JSON above.

Does this Actor return full text or medical conclusions?

No. Official NCBI ESearch and ESummary JSON; no browser scraping or login. Citation metadata only — not full text or abstracts. PubMed records can be incomplete or updated after publication. Optional NCBI API key; keyless mode is paced conservatively. Outputs are not medical advice, clinical efficacy claims, or a substitute for reviewing the source publication. Keep NCBI attribution and source URLs.
